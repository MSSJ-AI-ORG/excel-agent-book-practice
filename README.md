# 《클로드로 엑셀 천재되기》 실습 자료

책 《클로드로 엑셀 천재되기》를 읽으면서 **직접 따라 해 볼 엑셀 파일**과, 해 본 결과가 맞는지 알려 주는 **채점기**가 들어 있습니다.

책은 엑셀에게 일을 «시키는 법»보다 시킨 결과를 «확인하는 법»을 더 많이 다룹니다.
이 저장소도 같습니다. 과제를 끝내면 채점기가 파일을 직접 열어 보고, 맞았는지 틀렸는지를 항목마다 알려 줍니다.
「다 했습니다」라는 말 대신 파일로 확인하는 연습입니다.

---

## 받는 법

둘 중 편한 쪽을 고르세요.

**① 압축 파일로 받기 (처음이라면 이쪽)**

1. 이 페이지 위쪽의 초록색 **Code** 단추를 누릅니다.
2. 맨 아래 **Download ZIP** 을 누릅니다.
3. 내려받은 파일을 오른쪽 클릭해 **압축 풀기**를 합니다. 바탕 화면보다는 `C:\엑셀실습` 같은 따로 만든 폴더에 푸는 편이 좋습니다(책 2장 2.1).
4. 풀고 나면 이름 끝에 `-main` 이 붙은 폴더(`excel-agent-book-practice-main`)가 생깁니다. 이름은 그대로 두어도 됩니다.
   그 폴더를 열었을 때 `practice` · `exercises` · `grader` 세 폴더와 이 `README.md` 가 바로 보여야 합니다.
   폴더를 한 번 더 열어야 그것들이 보인다면, 한 겹 안쪽 폴더가 「저장소 폴더」입니다.

**② git 으로 받기 (git 을 써 봤다면)**

```
git clone https://github.com/MSSJ-AI-ORG/excel-agent-book-practice.git
```

## 폴더 안내

```
excel-agent-book-practice/
├── practice/              실습 파일 — 책 본문이 부르는 이름 그대로입니다
│   ├── 이번 달 매출.xlsx       0부·1부·3부에서 쓰는 작은 표
│   ├── 부서 관리대장.xlsx      2부·6부·7부에서 쓰는 물려받은 파일 (시트 일곱 장)
│   ├── 부서 관리대장.xlsm      4부에서 쓰는 같은 대장 — 매크로 네 묶음이 들어 있습니다
│   ├── 받은파일/              15장에서 합칠 부서별 파일 세 개
│   └── MANIFEST.json          위 파일들의 지문 — 채점기가 「원본을 건드렸나」를 볼 때 씁니다
├── exercises/             과제 문서
│   ├── README.md              과제 문서를 읽는 법
│   ├── CATALOGUE.md           장마다 있는 과제 목록
│   └── 00-01/                 과제 하나 = 폴더 하나
│       ├── README.md              과제 문서 — 이것만 읽으면 됩니다
│       ├── check.json             채점기가 읽는 규칙
│       ├── solution/ · wrong/     막혔을 때 보는 정답 예시와 흔한 실수 예시
│       └── _verify.txt 같은 _ 로 시작하는 파일   과제를 만든 쪽의 확인 기록(읽지 않아도 됩니다)
└── grader/                채점기
    ├── check.py               채점하는 프로그램
    ├── test_check.py          채점기가 제대로 도는지 스스로 시험하는 파일
    └── testdata/              그 시험에 쓰는 파일
```

★ **practice 폴더의 파일은 고치지 마세요.** 과제는 늘 사본을 만들어서 사본으로 합니다.
채점기는 원본의 지문(파일 내용을 숫자 한 줄로 줄인 값)을 보고, 원본이 바뀌었으면 알려 줍니다.

★ 책에서 5장부터 「부서 관리대장」을 쓸 때는 `부서 관리대장.xlsx` 를, 4부(12~15장)에서는 `부서 관리대장.xlsm` 을 씁니다.
16~18장의 코드 실습은 책에 실린 공개 코드(외부 오픈소스)를 쓰는데, 그 코드는 이 저장소에 싣지 않았습니다.
그 세 장의 과제는 `부서 관리대장.xlsm` 의 매크로나 여러분이 가진 매크로 파일로 하게 짜여 있습니다.

## 채점기를 쓰려면 — 파이썬 확인 한 줄

채점기는 파이썬(Python, 프로그램을 돌리는 도구)으로 돕니다.

**명령 창을 저장소 폴더에서 여는 법.** 파일 탐색기로 저장소 폴더(`README.md` 가 보이는 폴더)를 엽니다.
위쪽 주소 표시줄을 한 번 누르고, 거기 적힌 경로를 지운 뒤 `cmd` 라고 치고 엔터를 누릅니다.
검은 창이 뜨고 맨 앞에 그 폴더 경로가 보이면 됩니다. 아래 명령은 모두 이 창에 칩니다.

먼저 이 한 줄을 쳐 보세요.

```
python --version
```

`Python 3.9` 이상이 나오면 됩니다. 다음 둘 중 하나라면 파이썬이 아직 없는 것입니다.

- 「'python'은(는) 내부 또는 외부 명령 … 이 아닙니다」 같은 글이 나온다
- 아무 글 없이 마이크로소프트 스토어(Microsoft Store) 창이 뜬다

그때는 `python.org` 의 Downloads 에서 파이썬을 내려받아 설치합니다.
★ 설치 첫 화면 아래쪽의 **「Add python.exe to PATH」 칸에 꼭 체크**하고 설치하세요. 이 칸을 빼먹으면 설치하고도 위와 같은 글이 나옵니다.
설치가 끝나면 명령 창을 **닫았다가 다시 열고** `python --version` 을 한 번 더 쳐 봅니다.

그다음 엑셀 파일을 읽는 부품(openpyxl)을 한 번만 설치합니다.

```
python -m pip install openpyxl
```

## 채점기 쓰는 법

저장소 폴더(이 README 가 있는 폴더)에서 이렇게 칩니다.

```
python grader/check.py <과제번호> <내 파일>
```

예를 들어 첫 과제를 끝내고 `00-01_점검.xlsx` 를 만들었다면:

```
python grader/check.py 00-01 00-01_점검.xlsx
```

파일 이름에 띄어쓰기가 있으면 이름 전체를 큰따옴표로 감쌉니다. 따옴표가 없으면 채점기가 이름을 둘로 알아듣습니다.

```
python grader/check.py 08-01 "부서 관리대장_20260921.xlsx"
```

결과는 항목마다 한 줄씩 나옵니다.

| 표시 | 뜻 |
|---|---|
| ✓ | 맞았습니다 |
| ✗ | 틀렸습니다. 바로 아래 줄에 왜 틀렸는지가 나옵니다 |
| ! | 채점할 수 없습니다. 수식은 있는데 계산된 값이 파일에 없습니다 — **엑셀에서 그 파일을 한 번 열고 저장한 뒤** 다시 채점하세요 |
| ? | 과제 쪽 규칙에 문제가 있습니다. 저장소를 최신으로 다시 받아 보세요 |

`!` 가 나오는 까닭: 클로드가 파이썬으로 파일을 저장하면 수식은 들어가도 **계산 결과는 비어 있는 채로** 저장됩니다(책 24.2·25.1).
엑셀로 한 번 열고 저장하면 엑셀이 계산해서 채워 넣습니다. 틀린 것이 아니라 아직 계산이 안 된 것이라 ✗ 로 적지 않습니다.

★ 채점기는 기대값을 되도록 과제 문서에 적어 두지 않고, **practice 폴더의 원본 자료에서 직접 계산**합니다.
예를 들어 「금액 합계」를 볼 때는 원본의 수량과 단가를 행마다 곱해서 더한 값과 댑니다.
정렬 순서처럼 채점기가 아직 계산하지 못하는 것은 숫자를 check.json 에 적어 두었습니다. 그런 과제에는
`_expected.py` 가 있어서, 적어 둔 숫자가 원본에서 따로 계산한 값과 같은지 누구나 돌려 볼 수 있습니다.

스스로 확인하는 과제(manual)는 파일 없이 번호만 치면 확인 목록이 나옵니다.

```
python grader/check.py 00-02
```

## 책의 장과 과제의 관계

이 저장소에는 책의 장마다 혼자 해 볼 과제가 둘 있습니다. 부가 끝날 때마다 종합 과제가 하나 더 있습니다.

| 번호 | 뜻 | 예 |
|---|---|---|
| `NN-01` | 그 장의 기본 과제 | `07-01` = 7장 기본 |
| `NN-02` | 그 장의 응용 과제 | `07-02` = 7장 응용 |
| `PN-01` | N부 종합 과제 — 그 부의 마지막 장 뒤에 합니다 | `P2-01` = 2부 종합 |

| 부 | 장 | 주로 쓰는 파일 |
|---|---|---|
| 0부 준비 | 0~2장 | 이번 달 매출.xlsx |
| 1부 화면부터 만지기 | 3~4장 | 이번 달 매출.xlsx |
| 2부 쓰던 파일 살리기 | 5~8장 | 부서 관리대장.xlsx |
| 3부 수식 열기 | 9~11장 | 이번 달 매출.xlsx |
| 4부 매크로와 VBA | 12~15장 | 부서 관리대장.xlsm · 받은파일 |
| 5부 내 자산 되살리기 | 16~18장 | 부서 관리대장.xlsm · 내 매크로 파일 |
| 6부 사고 막기 | 19~22장 | 부서 관리대장.xlsx |
| 7부 사람 손을 떼기 | 23~25장 | 부서 관리대장.xlsx · 내 작업 폴더 |

과제는 그 장에서 배운 **시킬 말과 확인법**을 여러분 파일에 다시 써 보게 짜여 있습니다.
전체 목록은 [exercises/CATALOGUE.md](exercises/CATALOGUE.md) 에 있습니다. 60개 모두 폴더가 있습니다.
자동 채점(auto)이 51개, 스스로 확인하는 과제(manual)가 9개입니다.

## 채점기가 제대로 도는지 시험하기 (선택)

채점기를 고치거나 과제를 더하는 분만 보면 됩니다.

```
python -m pip install pytest
python -m pytest grader
```

정답 파일은 전부 ✓, 오답 파일은 일부러 틀리게 만든 그 항목만 ✗, 계산값이 없는 파일은 ✗ 가 아니라 ! 가 나오는지를 봅니다.
자동 채점 과제 51개도 모두 돌립니다. 과제마다 `solution/` 의 정답 예시는 전부 ✓, `wrong/` 의 오답 예시는 그 과제의 `_verify.txt` 에 적힌 항목만 ✗ 인지 확인합니다.
