# 25-02 같아도 옮기지 않는 것 — 세지 못한 줄 경고

- **어느 장**: 25장 「25.3 같아도 옮기지 않는 것」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: 25-01 에서 만든 `25-01_대조.xlsx`
- **낼 파일**: `25-02_경고.xlsx`

---

## 왜 하나

25-01 에서 여덟 줄이 전부 같았습니다. 그런데 25.3 은 이렇게 말합니다.
「대조가 답하는 것은 「옮기다 어긋났나」이지 「원래 맞았나」가 아니다.」

부서 표기가 흔들린 줄(「영업 1팀」·「영업1 팀」 같은 것)은 엑셀의 `SUMIF` 도 안 세고, 엑셀과 똑같이 만든 화면도 안 셉니다.
둘이 같게 틀리니 대조는 「같음」이라고 합니다.
이 과제에서 그 줄들을 대조 결과 아래에 **경고로 세워 둡니다.** 숫자로 박지 않고 수식으로 둡니다. 다음 달 자료에서도 따라 세도록.

## 할 일

1. 25-01 결과의 사본을 만듭니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   「25-01_대조.xlsx」를 복사해서 「25-02_경고.xlsx」로 만들어 줘. 이 과제에서는 이 사본만 고쳐 줘.
   ```

2. 세지 못한 줄을 세게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   대조 시트 아래에 경고 두 줄을 넣어 줘.
   A11 에 「세지 못한 행 건수」, B11 에는 대장에서 부서는 적혀 있는데 정산 대상 세 이름과 정확히 같지 않은 줄의 수.
   A12 에 「세지 못한 행 금액」, B12 에는 그 줄들의 금액 합.
   B11·B12 는 숫자가 아니라 수식으로 넣어서, 대장이 바뀌면 따라 바뀌게 해 줘.
   ```

   > [그림 25-02-A] 「같음」 아래에 붙은 세지 못한 행 경고 (촬영 예정)

3. 무엇을 넘기고 무엇을 엑셀에 남길지 표로 적게 합니다. 25.3 ❷ 의 기준 셋을 쓰는, 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   25.3 의 기준 셋(규칙이 숫자로 적히나 · 매달 같은 모양인가 · 보는 사람이 읽기만 하나)으로
   지금 이 파일로 하는 일을 「넘긴다」와 「엑셀에 남긴다」로 갈라 대조 시트 아래에 표로 적어 줘.
   ```

4. 25.3 의 고장 진단 시킬 말을 책 그대로 칩니다.

   ```prompt
   이 화면이 안 뜨거나 숫자가 이상할 때 어디를 볼지 순서로 적어 줘.
   그리고 규칙이 바뀌면 어느 파일을 고쳐야 하는지도 같이 적어 줘.
   ```

5. `25-02_경고.xlsx` 를 **엑셀로 한 번 열고, 저장하고, 닫습니다.** 그리고 채점합니다.

   ```
   python grader/check.py 25-02 25-02_경고.xlsx
   ```

## 확인법 — 25장에서 배운 것

- 「**대조는 이 자리를 못 잡는다.** 둘이 같은 답을 내니까 「같음」으로 나온다.」 — 그래서 경고를 따로 세웁니다.
- 「**엑셀을 지우지 않는다.**」 — 넘기는 것은 «보는 일» 입니다.
- 「규칙이 바뀌면 고칠 곳은 **`rules.json` 한 곳**이다.」 — 고장 진단 순서에 rules.json 이 나오는지 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| A11·A12 의 이름 | 이 과제에서 정한 이름 |
| B11·B12 가 숫자가 아니라 수식이다 | — |
| B11 = 세지 못한 행 건수 | 원본 대장에서 부서는 적혀 있지만 세 이름(영업1팀·영업2팀·영업3팀)과 정확히 같지 않은 줄을 채점기가 센 값 |
| B12 = 세지 못한 행 금액 | 그 줄들의 금액을 채점기가 원본 대장에서 직접 더한 값 |
| practice 의 원본이 그대로다 | 원본 파일의 지문 |

## 정답·오답 예시

- `_verify.txt` — 두 파일을 채점한 출력 원문.
