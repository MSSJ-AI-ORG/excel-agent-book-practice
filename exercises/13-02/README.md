# 13-02 한 번에 하나씩 고치고, 지우는 줄은 주석으로 남기기

- **어느 장**: 13장 「13.2 시트 이름·범위가 바뀌어 깨진 곳 고치기」 · 「13.4 고친 매크로를 옛 결과와 대조하기」
- **응용 과제** · 채점: 자동(auto) — 코드 글 파일을 채점합니다
- **시작 파일**: `practice/부서 관리대장.xlsm` — 원본은 열지 않습니다. 사본에서 합니다.
- **낼 파일**: `월말정리_고침.bas` (고친 「깨진매크로」 모듈을 내보낸 글 파일)

---

## 왜 하나

13-01 에서 월말정리가 멈추는 곳 세 군데를 읽어서 찾았습니다. 없는 시트 「매출대장」, 없는 시트 「백업_0401」을 지우는 줄, 4~19행에 묶인 반복입니다.
이 과제에서는 13.2 대로 **한 번에 하나씩** 고칩니다. 지우는 줄은 지우지 않고 **주석**(앞에 `'` 를 붙여 돌지 않게 막은 줄)으로 남깁니다.
끝으로 13.4 대로 무엇을 고쳤고 어떻게 확인했는지를 코드 맨 위에 적습니다.

## 할 일

1. `practice/부서 관리대장.xlsm` 을 작업 폴더에 `13-02_작업.xlsm` 으로 복사하게 합니다. 원본은 열지 않게 합니다.

2. 13.2 의 첫 시킬 말을 책 그대로 칩니다.

   ```prompt
   월말정리 매크로에서 시트 이름 문제를 고쳐 줘.
   「매출대장」은 「대장」으로, 「백업_0401」은 어떻게 할지 먼저 물어봐 줘.
   ★고치기 전에 원본을 「월말정리_원본」으로 남겨 둬.
   ```

   과제에서 덧붙이는 말:

   ```prompt
   월말정리_원본은 깨진매크로 모듈이 아니라 새 모듈에 넣어 줘. 월말정리_원본은 돌리지 마.
   ```

   원본을 같은 모듈에 두면, 원본에 남은 「매출대장」 줄 때문에 채점기가 고치지 않았다고 봅니다.

3. 「백업_0401」을 어떻게 할지 물어 오면, 13.2 의 시킬 말을 책 그대로 답합니다.

   ```prompt
   백업_0401 을 지우는 줄은 일단 주석 처리해 줘.
   지우는 대신 나중에 결정할 수 있게 남겨 두고, 왜 남겼는지 주석에 적어 줘.
   ```

4. 13.2 의 범위 시킬 말을 책 그대로 칩니다.

   ```prompt
   For i = 4 To 19 을 데이터가 있는 마지막 행까지 돌게 고쳐 줘.
   고친 뒤에 몇 행까지 도는지 알려 줘.
   ```

   대장에는 중간에 빈 행이 하나 있습니다(12행). 몇 행까지 도는지 받은 답을 그냥 넘기지 말고 대장과 대 봅니다.

5. 13.4 의 두 시킬 말을 책 그대로 칩니다.

   ```prompt
   고친 매크로를 돌리기 전에 작업본의 사본을 하나 더 만들어 줘.
   사본에서 돌리고, 원래 작업본과 무엇이 달라졌는지 셀 단위로 비교해 줘.
   ```

   ```prompt
   고친 매크로 맨 위에 주석으로 이렇게 적어 줘 —
   언제 · 무엇이 깨져 있었나 · 무엇을 고쳤나 · 확인은 어떻게 했나.
   ```

   > [그림 13-02-A] 고친 매크로를 사본에서 돌려도 되는지 묻는 화면 (촬영 예정)

6. 사본을 엑셀로 열고 VBA 편집기에서 「깨진매크로」 모듈을 고른 뒤 **[파일] - [파일 내보내기]** 로 `월말정리_고침.bas` 로 저장합니다.

7. 채점합니다.

   ```
   python grader/check.py 13-02 월말정리_고침.bas
   ```

## 확인법 — 13장에서 배운 것

- 「지우는 줄을 만나면 주석 처리부터 한다」 — 매크로를 살리는 것이 목적이지 지우는 것이 목적이 아닙니다.
- 「백업_0401」은 사람이 정한다 — 이 파일에는 「백업_0402」가 있는데, 같은 것인지 다른 날 백업인지 알 수 없습니다.
- 「「확인은 어떻게 했나」를 적는 것」 — 다음 사람이 무엇을 확인해야 하는지가 거기 적혀 있습니다.

## 채점기가 보는 것

채점기는 주석 줄을 빼고 코드를 봅니다(주석으로 남았는지를 보는 항목만 주석 줄을 봅니다).

| 항목 | 무엇을 보나 |
|---|---|
| `Sub 월말정리` 가 있다 | 모듈을 제대로 내보냈나 |
| 없는 시트 이름(「매출대장」·「백업_0401」)을 부르는 줄이 없다 | 원본 코드가 부르는 시트 이름을 원본 파일의 실제 시트 목록과 대 없는 것을 골랐다(`_expected.py`) |
| 주석 아닌 줄에 `.Delete` 가 없다 · `'` 로 막은 `.Delete` 줄이 있다 | 지우는 줄을 지우지 않고 주석으로 남겼나 |
| `For i = 4 To 19` 가 없다 · `End(xlUp)` 이 있다 | 마지막 데이터 행까지 도나 |
| `Sub 월말정리` 바로 위(또는 바로 아래) 주석 덩어리에 「확인」이 들어간 줄이 있다 | 「확인은 어떻게 했나」를 적었나 |

## 여기서 쓴 엑셀 기능

`Sheets()` · `Set` · `For` 범위 · `Cells(Rows.Count, 1).End(xlUp)` · 주석 처리 · [파일 내보내기]
