# 과제 목록 (카탈로그)

이 저장소에는 책의 장마다 혼자 해 볼 과제가 둘 있습니다. `NN-01` 이 기본, `NN-02` 가 응용입니다.
부가 끝날 때마다 종합 과제 `PN-01` 이 하나 더 있습니다. 모두 **60개**입니다(장 26개 × 2 + 부 8개).

과제는 새 기술을 가르치지 않습니다. **그 장에서 배운 시킬 말과 확인법을 여러분 파일에 한 번 더 써 보는 것**입니다.
그래서 과제마다 어느 절에서 왔는지와, 그 절의 확인 문장을 「」 안에 그대로 옮겨 두었습니다.

60개 모두 폴더(`exercises/<번호>/`)가 있습니다. **실제 채점 기준은 각 폴더의 README.md 와 check.json 입니다.**
이 목록은 과제를 설계할 때 쓴 것이라, 폴더를 만들며 바뀐 곳이 있습니다. 특히 ★ 표시한 새 채점 규칙은 아직 채점기에 없어서,
지금 있는 규칙으로 바꿔 짰거나(항목이 달라짐) 스스로 확인하는 과제(manual)로 돌렸습니다(12-02 · 23-01 · 23-02).

## 읽는 법

| 칸 | 뜻 |
|---|---|
| 장·절 | 과제가 다시 써 보게 하는 절 이름과 그 절의 확인 문장 |
| 시작 파일 | practice 폴더의 어느 파일에서 시작하나. **원본은 열지 않고 사본으로 합니다** |
| 낼 파일 | 채점기에 넣을 파일 이름 |
| 할 일 | 순서대로. 「」 안은 책에 실린 시킬 말이고, 과제에서 새로 붙인 말은 ‹› 로 표시했습니다 |
| 채점 | `auto`(채점기) · `manual`(스스로 확인). auto 는 항목마다 **기대값을 원본에서 어떻게 계산하는지** 적었습니다 |

시작 파일 줄임말: **〔매출〕** = `이번 달 매출.xlsx` · **〔대장〕** = `부서 관리대장.xlsx` · **〔대장m〕** = `부서 관리대장.xlsm` · **〔받은파일〕** = `받은파일/` 세 파일

★ 기대값은 되도록 check.json 에 숫자로 적지 않습니다. 채점기가 원본의 **입력 칸**(손으로 적힌 값)에서 계산합니다.
정렬 순서처럼 채점기가 아직 계산하지 못해 숫자를 적어 둔 과제(03-02 · 24-01 · 24-02 · P0-01 등)에는 `_expected.py` 가 있어, 적은 숫자를 원본에서 따로 다시 계산해 맞춰 봅니다.
원본의 수식 칸(〔매출〕 E열, 〔대장〕 정산 시트)은 기대값의 재료로 쓰지 않습니다. 예를 들어 금액은 E열이 아니라 수량×단가로 셉니다.

★ 거의 모든 auto 과제에 두 항목이 붙습니다. 따로 적지 않았습니다.
- **원본 그대로** — `practice_untouched`: 시작 파일의 지문이 처음 받은 그대로인가(「원본은 건드리지 마」가 지켜졌나)
- **계산값 안내** — 수식 칸에 계산값이 없으면 ✗ 가 아니라 「엑셀에서 열고 저장」 안내

- **장·절**: 24.3 「규칙을 코드 밖에 두기」 · 24.4 「값이 천 원 달랐다」 — 「옮길 때는 지금 수식이 하는 대로 옮긴다」 · 「「고쳤다」가 「맞다」가 아니다」 · 「기대값을 규칙 파일에 박아 둔다」
- **시작 파일**: 24-01 의 프로그램 · **낼 파일**: `out/정산.csv`
- **할 일**: 1) 「정산 계산에 쓰는 값들을 rules.json 으로 빼 줘 … 각 값이 원래 엑셀 어디에서 온 것인지 같이 적어 줘.」 2) 「기준 시트의 적용요율 열이 정산 수식에서 쓰이는지 확인해 줘 …」 3) 정산액을 계산해 엑셀 값과 대 본다 — 한 줄이라도 다르면 「정산액 반올림이 엑셀 ROUND 와 같게 동작하도록 고쳐 줘 …」 4) 고친 뒤 다시 대조한다
- **채점**: auto(`csv`)
  - 부서 세 줄의 정산액 = 원본 입력에서 옛 규칙으로 계산하고 `round_excel` 로 반올림한 값(06-01 과 같은 `calc`) — 딱 절반이 나오는 부서에서 파이썬 기본 반올림이면 여기서 ✗ 가 난다
  - 합계 줄 = 세 줄의 합
  - □ rules.json 의 값마다 출처가 적혀 있다 · □ 적용요율 열이 안 쓰인다는 사실이 주석으로 남아 있다
