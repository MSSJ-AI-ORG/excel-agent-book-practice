# 06-01 긴 수식을 단계마다 한 칸씩 풀어 적기

- **어느 장**: 6장 「6.1 긴 수식 한 줄을 단계별로 풀어 읽기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `06-01_풀이.xlsx`

---

## 왜 하나

정산 시트 D3 에는 다섯 단으로 겹친 긴 수식이 들어 있습니다. 6.1 에서는 그 수식을 안쪽부터 한 단계씩 풀어 설명과 값을 받았습니다.

이 과제에서는 받은 단계를 **시트에 한 칸씩, 수식으로** 옮겨 둡니다.
단계마다 값이 칸에 찍히니 [수식 계산] 버튼으로 본 중간값과 댈 수 있고, 손 계산과도 댈 수 있습니다.
그리고 달성했을 때 갈 가지와 미달일 때 갈 가지를 **둘 다** 칸으로 남겨, 조건이 바뀌면 얼마가 되는지 미리 봅니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 복사해서 「06-01_풀이.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「작업본」이라고 하면 이 사본을 가리키는 걸로 해 줘.
   ```

2. 6.1 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   작업본의 정산 시트 D3 수식을 안쪽부터 한 단계씩 풀어서,
   각 단계가 무엇을 하는지 한 줄씩 설명해 줘.
   그리고 각 단계의 결과값도 함께 알려 줘. 파일은 고치지 마.
   ```

3. 받은 단계를 시트에 옮기게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   작업본에 「풀이」 시트를 만들어 줘.
   A2:A10 에 ①~⑨ 를 적고, B2:B10 에는 아래 아홉 단계를 한 칸에 하나씩 «수식으로» 넣어 줘.
   ① 대장에서 부서 이름이 정산!A3 과 정확히 같은 줄의 금액 합
   ② 기준 시트에서 찾아온 그 부서의 목표
   ③ ① 이 ② 이상인가
   ④ 그 부서의 거래 건수
   ⑤ ④ 가 5건 이상이면 성과가산, 아니면 0
   ⑥ ① × 기준요율 + ⑤
   ⑦ ① × 기준요율 × 0.5
   ⑧ ③ 이 맞으면 ⑥, 아니면 ⑦ 을 천 원 단위로 반올림한 값
   ⑨ 정산!D3 의 값
   C열에는 단계마다 하는 일을 한 줄씩 적어 줘. 정산 시트와 다른 시트는 고치지 마.
   ```

4. `06-01_풀이.xlsx` 를 엑셀로 엽니다. 정산!D3 을 누르고 [수식] - [수식 계산]을 눌러 [계산]을 몇 번 누르며, 화면에 뜨는 중간값을 풀이 시트의 ①~③ 과 댑니다.

   > [그림 06-01-A] [수식 계산] 대화상자와 풀이 시트를 나란히 놓은 화면 (촬영 예정)

5. 손으로 한 번 계산해 봅니다. ① × 0.03 × 0.5 를 해서 ⑦ 과 같은지, 그 값을 천 원 단위로 반올림하면 ⑧ 과 같은지. 저장하고 닫습니다.

6. 채점합니다.

   ```
   python grader/check.py 06-01 06-01_풀이.xlsx
   ```

## 확인법 — 6.1 에서 배운 것

- 「손으로 한 번 계산해 보는 것을 건너뛰지 않는다」 — 5번.
- 「값이 아니라 «가지» 를 같이 받은 것이 중요하다」 — ⑥ 과 ⑦ 이 둘 다 칸에 남아 있는지 봅니다. 실제로 도는 것은 하나뿐입니다.
- 「받은 설명의 중간값과 엑셀이 보여 주는 중간값이 다르면, 설명 쪽이 틀린 것이다」 — 4번.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 풀이!B2:B10 이 모두 수식이다(①·②·④·⑧ 은 SUMIF·VLOOKUP·COUNTIF·ROUND 가 들어 있다) | — |
| ① 매출합 · ④ 건수 | 채점기가 원본 대장에서 부서 이름이 정확히 「영업1팀」인 줄을 골라 D열을 더하고 줄 수를 센다 |
| ② 목표 | 채점기가 원본 기준 시트에서 「영업1팀」을 찾아 목표를 읽는다 |
| ③ ~ ⑧ | ①·②·④ 와 원본 이름 정의(기준요율·성과가산)로 채점기가 정산 규칙대로 다시 계산한다. 반올림은 엑셀 `ROUND` 와 같은 방식 |
| ⑨ 정산!D3 의 값 | ⑧ 과 같은 계산 — 정산 수식이 같은 값을 내는지 |
| 정산 시트가 한 칸도 안 바뀌었다 | 원본 정산 시트와 칸마다 댄다(「파일은 고치지 마」) |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

`!` 가 나오면 엑셀로 한 번 열고 저장하지 않은 것입니다. 틀린 것이 아닙니다.

## 스스로 확인할 것

- □ [수식] - [수식 계산]을 눌러 본 중간값(5270000>=6000000 → FALSE)이 풀이 시트의 ①~③ 과 같았다
- □ 5,270,000 × 0.03 × 0.5 = 79,050 → 79,000 을 손으로 한 번 계산해 보았다
