# 13-01 돌리지 않고 읽어서 멈출 자리 찾기

- **어느 장**: 13장 「13.1 어디서 멈추는지 오류 줄 찾기」
- **기본 과제** · 채점: 스스로 확인하는 과제(manual)
- **시작 파일**: `practice/부서 관리대장.xlsm` — 원본은 열지 않습니다. 사본에서 합니다.
- **낼 파일**: 없음

---

## 왜 하나

깨진 매크로를 만나면 일단 돌려 보고 싶어집니다. 13.1 에서 이 책을 만들며 「월말정리」를 밖에서 불렀더니
**엑셀이 응답하지 않았고, 강제로 끄자 파일이 잠겨 다음 작업이 막혔습니다.**
그래서 이 과제는 **한 번도 돌리지 않고** 읽어서 멈출 곳을 찾습니다. 시험은 문장 하나씩만 떼어서 합니다.

## 할 일

1. `practice/부서 관리대장.xlsm` 을 작업 폴더에 복사하게 합니다. 원본은 열지 않게 합니다.

2. 13.1 의 시킬 말을 책 그대로 칩니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   월말정리 매크로를 돌리지 말고 코드만 읽어서,
   이 매크로가 무엇을 하려는 것인지, 그리고 지금 이 파일에서 안 될 만한 곳이 있는지 알려 줘.
   ★실행하지 마.
   ```

3. 코드에 나온 시트 이름과 이 파일의 실제 시트 목록을 나란히 적게 합니다(과제에서 붙인 말입니다).

   ```prompt
   월말정리 코드가 부르는 시트 이름을 전부 적고, 이 파일의 실제 시트 목록을 그 옆에 나란히 적어 줘.
   실제로 없는 이름에 표시해 줘. ★실행하지 마.
   ```

4. 13.1 의 시험 시킬 말을 책 그대로 칩니다.

   ```prompt
   「매출대장」 시트를 잡는 문장 하나만 떼어서, 오류가 나는지 시험해 줘.
   오류가 나면 번호와 설명을 알려 줘. 매크로 전체는 돌리지 마.
   ```

5. 첫 문장이 실패해 `ws` 가 빈 채로 남았을 때, 다음 줄을 만나면 어떤 오류가 나는지도 받습니다(과제에서 붙인 말입니다).

   ```prompt
   Set ws = … 가 실패해서 ws 가 비어 있는 채로 ws.Cells(4, 4).Value = 1 같은 줄을 만나면 어떤 오류가 나는지,
   그 문장만 떼어서 시험해 줘. 매크로 전체는 돌리지 마.
   ```

## 스스로 확인할 것

`python grader/check.py 13-01` 을 치면 아래 목록이 나옵니다.

- □ 시킬 말마다 「실행하지 마」를 붙였고, 월말정리 매크로 전체는 한 번도 돌리지 않았다
- □ 코드가 부르는 시트 이름과 파일의 실제 시트 목록을 나란히 적었고, 실제로 없는 이름 두 개를 찾았다
- □ 문장 하나만 떼어 시험해 받은 오류 번호와, ws 가 빈 채로 다음 줄을 만났을 때 받은 오류 번호가 다르다는 것을 적었다
- □ 화면에 보이는 오류 번호가 원인이 아니라는 것을 한 줄로 설명할 수 있다

## 확인법 — 13장에서 배운 것

- 「깨진 매크로를 만나면 일단 돌려 보고 싶어진다. 돌리지 않는다.」
- 「멈춘 자리가 원인인 자리가 아니다」 — 화면에 뜨는 오류 메시지에는 원인이 된 시트 이름이 안 나올 수 있습니다.
- 「우리가 시트 이름을 바꾼 적이 없다」 — 물려받은 파일에는 만든 사람이 쓰던 시트 이름이 코드에 남아 있습니다.
