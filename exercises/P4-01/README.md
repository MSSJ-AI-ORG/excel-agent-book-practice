## 왜 하나

13-02 에서 월말정리를 살렸습니다. 그런데 14.1 방식으로 «쓰는 곳»을 짚어 보면, 이 매크로는 대장 **F열(비고)**에 「확인」을 덮어씁니다.
F열에는 「특판」 같은 기존 메모가 있습니다. 13.4 가 말한 「매크로는 시킨 것보다 많이 할 수 있다」가 이것입니다.
이 과제에서는 쓰는 곳을 새 G열로 옮기고, 같은 사본에서 두 번 돌려 결과가 쌓이지 않는지 보고, 같은 판정을 수식으로도 만들어 나란히 댑니다.

## 할 일

1. `practice/부서 관리대장.xlsm` 을 작업 폴더에 `P4-01_월말정리.xlsm` 으로 복사하게 합니다. 원본은 열지 않게 합니다.

2. 13-02 처럼 월말정리를 고칩니다 — 「매출대장」 → 「대장」, 백업_0401 을 지우는 줄은 주석, 4~19행 고정 → 마지막 데이터 행까지. 원본은 새 모듈에 「월말정리_원본」으로 남기고 돌리지 않습니다.

3. 14.1 의 시킬 말을 월말정리에 걸어 «쓰는 곳»을 받습니다(책의 시킬 말에서 프로시저 이름만 바꿨습니다).

   ```prompt
   깨진매크로의 월말정리 프로시저를 읽고,
   이 코드가 «읽는 곳»과 «쓰는 곳»을 갈라서 목록으로 만들어 줘.
   시트 이름과 셀 범위까지 적어 줘. 실행하지는 마.
   ```

   쓰는 곳이 대장 F열이라는 답을 받으면, 과제에서 붙인 말로 고칩니다.

   ```prompt
   월말정리가 F열(비고)에 쓰지 말고, G열에 「점검」 열을 새로 만들어 거기에 쓰게 고쳐 줘.
   G3 에 머리글 「점검」을 적고, F열은 한 칸도 바꾸지 마.

4. 13.4 의 두 번 돌리기 시킬 말을 책 그대로 칩니다.

   ```

   > [그림 P4-01-A] 매크로를 돌려도 되는지 묻는 화면 (촬영 예정)

5. 13.4 의 수식 대조 시킬 말을 책 그대로 칩니다.

   ```prompt

   매크로를 돌린 결과와 수식 결과를 나란히 놓고 비교할 수 있게 해 줘.

   과제에서 붙인 말:

   ```

6. 13.4 의 마지막 시킬 말(고친 매크로 맨 위에 언제 · 무엇이 깨져 있었나 · 무엇을 고쳤나 · 확인은 어떻게 했나)도 칩니다.

7. `P4-01_월말정리.xlsm` 을 **엑셀로 한 번 열고, 저장하고, 닫습니다.**(H열 수식의 계산값이 파일에 들어가게 합니다.)

8. 채점합니다.

   ```

   ```

## 확인법 — 4부에서 배운 것

- 「매크로는 시킨 것보다 많이 할 수 있다」 — 바뀌지 말아야 할 셀이 바뀌지 않았나, 시트가 지워지지 않았나를 봅니다.
- 「두 번 돌리면 쌓이는 매크로」 — 「확인」이라고 적는 매크로는 두 번 돌려도 같지만, 값을 더하는 매크로는 두 배가 됩니다.
- 「같은 일을 두 방법으로 한다」 — 매크로와 수식은 만드는 방식이 다르므로, 같은 답이 나오면 믿을 만합니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| G3 = 「점검」 | — |
| G4~G19 = 「확인」 또는 빈칸 | 채점기가 원본 대장 D열 금액을 줄마다 읽어 3,000,000 을 넘으면 「확인」, 아니면 빈칸으로 판정(원래 코드의 조건 그대로) |
| H4~H19 가 줄마다 수식이다 | — |
| 「확인」이 적힌 줄의 H 값이 G 와 같다 | 제출 파일의 G열. 어느 줄인지는 `_expected.py` 가 원본 D열로 센다 |
| F4:F19(비고)·A1:E19 가 원본 그대로 | 원본 칸과 하나씩 댄다 |
| 시트 일곱 개가 다 있다 | 원본의 시트 이름(아무것도 지워지지 않았나) |
| practice 원본이 그대로다 | 원본 파일 지문 |

빈칸이 나와야 하는 줄의 H 값은 채점기가 대지 않습니다. 엑셀은 수식 결과가 빈 글자("")일 때 파일에 빈 값으로 저장하는데, 지금 채점기는 그것을 «계산값이 없다»와 가르지 못하기 때문입니다.
그 줄들은 채점 결과 아래 □ 목록으로 스스로 봅니다.
