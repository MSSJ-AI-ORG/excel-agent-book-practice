# 22-02 멈춤 조건을 시험하고, 「읽어주세요」를 다시 써서 넘기기

- **어느 장**: 22장 「22.2 조건에 걸리면 멈추고 묻게 하기」 · 「22.4 이 규칙을 다음 사람에게 넘기기」
- **응용 과제** · 채점: 스스로 확인하는 과제(manual)
- **시작 파일**: 22-01 에서 만든 `22-01_승인.xlsx` — 시험은 그 사본으로 합니다.
- **낼 파일**: 없음

---

## 왜 하나

22.2 의 멈춤 조건은 「**전부 숫자다.**」 그리고 걸었으면 시험합니다.
「**안 걸려야 하는 것이 걸리면 규칙이 곧 꺼진다.**」

22.4 에서는 전임자의 「읽어주세요」 네 줄 대신 우리가 새로 씁니다.
그리고 처음 보는 사람이라고 치고 그 문서만 읽고 해 보게 합니다. 「**막히는 곳이 그 문서에 빠진 곳이다.**」

이 과제의 결과는 대화에서 멈췄나·안 멈췄나입니다. 파일에 남지 않아서 채점기가 볼 수 없습니다. 아래 확인 목록으로 스스로 봅니다.

## 할 일

1. 시험용 사본을 만듭니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   「22-01_승인.xlsx」를 복사해서 「22-02_시험용.xlsx」로 만들어 줘. 이 과제의 시험은 이 사본에서만 해 줘.
   ```

2. 22.2 의 멈춤 조건 시킬 말을 책 그대로 칩니다. ⑤(0개일 때)를 빼지 않습니다.

   ```prompt
   다음 조건에 하나라도 걸리면 진행하지 말고 멈춰서 물어봐 줘.
   ① 바뀔 셀이 10개를 넘을 때
   ② 지울 행이 3개를 넘을 때
   ③ 합계가 5% 넘게 달라질 때
   ④ 검사기에서 「확인」이 하나라도 뜰 때
   ⑤ 지울 행이 0개일 때
   멈출 때는 어느 조건에 걸렸는지와 그 숫자를 알려 줘.
   ```

3. 22.2 의 양쪽 결과 시킬 말 첫 줄을 책 그대로 칩니다.

   ```prompt
   앞으로 멈출 때는 「진행하면 어떻게 되나」와 「안 하면 어떻게 되나」를 같이 보여 줘.
   ```

4. 멈춤이 걸리는지 시험합니다. 첫 시킬 말은 22.2 에 나온 그대로입니다. 걸려서 멈추면 「아니, 멈춰」라고 답합니다.

   ```prompt
   대장에서 행 다섯 개를 지워 줘.
   ```

   > [그림 22-02-A] 조건 ②에 걸려 멈추고 양쪽 결과를 보여 준 화면 (촬영 예정)

   나머지 두 시험은 22.2 의 시험 표를 이 과제에서 시킬 말로 옮긴 것입니다.

   ```prompt
   대장에서 행 두 개를 지워 줘.
   ```

   ```prompt
   검사기에 「확인」이 뜬 상태로 이 파일을 저장해 줘.
   ```

   세 번째 시험을 하려면 검사기가 있어야 합니다. 22-01 파일에는 검사기가 없으니, 21-02 의 오류를 심은 파일 사본으로 해도 됩니다.

5. 22.2 의 푸는 말 시킬 말을 책 그대로 칩니다. 그다음 「진행」 한 마디만 쳐 보고, 이어서 「진행 — 이유: …」로도 쳐 봅니다.

   ```prompt
   내가 「진행」이라고만 하면 진행하지 말고,
   「진행 — 이유: (이유)」 형식으로 말할 때만 진행해 줘.
   그리고 그 이유를 기록에 남겨 줘.
   ```

6. 22.4 의 「읽어주세요」 시킬 말을 책 그대로 칩니다. ⑤를 빼지 않습니다.

   ```prompt
   「읽어주세요」 시트를 새로 써 줘.
   처음 이 파일을 여는 사람이 알아야 할 것을 순서대로 적어 줘.
   ① 이 파일이 무엇을 하는 파일인지
   ② 어느 시트를 건드리면 안 되는지
   ③ 무엇을 하기 전에 무엇을 해야 하는지
   ④ 이상하면 어느 시트를 보면 되는지
   ⑤ 모르면 누구에게 물으면 되는지
   ```

7. 22.4 의 「한 번 돌려 본다」 시킬 말을 책 그대로 칩니다. 막힌 곳이 나오면 읽어주세요에 더해 적게 합니다.

   ```prompt
   내가 이 파일을 처음 보는 사람이라고 치고, 읽어주세요 시트만 읽고
   이번 달 작업을 처음부터 끝까지 해 봐 줘.
   중간에 막히는 곳이 있으면 어디서 막혔는지 알려 줘.
   ```

8. 채점기로 확인 목록을 띄웁니다.

   ```
   python grader/check.py 22-02
   ```

## 스스로 확인할 것

- □ 멈춤 조건 다섯 줄에 「많이」·「크게」·「이상하면」 같은 말이 없고 전부 숫자다(⑤ 지울 행이 0개일 때도 들어 있다)
- □ 「대장에서 행 다섯 개를 지워 줘.」에서 멈췄다
- □ 행 두 개 지우기는 멈추지 않았다(안 걸려야 하는 것이 안 걸렸다)
- □ 검사기에 「확인」이 뜬 상태로 저장하라고 했을 때 멈췄다
- □ 멈출 때 「진행하면 어떻게 되나」와 「안 하면 어떻게 되나」를 둘 다 받았다
- □ 「진행」 한 마디로는 진행하지 않았고, 「진행 — 이유: …」로 말했을 때만 진행했으며 그 이유가 기록에 남았다
- □ 새 「읽어주세요」에 ⑤ 모르면 물을 사람이 적혀 있다
- □ 「처음 보는 사람이라고 치고」 돌려 본 뒤, 막힌 곳을 읽어주세요에 더해 적었다

## 확인법 — 22장에서 배운 것

- 「**전부 숫자다.** 「많이」·「크게」·「이상하면」은 조건이 아니다.」
- 「**0건도 이상한 값**이다.」
- 「**진행하지 않는 쪽의 결과도 알아야 판단이 된다.**」
- 「**이유를 적게 하는 것이 한 번 더 생각하게 만든다.**」
- 「**막히는 곳이 그 문서에 빠진 곳**이다.」
