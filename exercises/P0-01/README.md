# P0-01 작업 폴더를 세우고 물려받은 파일의 뼈대를 대조하기

- **어느 장**: 0부 종합 — 2장 「2.1 작업 폴더 정하고 엑셀 파일 두기」 · 「2.2 내 시트 읽히고 무엇이 들었는지 설명받기」 · 「2.3 읽기만 하고 고치지 못하게 막아 두기」
- **종합 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 작업 폴더에 **복사**해 둡니다.
- **낼 파일**: `P0-01_뼈대.xlsx` — 시트마다 이름·행 수·수식 칸 수를 적은 새 파일

---

## 왜 하나

0부에서 도구를 깔고(0장), 할 일을 고르고(1장), 작업 폴더를 세우고 파일을 읽히고 잠갔습니다(2장).
이 과제는 그 순서를 한 번에 해 봅니다. 대상은 2부에서 다룰 물려받은 파일, 「부서 관리대장」입니다.

이 파일은 시트가 여러 장이라 2.2 의 표를 시트마다 한 줄씩 만듭니다.
채점기는 여러분이 적은 뼈대를 원본과 줄마다 댑니다.

## 할 일

1. 2.1 의 시킬 말로 작업 폴더를 만듭니다. 책 그대로 칩니다.

   ```prompt
   C:\엑셀실습  폴더를 만들고 거기로 옮겨 줘.
   그 안에 「작업본」과 「_백업」 폴더도 같이 만들어 줘.
   ```

   > [그림 P0-01-A] 만들어진 폴더 구조 (촬영 예정)

2. 저장소의 `practice/부서 관리대장.xlsx` 를 `C:\엑셀실습` 에 **복사**합니다. 옮기지 않습니다.
   이제부터 `C:\엑셀실습` 에서 `claude` 를 실행합니다.

3. 2.2 의 첫 시킬 말을 이 파일에 씁니다. 책의 시킬 말에서 **파일 이름만** 바꿨습니다.

   ```prompt
   부서 관리대장.xlsx 를 열지 말고 구조만 읽어서,
   시트가 몇 장인지, 각 시트에 어떤 열이 있는지, 몇 행인지 알려 줘.
   그리고 수식이 들어 있는 칸이 있으면 어디인지도 알려 줘.
   ```

4. 받은 답을 뼈대 표로 남기게 합니다. ‹과제에서 새로 붙인 시킬 말입니다.›

   ```prompt
   방금 읽은 것을 새 파일 P0-01_뼈대.xlsx 의 「뼈대」 시트에 적어 줘.
   1행은 머리글로 「시트 / 행 수 / 수식 칸 수」, 2행부터 시트 순서대로 한 줄에 한 시트씩.
   행 수는 값이 들어 있는 마지막 줄의 번호로, 중간에 빈 줄이 있어도 빼지 말고 적어 줘.
   수식 칸 수는 그 시트에서 수식이 든 칸의 개수를 숫자로 적어 줘.
   부서 관리대장.xlsx 는 고치지 마.
   ```

5. **받은 뼈대를 화면과 대조합니다.** 복사해 둔 `부서 관리대장.xlsx` 를 엑셀로 열고, 적어도 두 시트는 직접 봅니다.
   시트 탭의 순서, 마지막 줄 번호, 수식이 든 칸을 뼈대의 그 줄과 댑니다. 중간에 빈 줄이 있는 시트도 봅니다.

6. 2.3 처럼 복사본을 잠갔다가 풉니다. 책의 시킬 말에서 **파일 이름만** 바꿨습니다.

   ```prompt
   부서 관리대장.xlsx 에 읽기 전용 속성을 걸어 줘.
   그리고 그 상태에서 파일을 읽는 것은 되는지 확인해 줘.
   ```

   ```prompt
   읽기 전용을 풀어 줘. 풀기 전에 지금 이 파일이 정말 잠겨 있는지 먼저 확인해 줘.
   ```

7. 채점합니다. 저장소 폴더에서 뼈대 파일의 경로를 적습니다.

   ```
   python grader/check.py P0-01 C:\엑셀실습\P0-01_뼈대.xlsx
   ```

## 확인법 — 0부에서 배운 것

- 「원본을 옮기지 말고 복사한다」(2.1)
- 「첫 응답은 반드시 화면과 대조한다」(2.2) — 5번이 그 대조입니다.
- 「풀기 전에 지금 이 파일이 정말 잠겨 있는지 먼저 확인해 줘」(2.3)

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「뼈대」 시트가 있다 | — |
| A2:A8 시트 이름이 원본과 같은 순서로 있다 | 원본 파일의 시트 이름 목록 |
| B2:B8 시트마다 행 수 | 원본 시트마다 값이 있는 마지막 줄 번호 |
| C2:C8 시트마다 수식 칸 수 | 원본 시트마다 수식이 든 칸의 수 |
| A9 는 비어 있다 | 없는 시트가 끼어들지 않았는지 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

★ 채점기에 시트 이름·마지막 줄·수식 칸을 바로 세는 기능이 아직 없어, 이 과제의 기대값은 `check.json` 에 값으로 적어 두었습니다.
그 값이 원본에서 나온 것인지는 `_expected.py` 가 원본을 따로 세어 확인합니다(`python -X utf8 exercises/P0-01/_expected.py`).

폴더 셋과 잠금 확인은 채점기가 보지 않습니다. 결과 아래 「스스로 확인하세요」에 나옵니다.
