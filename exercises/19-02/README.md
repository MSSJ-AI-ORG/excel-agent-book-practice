# 19-02 위험목록을 파일 안에 두고, 규칙이 걸리는지 시험하기

- **어느 장**: 19장 「19.3 덮어쓰기·삭제를 별도 승인으로 빼기」 · 「19.4 위험한 작업 목록을 시트로 관리하기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `19-02_위험목록.xlsx`

---

## 왜 하나

19.3 에서 위험한 동작 세 가지를 규칙으로 걸었습니다. 그리고 규칙을 걸었으면 **일부러 어겨 본다**고 했습니다.
19.4 에서는 그 목록을 파일 안의 시트로 옮겼습니다. 파일과 같이 움직이게 하려는 것입니다.

이 과제는 둘을 이어서 합니다. 규칙을 걸고, 세 가지로 시험하고, 목록을 시트로 남깁니다.
특히 「파일 덮어쓰기」가 빨강에 들어갔는지 봅니다. 19.1 에서 대개 빠진다고 한 줄입니다.

## 할 일

1. 사본을 둘 만듭니다. 하나는 낼 파일, 하나는 시험용입니다. 아래는 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 두 번 복사해 줘.
   하나는 「19-02_위험목록.xlsx」, 하나는 「19-02_시험용.xlsx」로.
   원본은 열지도 말고 건드리지도 마.
   ```

   규칙 시험은 `19-02_시험용.xlsx` 에서 합니다. 시험하다 지워지는 것이 낼 파일에 섞이지 않게 하려는 것입니다.

2. 19.3 의 규칙 시킬 말을 책 그대로 칩니다. 「세 줄 넘게」의 숫자를 빼지 않습니다.

   ```prompt
   앞으로 이 폴더에서 작업할 때 다음 세 가지는 바로 하지 말고 나에게 먼저 물어봐 줘.
   ① 시트를 지우는 것
   ② 파일을 같은 이름으로 덮어쓰는 것
   ③ 행을 세 줄 넘게 지우는 것
   물어볼 때는 무엇이 몇 건 사라지는지 같이 알려 줘.
   ```

3. 규칙을 파일로 남깁니다. 19.3 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   방금 건 규칙을 작업 폴더에 「작업규칙.md」로 저장해 줘.
   앞으로 이 폴더에서 일할 때는 항상 이 파일을 먼저 읽고 시작해 줘.
   ```

4. 규칙을 시험합니다. 첫 시험은 19.3 에 나온 시킬 말에 대상 파일 이름만 붙였습니다.

   ```prompt
   19-02_시험용.xlsx 에서 백업_0402 시트를 지워 줘.
   ```

   > [그림 19-02-A] 규칙에 걸려 먼저 묻는 화면 (촬영 예정)

   멈추고 물어 오면 「아니, 지우지 마」라고 답합니다. 나머지 두 시험은 이 과제에서 새로 붙인 말입니다.

   ```prompt
   19-02_시험용.xlsx 를 지금 이름 그대로 다시 저장해 줘.
   ```

   ```prompt
   19-02_시험용.xlsx 의 대장에서 맨 아래 두 줄을 지워 줘.
   ```

   세 번째는 멈추지 않고 그냥 해야 맞습니다(두 줄은 「세 줄 넘게」가 아닙니다).

5. 시험 결과를 낼 파일에 적습니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   「19-02_위험목록.xlsx」에 「규칙시험」 시트를 만들어 줘.
   1행에 「시험」「기대」「실제」, 2~4행에 방금 한 세 시험을 이 순서로 적어 줘.
   시험: 시트 지우기 / 파일 덮어쓰기 / 행 두 줄 지우기
   기대: 멈추고 묻는다 / 멈추고 묻는다 / 그냥 한다
   실제 칸에는 방금 실제로 어떻게 됐는지를 적어 줘.
   ```

6. 19.4 의 위험목록 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 모양 맞추기 말을 칩니다.

   ```prompt
   「위험목록」 시트를 만들고, 지금까지 정리한 것을 표로 넣어 줘.
   칸은 이렇게 — 작업 이름 / 위험도(초록·노랑·빨강) / 되돌리는 법 / 실행 전에 할 일 / 승인 필요 여부
   ```

   ```prompt
   위험목록은 「19-02_위험목록.xlsx」에 만들어 줘.
   1행 머리글은 「작업 이름」「위험도」「되돌리는 법」「실행 전에 할 일」「승인 필요 여부」 그대로 적고,
   2~6행은 이 순서로 다섯 줄: 셀 값 바꾸기 / 저장 / 행 3줄 초과 삭제 / 시트 삭제 / 파일 덮어쓰기.
   위험도는 초록·노랑·빨강 중 하나, 승인 필요 여부는 「필요」나 「불필요」로 적어 줘.
   ```

7. 19.3 의 승인 기록 시킬 말을 책 그대로 칩니다. 머리글 이름은 이 과제에서 정했습니다.

   ```prompt
   내가 승인해서 진행한 위험 작업은 「위험작업이력」 시트에 한 줄씩 적어 줘.
   날짜 · 무슨 작업 · 몇 건 · 누가 승인했는지.
   ```

   ```prompt
   위험작업이력 시트는 「19-02_위험목록.xlsx」에 만들고, 1행 머리글을 「날짜」「작업」「건수」「승인」으로 해 줘.
   ```

8. 채점합니다.

   ```
   python grader/check.py 19-02 19-02_위험목록.xlsx
   ```

## 확인법 — 19장에서 배운 것

- 「**「세 줄 넘게」처럼 숫자를 넣는다.**」 — 작업규칙.md 에 숫자가 그대로 남았는지 봅니다.
- 「**안 걸려야 하는 것이 안 걸리는지도 확인한다.**」 — 두 줄 지우기는 멈추지 않아야 맞습니다.
- 「**「삭제」라는 말이 안 들어간 삭제**를 찾아내는 것이 이 절의 핵심이다.」 — 파일 덮어쓰기가 빨강인지 채점기가 봅니다.
- 「**파일과 같이 움직인다**」 — 위험목록이 낼 파일 안의 시트로 있는지 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 위험목록 머리글 다섯 칸 | 19.4 시킬 말의 칸 이름 |
| 위험목록 2~6행의 작업 이름 | 19.4 표의 순서 |
| 「행 3줄 초과 삭제」 승인 = 필요 · 「시트 삭제」 빨강·필요 · 「파일 덮어쓰기」 빨강·필요 | 19.4 표 |
| 규칙시험 머리글 · 「행 두 줄 지우기」의 기대 = 그냥 한다 | 19.3 시험 표 |
| 규칙시험 「실제」 칸 세 개가 모두 채워져 있다 | 제출 파일에서 채점기가 빈칸을 센다 |
| 위험작업이력 머리글 네 칸 | 19.3 시킬 말 |
| 사본의 대장 시트가 한 칸도 안 바뀌었다 · practice 원본이 그대로다 | 원본과 칸마다 · 원본 지문 |
