# 01-01 내 업무 목록을 적고 반복과 판단으로 가르기

- **어느 장**: 1장 「1.1 내가 매일 하는 엑셀 일을 목록으로 적기」 · 「1.2 손으로 반복하는 일만 골라내기」
- **기본 과제** · 채점: 스스로 확인(manual)
- **시작 파일**: 없음 — 여러분 컴퓨터의 엑셀 파일에서 시작합니다
- **낼 파일**: 없음 — 업무 목록 파일을 작업 폴더에 남겨 둡니다(22장에서 다시 씁니다)

---

## 왜 하나

무엇을 자동화할지 고르려면 지금 무슨 일을 하고 있는지부터 적어야 합니다.
1.1 은 목록을 적고, 1.2 는 그 목록을 「반복」과 「판단」으로 갈랐습니다.
이 과제는 그 일을 여러분 업무로 한 번 해 봅니다.

## 할 일

1. **목록을 적습니다.** 1.1 처럼 세 칸으로 적습니다. 클로드 없이 적습니다.

   | 언제 | 무슨 일 | 얼마나 걸리나 |
   |---|---|---|
   | (예: 매달 1일) | (예: 지난달 매출 파일에서 부서별 합계 내기) | (예: 40분) |

   「얼마나 걸리나」를 빼지 않습니다. 나중에 이 숫자가 판단 근거가 됩니다.

2. **잘 안 떠오르면** 최근 파일 목록을 받아 봅니다. 1.1 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   최근 한 달 동안 수정한 엑셀 파일을 찾아서,
   파일 이름과 마지막으로 고친 날짜를 목록으로 만들어 줘.
   파일 내용은 열지 말고 이름과 날짜만.
   ```

   > [그림 01-01-A] 최근 수정한 엑셀 파일 목록을 받은 화면 (촬영 예정)

3. 목록을 파일로 저장한 뒤, **반복과 판단으로 가르게** 합니다. 1.2 의 시킬 말을 책 그대로 칩니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   방금 만든 업무 목록을 열어서, 각 항목을 「반복」과 「판단」으로 나눠 줘.
   섞여 있는 항목은 반복되는 부분과 판단이 필요한 부분을 갈라서 적어 줘.
   ★내가 적지 않은 일을 새로 만들어 넣지는 마.
   ```

4. **돌려받은 목록의 줄 수를 셉니다.** 내가 적은 줄 수와 같아야 합니다. 늘었으면 내가 적지 않은 일이 끼어든 것입니다.

5. **먼저 할 순서를 매기게** 합니다. 1.2 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   갈라 놓은 목록에 먼저 할 순서를 매겨 줘.
   자주 하는 일 · 오래 걸리는 일 · 틀려도 티가 안 나는 일을 앞에 두고, 왜 그 순서인지 한 줄씩 적어 줘.
   ```

   > [그림 01-01-B] 순서가 매겨진 목록을 받은 화면 (촬영 예정)

## 확인법 — 1장에서 배운 것

- 「「얼마나 걸리나」를 꼭 적는다」
- 「목록이 커지면 아무것도 시작 못 한다」 — 그래서 3번에 「내가 적지 않은 일을 새로 만들어 넣지는 마」를 붙였고, 4번에서 줄 수를 셉니다.
- 「틀려도 티가 안 나는 일을 먼저 한다」 — 5번에서 받은 순서가 그렇게 돼 있는지 봅니다.

## 채점

스스로 확인하는 과제입니다. 아래 명령을 치면 확인 목록이 나옵니다.

```
python grader/check.py 01-01
```

- □ 모든 줄에 「언제 / 무슨 일 / 얼마나 걸리나」 세 칸이 다 있다
- □ 돌려받은 목록의 줄 수가 내가 적은 줄 수와 같다
- □ 섞여 있는 일은 반복되는 부분과 판단이 필요한 부분이 갈라져 있다
- □ 「틀려도 티가 안 나는 일」이 앞쪽에 있고, 순서마다 이유가 한 줄씩 붙어 있다
- □ 업무 목록을 파일로 작업 폴더에 남겨 두었다
