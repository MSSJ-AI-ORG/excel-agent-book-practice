# P7-01 손을 떼고, 1장의 목록을 다시 펴 보기

- **어느 장**: 7부 종합 — 23장 「장 닫기」 · 25장 「장 닫기 — 그리고 이 책의 마지막」
- **7부 종합 과제** · 채점: 스스로 확인하는 과제(manual)
- **시작 파일**: 내 작업 폴더 전체
- **낼 파일**: 없음

---

## 왜 하나

25장은 이렇게 끝납니다. 「**그 파일은 그대로 둡니다. 손만 뗍니다.**」
그리고 「**1장에서 적었던 목록을 다시 펴 보면 좋겠다.**」고 합니다.

이 과제는 책의 마지막 과제입니다. 7부에서 만든 것을 한 문서로 묶고, 한 번씩 돌려 보고, 1장의 목록을 다시 펴 봅니다.
결과는 여러분 폴더와 업무에 따라 다르므로 스스로 확인합니다.

## 할 일

1. 23장 장 닫기의 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금까지 만든 목록·순서표·손일 갈림을 한 문서로 묶어 줘.
   23_업무구조.md 로 저장하고, 맨 위에 「이 폴더가 하는 일」을 세 줄로 적어 줘.
   각 장에서 무엇이 왔는지도 적어 둬.
   ```

2. 24장의 화면과 25장의 대조기를 이번 달 자료로 한 번씩 돌립니다(24-02 · 25-01 과 같은 순서).
   돌린 뒤 원본 지문이 그대로인지, 대조가 여덟 줄 모두 「같음」인지 봅니다.

3. 01-01 에서 적은 업무 목록을 다시 엽니다. 줄마다 셋 중 하나를 적게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   01-01 에서 만든 내 업무 목록을 열어서, 줄마다 「아직 손으로 한다 / 도구가 한다 / 사람이 판단한다」 중 하나를 적어 줘.
   도구가 한다고 적은 줄에는 어느 도구(파일 이름)가 하는지도 같이 적어 줘.
   그리고 「아직 손으로 한다」가 몇 줄인지 세어 줘.
   ```

4. 25장 「이 책에서 가장 많이 나온 문장」 다섯 개가 내 폴더 어디에 걸려 있는지 하나씩 짚습니다.

   - 「했습니다」라는 답을 확인으로 쓰지 않는다
   - 일부러 틀리게 만들어 검사가 잡는지 본다
   - 찾는 것과 고치는 것을 나눈다
   - 상태 표시가 아니라 실물로 판정한다
   - 기준을 먼저 잡아야 비교가 된다

   문장마다 「이 파일의 이 시트(또는 이 검사)」를 한 줄씩 짝지어 `23_업무구조.md` 끝에 적어 둡니다.

5. 채점기로 확인 목록을 띄웁니다.

   ```
   python grader/check.py P7-01
   ```

## 스스로 확인할 것

- □ 23_업무구조.md 맨 위에 「이 폴더가 하는 일」 세 줄이 있고, 각 장에서 무엇이 왔는지 적혀 있다
- □ 24장 화면은 AI 를 부르지 않고, 원본을 고치지 않고, 돌 때마다 엑셀 값과 스스로 댄다
- □ 이번 달 자료로 24장 화면과 25장 대조기를 한 번씩 돌렸다
- □ 사람이 손대는 곳이 세 군데 이하이고, 셋 다 판단하는 일이다
- □ 01-01 에서 적은 업무 목록의 줄마다 「아직 손으로 한다 / 도구가 한다 / 사람이 판단한다」를 적었다
- □ 1장 목록에서 아직 손으로 하는 일이 몇 개 남았는지 셌다
- □ 25장 「이 책에서 가장 많이 나온 문장」 다섯 개마다 「이 파일의 이 시트(또는 이 검사)」를 짝지었다

## 확인법 — 7부에서 배운 것

- 「**앞의 스물세 장이 여기서 한 문장이 된다.**」(23장 장 닫기)
- 「이 화면은 **엑셀과 같은 값**을 낸다. 그런데 「같다」가 「맞다」는 아니다.」(24장 장 닫기)
- 「**그것이 맞게 돌고 있다는 것을 당신이 확인할 수 있다.**」(25장 마지막)

## 채점기가 이 과제를 못 보는 이유

1장의 업무 목록과 여러분 폴더의 모양은 사람마다 다릅니다. 기대값을 미리 가질 수 없어 스스로 확인하는 과제로 두었습니다.

## 여기서 쓴 엑셀 기능

없다 — 앞 장에서 만든 것을 다시 돌리고 목록을 다시 읽습니다.
