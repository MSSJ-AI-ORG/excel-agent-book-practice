# 17-02 규칙 문서·용어 사전·CLAUDE.md 다섯 줄

- **어느 장**: 17장 「17.2 이름 짓는 규칙·주석 방식 적어 두기」 · 「17.3 우리 부서에서만 쓰는 용어 사전 만들기」 · 「17.4 규칙 문서를 클로드가 항상 읽게 걸기」
- **응용 과제** · 채점: 스스로 확인하는 과제(manual)
- **시작 파일**: 17-01 에서 센 결과 · `practice/부서 관리대장.xlsx` (용어를 뽑을 때 — 원본은 열지 않고 사본에서)
- **낼 파일**: 없음 (작업 폴더에 `코드규칙.md` · `용어사전.md` · `CLAUDE.md` 가 생깁니다)

---

## 왜 하나

센 것을 문서로 만들고, 그 문서를 클로드가 작업할 때마다 읽게 겁니다.
이 과제의 요점은 세 가지 «비워 두기·짐작하지 않기·줄이기»입니다. 「앞으로 어떻게 할까」는 사람이 채우고,
용어의 뜻은 클로드가 짐작해 채우지 않게 하고, CLAUDE.md(클로드 코드가 작업을 시작할 때 먼저 읽는 파일)에는 다섯 줄만 직접 적습니다.

## 할 일

1. 17.2 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   방금 센 결과를 「코드규칙.md」로 정리해 줘.
   각 항목에 ① 지금 어떻게 돼 있나(숫자와 함께) ② 앞으로 어떻게 할까 를 나눠서 적어 줘.
   ②는 비워 두고, 내가 채울 수 있게 해 줘.
   ```

   ②를 **직접** 채웁니다. 그리고 「기존 코드는 안 고침」을 적습니다.

2. 17.2 의 확인 시킬 말을 책 그대로 칩니다.

   ```prompt
   방금 정한 규칙 중에 지키기 어려워 보이는 것이 있으면 알려 줘.
   그리고 각 규칙을 지켰는지 기계로 확인할 수 있는지도 알려 줘.
   ```

3. 17.3 의 시킬 말을 책 그대로 칩니다. 대상은 `practice/부서 관리대장.xlsx` 의 사본입니다.

   ```prompt
   대장·기준·정산 시트에 나오는 열 이름과 값들을 전부 뽑아서,
   「이 말이 무슨 뜻인지 내가 설명해야 하는 것」을 골라 줘.
   ★뜻을 짐작해서 채우지 말고, 물어볼 목록만 만들어 줘.
   ```

   ```prompt
   수식과 코드에 직접 박힌 숫자를 전부 찾아서,
   각 숫자가 무엇을 뜻하는지 물어볼 목록을 만들어 줘.
   ```

   뜻은 **내가** 적습니다. 그리고 17.3 대로 두 군데에 둡니다.

   ```prompt
   용어 사전과 숫자 사전을 「용어」 시트로 만들어서 파일 안에 넣어 줘.
   그리고 「용어사전.md」로도 작업 폴더에 저장해 줘.
   ```

4. 17.4 의 시킬 말입니다. 아직 만들지 않은 문서(작업규칙.md 같은 것)는 목록에서 빼고 칩니다.

   ```prompt
   작업 폴더에 「CLAUDE.md」 파일을 만들고, 지금까지 만든 문서들을 거기서 가리키게 해 줘.
   · 코드규칙.md
   · 용어사전.md
   · 작업규칙.md
   · 월간작업.md
   · 복구절차.md
   각 문서가 무엇인지 한 줄씩 적고, 언제 읽어야 하는지도 적어 줘.
   ```

   ```prompt
   CLAUDE.md 에 직접 적을 것은 다섯 줄 이내로 해 줘.
   나머지는 「~할 때는 ~문서를 읽어라」 형식으로 가리키기만 해 줘.
   ```

5. 클로드 코드를 새로 시작하고, 17.4 의 확인 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금 CLAUDE.md 에 뭐라고 적혀 있는지 말해 줘.
   그리고 3번 규칙에 걸리는 작업을 하나 예로 들어 줘.
   ```

## 스스로 확인할 것

`python grader/check.py 17-02` 를 치면 아래 목록이 나옵니다.

- □ 코드규칙.md 의 「앞으로」 칸은 내가 채웠고, 「기존 코드는 안 고침」이 적혀 있다
- □ 규칙마다 「기계로 확인되나」가 표시돼 있다
- □ 용어 사전의 뜻 칸을 클로드가 짐작해 채우지 않았다(정기·신규·특판·성과가산·기준요율, 숫자 0.5·4·-3 포함 — 뜻은 내가 적었다)
- □ CLAUDE.md 에 직접 적은 줄이 다섯 줄 이내이고, 나머지 문서는 «언제 읽을지»만 가리킨다
- □ 「읽었습니다」라는 답이 아니라, CLAUDE.md 에 무엇이 적혀 있는지 내용을 말하게 해서 확인했다

## 확인법 — 17장에서 배운 것

- 「②를 비워 두게 하는 것」 — 「앞으로 어떻게 할까」는 판단이고, 그건 사람이 정합니다.
- 「「짐작해서 채우지 마」」 — 그럴듯한 뜻이 우리 부서의 뜻과 다르면 결과가 조용히 틀립니다.
- 「읽었다는 답이 아니라 내용을 말하게 한다」
