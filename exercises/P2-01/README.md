# P2-01 물려받은 파일을 옮기지 않고 한 벌 살리기

- **어느 장**: 2부 종합 — 5장 「5.4 아무도 안 쓰는 시트·열 찾아내기」 · 7장 · 8장
- **2부 종합 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 작업본을 만들게 합니다.
- **낼 파일**: `P2-01_2부종합.xlsx`

---

## 왜 하나

2부 네 장에서 한 일을 한 파일에 차례대로 해 봅니다. **물려받은 파일을 옮기지 않고, 읽고, 고치고, 그 위에 얹는 것.**

순서가 중요합니다. 찾는 것과 고치는 것을 나누고, 고치는 것과 지우는 것을 또 나눕니다.
그리고 고치기 전에 기준값을 먼저 적어 둡니다. 이 과제는 앞의 과제(05-01~08-02)를 한 줄로 이어 붙인 것이라, 막히면 그 과제의 README 를 펴 봅니다.

## 할 일

1. **작업본** — 저장소 폴더에서 `claude` 를 실행하고 작업본을 만들게 합니다(8.1). 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 복사해서 「P2-01_2부종합.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「작업본」이나 「대장」이라고 하면 이 사본을 가리키는 걸로 해 줘.
   ```

2. **안 쓰는 시트 찾기** — 5.4 의 시킬 말 둘을 책 그대로 칩니다. 이어서 결과를 둘 자리를 이 과제에서 새로 붙인 말로 정해 줍니다.

   ```prompt
   어느 시트에서도 참조되지 않고 수식도 없는 시트를 찾아 줘.
   ★지우지 말고 목록만 만들어 줘.
   각 항목마다 왜 안 쓰인다고 봤는지 근거를 한 줄씩 적어 줘.
   ```

   ```prompt
   각 후보마다 다음을 함께 확인해 줘.
   ① 차트가 그 시트의 값을 쓰고 있는가
   ② 그 시트에 사람이 읽을 글이 적혀 있는가
   ③ 시트 이름이 다른 시트 어디엔가 글자로 적혀 있는가
   확인해도 판단이 안 서는 것은 「모름」으로 남겨 줘.
   ```

   ```prompt
   이 결과를 작업본의 새 시트 「정리후보」에 남겨 줘.
   A1:E1 에 「시트 / 판정 / ① 차트 / ② 사람이 읽을 글 / ③ 이름이 글자로 적힌 곳」을 적고,
   2행부터 후보를 시트 탭 차례로 한 줄에 하나씩 적어 줘. 판정은 「쓴다」·「안 씀」·「모름」 가운데 하나로.
   시트는 하나도 지우지 마.
   ```

3. **정리 전 기준값** — 07-01 의 2번(7.4 「정리 전」 시킬 말과 적을 자리)을 그대로 합니다. 반드시 4~6번보다 먼저 합니다.

4. **제목 병합** — 07-02 의 2·3번(7.1 시킬 말 두 개, 셋째 줄 빼고)을 그대로 합니다.

5. **글자 날짜** — 07-02 의 4·5번(7.2 시킬 말 넷과 「날짜검산」 시트)을 그대로 합니다.

6. **부서 표기** — 07-01 의 3·4번(7.3 시킬 말 둘)을 그대로 합니다.

7. **검산표** — 07-01 의 5번(7.4 시킬 말 둘과 「검산」 시트 자리)을 합니다. 이번에는 고친 것이 세 가지이므로 2~4행에 한 줄씩 적힙니다.

8. **검토 열** — 08-01 의 5번(8.2 시킬 말)을 그대로 합니다.

9. **표로 바꾸기** — 8.4 의 시킬 말을 칩니다. 이 과제에서는 G열 「검토」까지 표에 들어가도 됩니다.

   ```prompt
   대장의 데이터 구간(3행 머리글부터)을 표로 바꿔 줘. 표 이름은 「대장표」로 해 줘.
   바꾼 뒤에 정산 값이 달라지는지 확인해서 알려 줘.
   ```

   그다음 20행 시험을 합니다. 이 과제에서 새로 붙인 시킬 말입니다. **시험한 줄은 지웁니다** — 돌려놓는 것까지가 시험입니다(11.2).

   ```prompt
   대장 20행에 일자 「2026-06-04」, 부서 「영업1팀」, 구분 「신규」, 금액 2000000 인 거래를 한 줄 넣고,
   표가 20행까지 넓어지는지, 정산!B3 의 값과 수식이 어떻게 바뀌는지 알려 줘.
   확인한 뒤에는 그 줄을 표에서 지워 줘.
   ```

10. `P2-01_2부종합.xlsx` 를 엑셀로 한 번 열고 저장한 뒤 채점합니다.

    ```
    python grader/check.py P2-01 P2-01_2부종합.xlsx
    ```

## 확인법 — 2부에서 배운 것

- 「「참조되지 않는다」는 「안 쓴다」가 아니다」 — 후보 넷 가운데 셋은 사람이 쓰는 시트입니다(차트·사람이 읽는 표·안내 글).
- 「「모름」 칸을 만들어 준다」 — 백업_0402 는 셋을 다 확인해도 「모름」입니다. **그리고 지우지 않습니다.**
- 「끝난 뒤의 모습을 미리 적어 두고 거기에 못 닿으면 멈추게 한다」 — 부서 표기는 세 가지여야 합니다.
- 「표로 만드는 것이 수식을 고치는 것보다 낫다」 — 9번에서 정산!B3 수식이 $B$20 으로 늘었다가, 줄을 지우면 $B$19 로 돌아오는지 봅니다.

## 스스로 확인할 것

- □ 정리후보 시트의 월별·담당자·읽어주세요 줄에 「왜 쓴다고 봤는지」 근거가 적혀 있다(차트·사람이 읽는 표·안내 글)
