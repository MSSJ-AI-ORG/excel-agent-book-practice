- **어느 장**: 12장 「12.2 기록된 코드를 클로드에게 해설받기」 · 「12.3 쓸데없이 기록된 줄 걷어내기」
- **기본 과제** · 채점: 자동(auto) — 코드 글 파일을 채점합니다
- **시작 파일**: `practice/부서 관리대장.xlsm` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 해서 사본에서 합니다.
- **낼 파일**: `매크로1_정리.bas` (정리한 「기록매크로」 모듈을 내보낸 글 파일)

## 왜 하나

12.2 에서 본 매크로1 은 한 일이 세 가지(머리글 굵게·색, 금액 표시 형식, 틀 고정)인데 코드가 27줄이었습니다.
기록기는 사람이 클릭한 순서를 그대로 적기 때문입니다.
이 과제에서는 12.3 순서대로 **지우기 전에 고르고, 원본을 남기고, 지운 뒤 같은 일을 하는지 사본 두 개로 대 봅니다.**

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고, 먼저 사본을 만들게 합니다(이 줄은 과제에서 붙인 말입니다).

   ```prompt
   practice 폴더의 「부서 관리대장.xlsm」을 이 폴더에 「12-01_작업.xlsm」으로 복사해 줘. 원본은 열지도 말고 건드리지도 마.
   이제부터 사본에서만 작업해 줘.
   ```

2. 12.2 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   이 매크로 코드를 한 줄씩 설명해 줘.
   각 줄이 무엇을 하는지, 그리고 그 줄이 «내가 한 동작» 중 무엇에 해당하는지 짝지어 줘.
   ```

3. 12.3 의 첫 시킬 말을 책 그대로 칩니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   이 코드에서 지워도 결과가 같은 줄을 골라 줘.
   각 줄마다 왜 지워도 되는지 이유를 적어 줘.
   ★지우지는 말고 목록만 만들어 줘.
   ```

4. 12.3 의 두 번째 시킬 말을 책 그대로 치고, 과제에서 한 줄을 덧붙입니다.

   ```prompt
   방금 고른 줄을 지우고, 남은 코드가 같은 일을 하도록 다시 써 줘.
   ★고치기 전에 원래 코드를 「매크로1_원본」이라는 이름으로 복사해 둬.
   ```

   과제에서 덧붙이는 말:

   ```prompt
   매크로1_원본은 「기록매크로」 모듈이 아니라 새 모듈에 넣어 줘. 기록매크로 모듈에는 정리한 매크로1 만 남겨 줘.
   ```

   원본을 같은 모듈에 두면, 원본에 남은 `.Select` 줄 때문에 채점기가 정리가 덜 됐다고 봅니다.

5. 12.3 의 대조 시킬 말을 책 그대로 칩니다.

   ```prompt
   매크로1_원본 과 정리한 매크로1 을 각각 새 사본에서 돌리고,
   결과 파일의 서식이 같은지 비교해 줘.
   다른 곳이 있으면 어느 셀인지 알려 줘.
   ```

   > [그림 12-01-A] 매크로를 돌려도 되는지 묻는 화면 (촬영 예정)

6. 정리한 모듈을 글 파일로 내보냅니다. 사본을 엑셀로 열고 VBA 편집기에서 「기록매크로」 모듈을 고른 뒤
   **[파일] - [파일 내보내기]** 로 `매크로1_정리.bas` 라는 이름으로 저장합니다.

7. 채점합니다.

   ```
   python grader/check.py 12-01 매크로1_정리.bas
   ```

## 확인법 — 12장에서 배운 것

- 「코드에서는 고를 필요가 없다」 — `Range("A3:F3").Select` 다음 `Selection.Font.Bold = True` 는 `Range("A3:F3").Font.Bold = True` 한 줄이면 됩니다.
- 「지우기 전에 고르는 것」 — 3번에서 목록만 받고, 지우는 것은 4번에서 합니다.
- 「「각각 새 사본에서」」 — 같은 파일에서 두 번 돌리면 두 번째는 이미 바뀐 상태에서 시작하므로 비교가 안 됩니다.
- 걷어낼 것 세 종류: 고르는 줄 · 기본값 설정 · 되돌렸다 다시 하는 줄(`FreezePanes = False` 뒤 `= True`).

## 채점기가 보는 것

채점기는 주석 줄(`'` 로 시작하는 줄)은 빼고 봅니다.

| 항목 | 무엇을 보나 |
|---|---|
| `Sub 매크로1` 이 있다 · `Option Explicit` 이 있다 | 모듈을 제대로 내보냈나 |
| `.Select` 가 없다 · `Selection` 이 없다 | 걷어낼 것 첫째 — 고르는 줄 |
| `Range("A3:F3").Font.Bold = True` 가 있다 | 12.2 의 「한 줄이면 된다」 |
| `Range("D4:D19").NumberFormat = "#,##0"` · `FreezePanes = True` 가 있다 | 하려던 일 세 가지가 남았나 |
| `FreezePanes = False` 가 없다 | 걷어낼 것 셋째 — 되돌렸다 다시 하는 줄 |
| `PatternColorIndex = xlAutomatic` · `PatternTintAndShade = 0` 이 없다 | 걷어낼 것 둘째 — 기본값 설정 |

채점 결과 아래에 나오는 □ 두 가지(두 사본의 결과가 같았나, 원본을 남겼나)는 스스로 확인합니다.
틀 고정은 코드에서 사라지기 쉬운 일입니다. 5번에서 두 사본의 틀 고정 위치가 같은지 꼭 봅니다.
