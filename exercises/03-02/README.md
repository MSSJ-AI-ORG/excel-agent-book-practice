# 03-02 정렬한 뒤 1행을 보고, 필터는 풀어서 넘기기

- **어느 장**: 3장 「3.4 정렬·필터를 말로 걸고 풀기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 사본 `03-02_정렬.xlsx` 를 만들어 그 사본을 엑셀로 엽니다.
- **낼 파일**: `03-02_정렬.xlsx`

---

## 왜 하나

3.4 에서 머리글을 빼라고 분명히 적었는데도 「담당자」 머리글이 3행으로 섞여 들어갔습니다.
정렬 범위에서 1행을 빼야 제대로 됐습니다. 그래서 3.4 는 이렇게 정리했습니다.
「정렬한 뒤에는 1행을 본다」. 그리고 필터는 「걸어 둔 채로 다른 사람에게 파일을 넘기지 않는다」.

이 과제는 정렬과 필터를 걸었다가 풀고, 넘길 수 있는 상태로 저장합니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. ‹과제에서 새로 붙인 시킬 말입니다.›

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 「03-02_정렬.xlsx」라는 이름으로 복사해 줘.
   원본은 열지도 말고 건드리지도 마.
   ```

   `03-02_정렬.xlsx` 를 엑셀로 열고, 03-01 의 2번처럼 3.1 의 시킬 말로 그 창에 붙게 합니다.

2. 3.4 의 정렬 시킬 말을 책 그대로 치고, 뒤에 한 줄을 붙입니다.
   앞의 두 줄은 책 그대로이고, ‹셋째 줄은 과제에서 새로 붙인 말›입니다.

   ```prompt
   매출 시트의 A2:E11 범위만 담당자 오름차순으로 정렬해 줘.
   1행은 범위에 넣지 마.
   같은 담당자 안에서는 금액이 큰 줄이 위로 오게 해 줘.
   ```

   **정렬이 끝나면 1행을 봅니다.** 「담당자 / 품목 / 수량 / 단가 / 금액」 그대로여야 합니다.

   > [그림 03-02-A] 정렬 뒤 1행에 머리글이 그대로 있는 화면 (촬영 예정)

3. 3.4 의 필터 시킬 말 두 개를 책 그대로 칩니다.

   ```prompt
   담당자 열에 필터를 걸고, 이현우 담당 행만 보이게 해 줘.
   ```

   ```prompt
   지금 화면에 보이는 행들의 금액 합계를 알려 줘.
   그리고 필터를 무시한 전체 합계도 같이 알려 줘.
   ```

   ‹받은 두 값을 적어 둡니다. 보이는 행 합계는 G1 에, 전체 합계는 G2 에 넣을 것입니다.›

4. 3.4 의 필터 푸는 시킬 말을 책 그대로 칩니다.

   ```prompt
   필터를 전부 풀고, 숨어 있던 행이 몇 개였는지 알려 줘.
   ```

5. 필터가 풀린 뒤 G1·G2·G3 에 받은 값을 **숫자로** 적습니다. ‹과제에서 새로 붙인 단계입니다.›
   G1 보이던 행 금액 합계 · G2 전체 합계 · G3 숨어 있던 행 수.
   (필터를 건 채로 적으면 G2·G3 칸이 숨은 줄에 걸릴 수 있어서, 푼 뒤에 적습니다.)

6. 엑셀에서 저장(Ctrl+S)하고 닫은 뒤 채점합니다.

   ```
   python grader/check.py 03-02 03-02_정렬.xlsx
   ```

## 확인법 — 3장에서 배운 것

- 「그래서 정렬한 뒤에는 1행을 본다」 — 「머리글 있음으로 처리했습니다」라는 답은 확인이 아닙니다.
- 「두 값이 다르다. 그리고 어느 쪽을 원했는지는 시킨 사람만 안다」 — G1 과 G2
- 「필터를 걸어 둔 채로 다른 사람에게 파일을 넘기지 않는다」 — 4번

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| A1:E1 머리글이 원본 그대로 1행에 있다 | 원본 1행과 칸마다 댄다 |
| 2~11행의 담당자·품목·금액 | 원본 열 줄을 담당자 오름차순, 같은 담당자 안에서 금액(수량×단가) 내림차순으로 줄 세운 결과 |
| 합계 칸(D12:E12)이 제자리에 원본 수식 그대로 있고, 값이 전체 합과 같다 | 원본 수량×단가를 채점기가 더한다 |
| G1 이현우 행 금액 합 | 원본에서 담당자가 이현우인 줄만 수량×단가를 더한다 |
| G2 전체 금액 합 | 원본 수량×단가를 모두 더한다 |
| G3 숨어 있던 행 수 | 원본 데이터 행 수에서 이현우 줄 수를 뺀다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

★ 채점기에 정렬 순서를 보는 규칙이 아직 없어, 2~11행의 기대값은 `check.json` 에 값으로 적어 두었습니다.
그 값이 원본을 정렬한 결과인지는 `_expected.py` 가 원본을 따로 정렬해 확인합니다.

★ **필터가 풀렸는지(숨은 행이 없는지)는 채점기가 아직 보지 못합니다.** 결과 아래 「스스로 확인하세요」에 나옵니다.

## 예시 파일

`solution/` 은 위 과정을 엑셀에서 그대로 한 파일입니다.
`wrong/` 은 책 3.4 의 그 실수 — **1행까지 범위에 넣고 정렬한** 파일입니다. 머리글 「담당자」가 3행으로 들어갔고,
맨 위로 올라간 줄이 합계 범위(E2:E11) 밖으로 밀려나 합계까지 달라졌습니다. 화면에는 오류 표시가 없습니다.
