# 08-01 작업본에 「검토」 열만 얹고 나머지는 세어 두기

- **어느 장**: 8장 「8.1 원본을 건드리지 않고 작업본 만들기」 · 「8.2 쓰던 수식·서식 그대로 두고 단계만 붙이기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 「작업본」 폴더로 복사하게 합니다.
- **낼 파일**: `작업본/부서 관리대장_<오늘 날짜 8자리>.xlsx` (예: `부서 관리대장_20260921.xlsx`)

---

## 왜 하나

8장의 전제는 하나입니다. **그 파일을 그대로 쓴다.** 옮기지 않고, 다시 그리지 않고, 필요한 것만 얹습니다.

얹을 때 기존에 있던 것이 조용히 사라질 수 있습니다. 조건부 서식이 날아가면 색이 빠질 뿐이고, 알아차리는 데 몇 달이 걸립니다.
그래서 얹기 전과 뒤에 개수를 세어 둡니다. 채점기는 기존 열이 한 칸도 안 바뀌었는지를 원본과 대 봅니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행합니다.

2. 8.1 의 시킬 말을 칩니다. 책의 「관리대장.xlsx」 자리만 이 저장소의 파일 이름으로 바꿨습니다.

   ```prompt
   practice 폴더의 부서 관리대장.xlsx 를 「작업본」 폴더에 복사하고, 파일 이름 뒤에 오늘 날짜를 붙여 줘.
   원본 파일은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「대장」이라고 하면 작업본을 가리키는 걸로 해 줘.
   ```

   날짜는 `_20260921` 처럼 밑줄 뒤 숫자 8자리로 붙게 합니다. 모양이 다르면 「날짜는 밑줄 뒤에 숫자 8자리로 붙여 줘」라고 한 번 더 말합니다.

3. 8.1 의 둘째 시킬 말을 책 그대로 칩니다.

   ```prompt
   작업본을 고치기 전에 「작업본_직전」이라는 이름으로 한 벌 더 복사해 줘.
   앞으로 파일을 크게 바꾸는 작업을 하기 전마다 이 복사를 먼저 해 줘.
   ```

4. 얹기 전에 개수를 받아 둡니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   작업본에서 표 개수, 차트 개수, 이름 정의 개수(숨김 이름은 빼고), 대장 시트의 조건부 서식 개수,
   대장 C열에 유효성 검사가 있는지를 세어서 표로 알려 줘. 파일은 고치지 마.
   ```

5. 8.2 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   대장 시트 G열에 「검토」 열을 더해 줘.
   금액이 300만 이상인 행에만 「확인 필요」라고 표시되게 해 줘.
   ★기존 열·수식·서식·유효성 검사는 하나도 건드리지 마.
   ```

6. 4번의 시킬 말을 한 번 더 쳐서 얹은 뒤의 개수를 받고, 4번의 답과 나란히 놓습니다.

7. practice 폴더의 원본 파일 속성에서 **수정한 날짜**가 작업 전과 같은지 봅니다.

8. 작업본을 엑셀로 한 번 열고 저장한 뒤 채점합니다. 파일 이름은 여러분 작업본의 이름으로 바꿔 넣습니다.

   ```
   python grader/check.py 08-01 "작업본/부서 관리대장_20260921.xlsx"
   ```

## 확인법 — 8.1·8.2 에서 배운 것

- 「「안 건드렸습니다」라는 답을 받는 것과 파일이 안 바뀐 것은 다른 사실이다」 — 7번.
- 「이 다섯 줄을 세는 데 드는 시간이 이 절에서 가장 값어치 있는 시간이다」 — 4번과 6번.
- 「오른쪽 끝에 붙이는 것을 기본으로 한다」 — 검토 열이 G열(표의 오른쪽 끝)에 붙었는지 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 대장!G3 머리글이 「검토」 | 시킬 말의 글자 |
| 대장!G6·G9·G13·G18 이 「확인 필요」 | 원본 대장 D열이 300만 이상인 줄. 고른 스크립트가 [`_expected.py`](_expected.py) 에 있다 |
| 대장 A1:F19 가 한 칸도 안 바뀌었다 | 원본 대장과 칸마다 댄다 — 값 칸은 값, 수식 칸은 수식 글자 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

## 스스로 확인할 것

- □ 낼 파일 이름이 「부서 관리대장_」 뒤에 오늘 날짜 8자리(예: 20260921)로 끝난다
- □ G열에서 「확인 필요」가 네 줄(6·9·13·18행)에만 있고 나머지 줄은 비어 있다
- □ 얹기 전후로 표 2 · 차트 1 · 이름 정의 4 · 조건부 서식 1 · C열 유효성 검사 있음 — 다섯 줄이 같다
- □ practice 원본 파일 속성의 「수정한 날짜」가 작업 전과 같다

채점기는 아직 파일 이름, 표·차트·서식 개수, 그리고 «비어 있어야 할 칸»을 보지 못합니다.
(수식이 빈 글자를 내는 칸은 엑셀이 계산값을 저장하지 않아 채점기가 읽을 수 없습니다.) 그래서 위 네 줄은 눈으로 확인합니다.

## 막혔을 때
