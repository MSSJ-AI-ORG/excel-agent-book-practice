# 24-01 엑셀을 띄우지 않고 매출합계를 읽어 내기

- **어느 장**: 24장 「24.1 왜 이 화면에는 AI 가 안 들어가나」 · 「24.2 엑셀을 열지 않고 엑셀 파일 읽기」
- **기본 과제** · 채점: 자동(auto) — 글 파일(CSV)을 채점합니다
- **시작 파일**: `practice/부서 관리대장.xlsx` — 프로그램이 **읽기만** 합니다. 고치지 않습니다.
- **낼 파일**: 프로그램이 만든 `out/매출합계.csv`

---

## 왜 하나

24장은 엑셀을 열지 않고 같은 값을 내는 프로그램을 짓습니다. 조건은 셋입니다 — 엑셀을 띄우지 않는다, 돌 때 AI 를 부르지 않는다, 원본을 고치지 않는다.
이 과제에서는 그 첫걸음으로 **부서별 매출합계**만 CSV(쉼표로 칸을 나눈 글 파일)로 내게 합니다.

이 실습 파일에는 24.2 의 함정이 그대로 들어 있습니다.
**정산 시트에 저장된 계산값이 전부 0 입니다.** 엑셀로 다시 계산해 저장한 적이 없는 파일이라서입니다.
프로그램이 그 저장값을 그대로 읽으면 부서 셋이 모두 0 으로 나옵니다. 조용히 틀립니다.
그래서 정산 시트의 값을 읽지 말고, **대장의 입력 값에서 지금 수식과 같은 규칙으로** 계산하게 합니다.
지금 수식(`SUMIF`)은 부서 이름이 **정확히 같은 줄만** 더합니다.

## 할 일

1. 작업 폴더에서 `claude` 를 실행하고, 24.1 의 세 조건 시킬 말을 책 그대로 칩니다.
   23장의 `23_업무구조.md` 가 없다면 첫 줄은 빼고 칩니다.

   ```prompt
   23_업무구조.md 를 읽고, 정산 시트가 내는 값과 같은 값을 내는 웹 화면을 지어 줘.
   조건이 셋 있어.
   ① 엑셀을 띄우지 마. 파일을 읽기만 해.
   ② 화면이 돌 때는 AI 를 부르지 마. 규칙은 전부 코드에 있어야 해.
   ③ 원본 파일을 고치지 마. 결과는 out 폴더에만 써.
   ```

   이어서 이 과제에서 새로 붙인 말을 칩니다.

   ```prompt
   원본은 practice 폴더의 「부서 관리대장.xlsx」야.
   먼저 부서별 매출합계만 out/매출합계.csv 로 내 줘.
   첫 줄은 「부서,매출합계」, 그다음 정산 대상 부서마다 한 줄씩. 숫자는 쉼표 없이 적어 줘.
   정산 시트에 저장된 값은 쓰지 말고, 대장의 입력 값에서 지금 정산 수식과 같은 규칙으로 계산해 줘 — 부서 이름이 정확히 같은 줄만 더해.
   ```

2. 24.2 의 빈 칸 시킬 말을 책 그대로 칩니다.

   ```prompt
   읽은 값 중에 비어 있는 칸이 있는지 세어 줘.
   있으면 어느 시트 어느 칸인지 알려 주고, 그 칸을 0 으로 채우지 마.
   ```

3. 24.2 의 지문 시킬 말을 책 그대로 칩니다.

   ```prompt
   화면을 만들기 전과 후에 원본 파일의 지문(sha256)을 찍어서 같은지 대조해 줘.
   ```

   > [그림 24-01-A] 만들기 전후 원본 지문이 같은 화면 (촬영 예정)

   이 저장소의 원본 지문은 `practice/MANIFEST.json` 에 적혀 있습니다(`6a0b6808…` 로 시작). 전·후 둘 다 그 값이어야 합니다.

4. 24.1 의 통신 확인 시킬 말을 책 그대로 칩니다. 그리고 인터넷을 끊고 프로그램을 한 번 더 돌려 봅니다.

   ```prompt
   이 프로그램이 도는 동안 바깥으로 나가는 통신이 있는지 확인해 줘.
   import 한 것 중에 네트워크를 쓰는 것이 있는지, API 키를 읽는 자리가 있는지 봐 줘.
   ```

5. 채점합니다. CSV 가 생긴 곳으로 경로를 바꿔 칩니다.

   ```
   python grader/check.py 24-01 out/매출합계.csv
   ```

## 확인법 — 24장에서 배운 것

- 「**비었으면 비었다고 알린다.** 0 으로 채우면 합계가 조용히 줄어든다.」 — 이 파일에서는 저장값이 0 이라 더 조용합니다.
- 「**지문이 같으면 한 바이트도 안 바뀐 것**이다.」 — 3번에서 전·후 지문을 받았는지 봅니다.
- 「**옮길 때는 지금 수식이 하는 대로 옮긴다.**」(24.3) — 부서 이름이 정확히 같은 줄만 더했는지 채점기가 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 첫 줄이 「부서,매출합계」다 | — |
| 영업1팀 · 영업2팀 · 영업3팀 줄의 값 | 원본 대장 D 를 B 가 그 부서와 정확히 같은 줄만 더한 값. CSV 를 채점하는 규칙은 숫자를 식으로 적을 수 없어 check.json 에 숫자를 적었고, 그 숫자는 `_expected.py` 가 원본에서 따로 계산한다 |
| 값이 0 인 부서 줄이 없다 | 정산 시트의 저장값(0)을 옮기지 않았는지 |

이 과제는 글 파일을 채점하므로 채점기가 원본 지문을 따로 보지 못합니다. 원본 그대로인지·인터넷 없이 도는지는 확인 목록으로 나옵니다.

## 정답·오답 예시

- `solution/screen.py` — 엑셀을 띄우지 않고 원본을 읽기만 해서 `out/매출합계.csv` 를 내는 프로그램(파이썬 · 네트워크 모듈 없음). 돌린 결과가 `solution/out/매출합계.csv` 이고, 채점하면 전부 ✓. 돌릴 때 빈 칸 수·정산 시트 저장값(0)·원본 지문 전후를 찍습니다.
- `wrong/make_wrong.py` · `wrong/out/매출합계.csv` — **부서 이름의 띄어쓰기를 지우고 더한** 결과. 「영업 1팀」 같은 줄까지 세어져 값이 더 커 보이지만 지금 수식과 다릅니다. 영업1팀·영업2팀 두 항목만 ✗.
- `_expected.py` — 부서별 매출합계를 원본에서 따로 계산한다. `_verify.txt` — 두 파일을 채점한 출력 원문.
