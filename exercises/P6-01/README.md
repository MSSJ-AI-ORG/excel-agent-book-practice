# P6-01 사고 막는 장치를 한 파일에 갖춰 넘기기

- **어느 장**: 6부 종합 — 19장 「19.4 위험한 작업 목록을 시트로 관리하기」 · 21장 · 22장 「22.3 승인 기록을 파일로 남기기」 · 「22.4 이 규칙을 다음 사람에게 넘기기」
- **6부 종합 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` 를 파일째 복사한 작업본 — 원본은 열지 않습니다.
- **낼 파일**: `P6-01_사고막기.xlsx`

---

## 왜 하나

22.4 에서 넘길 것을 모아 보니 「**절반이 파일 안 시트**」였습니다.
파일은 메일로 오가고 폴더를 떠납니다. 그래서 「**파일과 같이 움직인다**」는 쪽에 둡니다.

이 과제는 6부에서 만든 장치를 한 파일에 모읍니다.
위험목록(19.4) · 검사기 여덟 줄과 검사이력(21장) · 승인이력과 보호(22.3) · 새로 쓴 읽어주세요(22.4).
채점기는 19-02 · 21-01 · 22-01 에서 본 것을 이 한 파일에서 다시 봅니다.

## 할 일

1. 작업본을 만듭니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 파일째 복사해서 「P6-01_사고막기.xlsx」로 만들어 줘.
   원본은 건드리지 마. 이 과제에서는 이 작업본만 고치고, 대장 시트는 고치지 마.
   ```

2. **위험목록** — 19-02 의 6번(19.4 시킬 말 + 모양 맞추기 말)을 파일 이름만 `P6-01_사고막기.xlsx` 로 바꿔 칩니다.

3. **검사기** — 21-01 의 2~5번(21.1 · 21.2 · 21.3 시킬 말 + 여덟 줄 모양 맞추기 말)을 이 작업본에 다시 칩니다.

4. **검사이력** — 21.4 의 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 말을 칩니다.

   ```prompt
   검사기를 돌린 결과를 「검사이력」 시트에 한 줄씩 쌓아 줘.
   날짜 · 검사 항목 수 · 통과한 수 · 확인이 뜬 항목 이름.
   ★덮어쓰지 말고 한 줄씩 추가해 줘.
   ```

   ```prompt
   검사이력 1행 머리글은 「날짜」「항목 수」「통과」「확인이 뜬 것」으로 하고, 지금 결과를 2행에 남겨 줘.
   ```

5. **승인이력과 보호** — 22-01 의 4·5번(22.3 시킬 말 + 머리글 맞추기 말 + 보호 시킬 말)을 이 작업본에 다시 칩니다. 이유 칸을 비우지 않습니다.

6. **넘길 것 점검** — 22.4 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   이 파일과 폴더를 다음 사람에게 넘기려고 해.
   넘겨야 할 것을 목록으로 만들어 줘.
   파일 · 시트 · 규칙 문서 · 절차 문서 · 이력 — 빠진 것이 없는지 확인해 줘.
   ```

   > [그림 P6-01-A] 넘기기 전 점검에서 빠진 것이 나온 화면 (촬영 예정)

7. **읽어주세요 다시 쓰기** — 22.4 의 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 말을 칩니다.

   ```prompt
   「읽어주세요」 시트를 새로 써 줘.
   처음 이 파일을 여는 사람이 알아야 할 것을 순서대로 적어 줘.
   ① 이 파일이 무엇을 하는 파일인지
   ② 어느 시트를 건드리면 안 되는지
   ③ 무엇을 하기 전에 무엇을 해야 하는지
   ④ 이상하면 어느 시트를 보면 되는지
   ⑤ 모르면 누구에게 물으면 되는지
   ```

   ```prompt
   읽어주세요는 A열에 한 줄씩, A1 부터 차례로 적어 줘. 전임자의 네 줄은 새 글로 바꿔 줘.
   ```

8. `P6-01_사고막기.xlsx` 를 **엑셀로 한 번 열고, 저장하고, 닫습니다.** 그리고 채점합니다.

   ```
   python grader/check.py P6-01 P6-01_사고막기.xlsx
   ```

## 확인법 — 6부에서 배운 것

- 「**파일과 같이 움직인다**」(19.4) — 위험목록·검사기·이력이 모두 이 파일 안 시트로 있는지 채점기가 봅니다.
- 「**기준은 수식이 아니라 숫자로 적는다.**」(21.1) — 검사기 C열을 칸마다 봅니다.
- 「**「이유」 칸이 이 기록의 값어치다.**」(22.3)
- 「**절반이 파일 안 시트**다.」(22.4) — 파일 밖에 둔 것(작업규칙.md · 복구절차.md 같은 것)은 넘길 것 목록에 따로 적혔는지 스스로 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 위험목록 — 머리글·작업 이름·빨강·필요(19-02 와 같다) | 19.4 의 표 |
| 검사기 여덟 줄 — B 수식·C 손으로 적은 값·D 통과·B·C 값(21-01 과 같다) | 원본 대장에서 채점기가 직접 센다(중복 0 은 `_expected.py`) |
| 검사이력 — 머리글 · 2행 항목 수 8 · 2행 통과 = 지금 검사기의 「통과」 수 | 제출 파일 검사기 D2:D9 에서 채점기가 센다 |
| 승인이력 — 머리글 여섯 칸 · 이유 칸(F2)이 채워져 있다(22-01 과 같다) | 22.3 의 표 |
| 읽어주세요 A1:A5 가 모두 채워져 있다(다섯 줄 이상 — 전임자의 네 줄보다 길다) | 제출 파일에서 채점기가 센다 |
| 대장 A1:F19 가 원본과 같다 · practice 원본이 그대로다 | 원본과 칸마다 · 원본 지문 |
