# 03-01 서식·열 너비·틀 고정을 말로 걸고 값은 그대로 두기

- **어느 장**: 3장 「3.2 셀 값과 글꼴·색을 말로 바꾸기」 · 「3.3 열 너비·행 높이·틀 고정을 말로 맞추기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 사본 `03-01_서식.xlsx` 를 만들어 그 사본을 엑셀로 엽니다.
- **낼 파일**: `03-01_서식.xlsx`

---

## 왜 하나

3장에서 처음으로 화면이 움직였습니다. 클로드가 열려 있는 엑셀 창을 잡고, 말할 때마다 서식이 붙었습니다.
그리고 3.2 에서는 「화면에 보이는 것과 셀에 든 것을 가르는 습관」을, 3.3 에서는 「`#####` 은 오류가 아니다」를 배웠습니다.

이 과제는 3.2·3.3 의 시킬 말을 한 벌 그대로 해 봅니다. 채점기는 서식이 걸렸는지와 함께,
**값은 한 칸도 바뀌지 않았는지**를 원본과 칸마다 댑니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. ‹과제에서 새로 붙인 시킬 말입니다.›

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 「03-01_서식.xlsx」라는 이름으로 복사해 줘.
   원본은 열지도 말고 건드리지도 마.
   ```

2. `03-01_서식.xlsx` 를 **여러분이 직접** 엑셀로 엽니다. 그 창을 닫지 말고 둔 채, 3.1 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금 열려 있는 엑셀 창을 잡아서, 그 안에 어떤 통합 문서가 몇 개 열려 있는지 알려 줘.
   새로 띄우지 말고 이미 떠 있는 것에 붙어 줘. 값은 바꾸지 마.
   ```

   받은 문서 수가 화면에 보이는 수와 같은지 봅니다.

3. 3.2 의 서식 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금 열려 있는 매출 시트에서 다음 세 가지를 해 줘.
   ① 1행 머리글을 굵게
   ② C열부터 E열까지 숫자에 천 단위 구분 기호
   ③ E열 금액 칸에 연한 파란색 채우기
   값은 바꾸지 말고 서식만 바꿔 줘.
   ```

   이어서 3.2 의 확인 문장을 칩니다.

   ```prompt
   E2 셀에 실제로 들어 있는 값과, 화면에 보이는 글자를 각각 알려 줘.
   ```

   ‹3.2 에 나오는 「B2 를 「태블릿」으로 바꿔 줘」는 이 과제에서 하지 않습니다. 값은 그대로 둡니다.›

4. 3.3 의 순서대로 먼저 좁혀서 `#####` 을 봅니다. 책 그대로 칩니다.

   ```prompt
   D열과 E열의 너비를 6으로 좁혀 줘.
   ```

   금액 칸이 `#####` 으로 보이면, D2 를 눌러 수식 입력줄에 값이 그대로 있는지 봅니다. 그다음 맞춥니다.

   ```prompt
   A열부터 E열까지 내용에 맞춰 너비를 자동으로 맞춰 줘.
   ```

5. 3.3 의 틀 고정 시킬 말을 책 그대로 칩니다.

   ```prompt
   1행 머리글이 스크롤해도 보이게 틀 고정을 걸어 줘.
   지금 몇 행에 틀 고정이 걸리는지도 알려 줘.
   ```

6. 엑셀에서 저장(Ctrl+S)하고 닫은 뒤 채점합니다.

   ```
   python grader/check.py 03-01 03-01_서식.xlsx
   ```

## 확인법 — 3장에서 배운 것

- 「화면에 보이는 것과 셀에 든 것을 가르는 습관」 — 3번의 E2 확인
- 「`#####` 은 「데이터가 사라졌다」가 아니라 「지금 이 폭으로는 못 보여 준다」는 뜻이다」 — 4번
- 「몇 행에 걸리는지 알려 줘」를 붙인다 — 5번. 틀 고정은 선택한 셀에 따라 엉뚱한 곳에 걸릴 수 있습니다.

## 채점기가 보는 것

| 항목 | 기대값 |
|---|---|
| A1:E1 굵게 | — |
| C2:E11 과 E12 의 표시 형식이 `#,##0` | 3.2 의 「G/표준 → #,##0」 |
| E2:E11 에 채우기 색 | — |
| D·E열 너비가 9 이상 | 금액이 `#####` 없이 보일 만큼 — 자동 맞춤까지 했는지 |
| 틀 고정이 A2 | 1행만 고정 |
| 매출 A1:E12 가 원본과 같다 | 원본과 칸마다 댄다 — 값 칸은 값, 수식 칸은 수식 글자 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

## 예시 파일

`solution/` 은 위 과정을 엑셀에서 그대로 한 파일입니다. `_build_log.txt` 에 그때 본 것이 있습니다.
너비 6 에서 D2 의 화면 글자는 `#####` 이었고 값은 그대로였으며, 자동 맞춤 뒤에는 `1,290,000` 으로 보였습니다.

`wrong/` 은 흔한 실수 하나 — 좁힌 뒤 **자동 맞춤을 하지 않은** 파일입니다. 저장한 파일에서 금액이 `#####` 으로 보입니다.
