# 04-02 사본 규칙을 걸고, 고쳤다가 사본으로 되돌리기

- **어느 장**: 4장 「4.3 실행 취소가 듣는 경우와 안 듣는 경우 가르기」 · 「4.4 작업 전 사본을 자동으로 남기게 하기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 작업 폴더에 **복사**한 것을 작업본으로 씁니다.
- **낼 파일**: `04-02_작업본.xlsx` — 사본으로 되돌린 작업본

---

## 왜 하나

4.3 에서 클로드가 엑셀 창을 제어해 바꾼 값은 Ctrl+Z 로 되돌아가지 않았습니다.
그래서 4.3 은 「되돌리는 방법은 하나뿐이다 — 사본」이라고 했고, 4.4 에서 고치기 전에 사본이 자동으로 남게 걸었습니다.

이 과제는 그 규칙을 걸고, 일부러 고쳤다가, 사본으로 되돌립니다.
채점기는 되돌린 작업본이 원본과 칸마다 같은지를 봅니다.

## 할 일

1. P0-01 에서 만든 `C:\엑셀실습` 을 씁니다(없으면 P0-01 의 1번을 먼저 합니다).
   저장소의 `practice/이번 달 매출.xlsx` 를 `C:\엑셀실습\작업본` 에 복사하고, 이름을 `04-02_작업본.xlsx` 로 바꿉니다.
   `C:\엑셀실습` 에서 `claude` 를 실행합니다.

2. 4.4 의 사본 규칙을 책 그대로 겁니다.

   ```prompt
   앞으로 이 폴더의 엑셀 파일을 고치기 전에는, 먼저 「_백업」 폴더에 사본을 만들어 줘.
   사본 이름은 원래 이름 뒤에 날짜와 시각을 붙여 줘.
   사본을 만든 뒤에 고치고, 사본 경로를 알려 줘.
   ```

   사본 개수 규칙도 책 그대로 겁니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   _백업 폴더의 사본이 열 개를 넘으면 가장 오래된 것부터 지워 줘.
   단, 오늘 만든 사본은 지우지 마.
   ```

3. 작업본을 엑셀로 열고, 3.1 의 시킬 말로 그 창에 붙게 합니다(03-01 의 2번). 그다음 B2 를 바꾸게 합니다.
   ‹과제에서 새로 붙인 시킬 말입니다.›

   ```prompt
   작업본 04-02_작업본.xlsx 의 매출 시트 B2 를 「태블릿」으로 바꾸고 저장해 줘.
   ```

   `_백업` 폴더에 시각이 붙은 사본이 생겼는지 봅니다. 엑셀 창에서 **Ctrl+Z** 를 눌러 보고, B2 가 어떻게 되는지 적어 둡니다.

   > [그림 04-02-A] 사본을 만든 뒤 고쳤다는 답을 받은 화면 (촬영 예정)

4. 사본과 작업본을 비교하게 합니다. 4.4 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   방금 만든 사본과 지금 작업 중인 파일이 같은지 비교해 줘.
   다르면 어느 시트 어느 셀이 다른지 알려 줘.
   ```

5. 엑셀 창을 닫고 되돌립니다. 4.4 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   _백업 폴더의 가장 최근 사본으로 작업본을 되돌려 줘.
   되돌리기 전에 지금 작업본도 「_되돌리기전」이라는 이름으로 한 벌 남겨 줘.
   ```

6. 저장소 폴더에서 되돌린 작업본을 채점합니다.

   ```
   python grader/check.py 04-02 C:\엑셀실습\작업본\04-02_작업본.xlsx
   ```

## 확인법 — 4장에서 배운 것

- 「두 경로 다 Ctrl+Z 가 답이 아니다. 되돌리는 방법은 하나뿐이다 — 사본.」
- 「지우는 규칙에는 반드시 예외를 같이 건다」 — 2번의 「단, 오늘 만든 사본은 지우지 마」
- 「되돌리기 전에 지금 상태를 남긴다」 — 5번의 「_되돌리기전」

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 매출!B2 에 원래 품목이 돌아와 있다 | 원본 매출!B2 를 채점기가 읽는다 |
| 매출 A1:E12 전체가 원본과 같다 | 원본과 칸마다 댄다 — 값 칸은 값, 수식 칸은 수식 글자 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

`_백업` 사본, 사본 비교 결과, Ctrl+Z 결과, `_되돌리기전` 파일은 채점기가 보지 않습니다. 결과 아래 「스스로 확인하세요」에 나옵니다.

## 예시 파일

`solution/` 은 위 순서를 엑셀과 파일 복사로 그대로 한 결과입니다. `_build_log.txt` 에 그때 본 것이 있습니다.
사본은 만든 직후 작업본과 같았고, 엑셀 창을 제어해 B2 를 바꾼 뒤 실행 취소(Undo)를 부르자 엑셀 오류로 끝났으며 B2 는 「태블릿」 그대로였습니다.
저장 뒤에는 사본과 작업본이 달랐고, 사본으로 되돌린 뒤에는 다시 같아졌습니다.

`wrong/` 은 흔한 실수 하나 — 가장 최근 사본이 아니라 **방금 남긴 「_되돌리기전」 파일로 되돌린** 작업본입니다. 「태블릿」이 그대로 남아 있습니다.
