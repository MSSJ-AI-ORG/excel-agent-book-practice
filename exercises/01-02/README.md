# 01-02 시연 네 문장을 쳐 보고, 받은 답을 파일로 대조하기

- **어느 장**: 1장 「1.4 말로 시킨 결과를 한 번 미리 보기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 열지 않고 클로드에게 읽히기만 합니다. 고치지 않습니다.
- **낼 파일**: `01-02_미리보기.xlsx` — 받은 답을 여러분이 새 엑셀 파일에 적은 것

---

## 왜 하나

1.4 에서 한국어 문장 네 개로 낯선 파일의 구조를 받고, 부서 표기가 흔들린 것을 찾고,
그 때문에 목표 달성 여부가 뒤집힌다는 것까지 봤습니다. 그리고 1.4 는 이렇게 끝났습니다.
「받은 답이 맞는지 확인하는 법」이 이 책이라고요.

이 과제는 그 시연을 직접 쳐 보고, **받은 답을 파일에 적어 채점기와 대 봅니다.**
채점기는 받은 답을 믿지 않고, 원본 파일에서 직접 다시 셉니다.

## 할 일

1. 저장소의 `practice` 폴더에서 명령 프롬프트를 열고 `claude` 를 실행합니다.
   (책의 시킬 말이 「이 폴더의 부서 관리대장.xlsx」라서, 그 파일이 있는 폴더에서 시작합니다.)

2. 1.4 의 시킬 말을 **책에 나온 순서대로, 책 그대로** 칩니다.

   첫 문장 — 구조 목록

   ```prompt
   이 폴더의 부서 관리대장.xlsx 를 열지 말고 구조만 읽어서,
   시트·이름 정의·표·차트를 목록으로 만들어 줘.
   ```

   두 번째 문장 — 부서 이름 목록

   ```prompt
   대장 시트 B열에 적힌 부서 이름을 중복 없이 목록으로 만들고,
   각 표기가 몇 건씩 쓰였는지 세어 줘.
   ```

   세 번째 문장 — 영업1팀 두 값

   ```prompt
   정산 시트에서 영업1팀 매출합계를 구하는 수식이 있는데,
   그 수식이 지금 얼마를 세고 있는지, 그리고 띄어쓰기를 무시하고 다시 세면
   얼마가 되는지 둘 다 알려 줘.
   ```

   그다음 — 목표 대비

   ```prompt
   기준 시트에서 영업1팀 목표가 얼마인지 확인하고,
   방금 두 값 각각이 목표를 넘는지 알려 줘.
   ```

   > [그림 01-02-A] 네 문장의 답을 받은 화면 (촬영 예정)

3. 받은 답을 새 엑셀 파일에 적습니다. ‹이 단계는 과제에서 새로 붙인 것입니다.›
   엑셀에서 새 통합 문서를 만들고, 시트 이름을 「답」으로 바꾼 뒤 아래처럼 적습니다.
   A열은 이름표라서 채점하지 않습니다. **B열에는 숫자만** 적습니다(「7개」가 아니라 `7`).

   | 칸 | 적을 것 |
   |---|---|
   | B1 | 시트 수 |
   | B2 | 이름 정의 수 |
   | B3 | 표 수 |
   | B4 | 차트 수 |
   | B5 | 부서 표기가 몇 가지인가(띄어쓰기가 다르면 다른 표기로 센다) |
   | B6 | 지금 수식이 세는 영업1팀 금액 |
   | B7 | 띄어쓰기를 무시하고 다시 센 영업1팀 금액 |
   | B8 | 영업1팀 목표 |

   `01-02_미리보기.xlsx` 로 저장합니다. practice 폴더가 아니라 저장소 폴더(practice 의 한 단계 위)에 두면 채점 명령이 짧아집니다.

4. 1.4 의 네 번째 문장을 책 그대로 칩니다. **이 문장은 고치라는 말이 아닙니다.**

   ```prompt
   이 표기를 고치면 정산 금액이 바뀌는데, 지금은 고치지 말고
   무엇을 고쳐야 하는지 목록으로만 만들어 줘.
   고쳤을 때 어느 셀의 값이 바뀌는지도 같이 알려 줘.
   ```

   > [그림 01-02-B] 고칠 목록과 영향 범위를 받은 화면 (촬영 예정)

5. 저장소 폴더에서 채점합니다.

   ```
   python grader/check.py 01-02 01-02_미리보기.xlsx
   ```

## 확인법 — 1장에서 배운 것

- 「찾는 것과 고치는 것을 나눈다」 — 4번 문장은 목록만 받습니다.
- 「그리고 아무것도 고치지 않았다」 — 그래서 채점기가 practice 의 원본이 처음 받은 그대로인지 지문으로 봅니다.
- 「받은 답이 맞는지 확인하는 법」 — 받은 답을 파일에 적어 원본에서 다시 센 값과 댑니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「답」 시트가 있다 | — |
| B1 시트 수 | 원본 파일의 시트를 채점기가 센다 |
| B2 이름 정의 수 | 원본에서 숨김이 아닌 이름 정의를 채점기가 센다 |
| B5 부서 표기 가짓수 | 원본 대장 B4:B19 에서 글자가 조금이라도 다른 표기를 센다 |
| B6 지금 수식이 세는 금액 | 원본 대장에서 B열이 「영업1팀」과 **글자까지 똑같은** 줄의 금액을 더한다 |
| B7 띄어쓰기 무시 금액 | 원본 대장에서 B열의 공백을 모두 빼면 「영업1팀」인 줄의 금액을 더한다 |
| B8 영업1팀 목표 | 원본 기준 시트에서 「영업1팀」을 찾아 목표를 읽는다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

★ **B3(표 수)·B4(차트 수)는 채점기가 아직 세지 못합니다.** 채점 결과 아래 「스스로 확인하세요」에 나옵니다.
원본을 복사한 사본을 엑셀로 열어, 표와 차트를 직접 세어 받은 답과 대 보세요.

## 예시 파일

`solution/` 은 맞게 적은 예, `wrong/` 은 흔한 실수 하나를 넣은 예입니다.
wrong 은 B6 에 띄어쓰기를 무시한 금액을 적었습니다 — 「지금 수식이 세는 금액」과 「고치면 되는 금액」을 바꿔 적는 실수입니다.
두 파일을 만든 방법과 채점 결과는 `_build_log.txt` · `_verify.txt` 에 있습니다.
