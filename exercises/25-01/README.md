# 25-01 여덟 줄 맞대기와 「손으로」 심판 칸

- **어느 장**: 25장 「25.1 줄마다 맞대기」 · 「25.2 다르면 어느 쪽이 틀렸나」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` 사본 · 24장에서 만든 CSV 두 개(`매출합계.csv` · `정산.csv`)
- **낼 파일**: `25-01_대조.xlsx`

---

## 왜 하나

25.1 은 「합계가 같다」로 끝내지 않습니다. 「**부서마다, 항목마다, 한 줄씩** 맞댄다.」
부서 셋 × 항목 둘(매출합계·정산액) + 합계 둘 = 여덟 줄입니다.

25.2 는 여기에 세 번째 값을 세웁니다. 엑셀과 화면 둘만 있으면 어느 쪽을 심판으로 세워도 그쪽이 이깁니다.
매출합계는 대장에서 그냥 더하면 나오니 심판이 됩니다. 정산액은 조건과 반올림이 섞여 있어 심판을 못 세웁니다.
「**심판을 못 세우는 줄이 있다는 것을 아는 것도 판정이다.**」 그래서 정산액 줄의 「손으로」 칸은 **비워 둡니다.**

## 할 일

1. 사본을 만듭니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 복사해서 「25-01_대조.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마. 대장·기준·정산 시트는 고치지 마.
   ```

2. 25.1 의 맞대기 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 모양 맞추기 말을 칩니다.

   ```prompt
   엑셀 정산 시트가 낸 값과 우리 화면이 낸 값을 맞대는 프로그램을 만들어 줘.
   부서별 매출합계와 정산액을 각각 한 줄로 놓고, 같은지 다른지 표시해 줘.
   합계만 비교하지 말고 줄마다 비교해 줘.
   ```

   ```prompt
   맞댄 결과는 「25-01_대조.xlsx」에 「대조」 시트를 만들어 적어 줘.
   1행 머리글: 「부서」「항목」「엑셀」「화면」「손으로」「같은가」
   2~9행은 이 순서로: 영업1팀 매출합계 / 영업1팀 정산액 / 영업2팀 매출합계 / 영업2팀 정산액 /
   영업3팀 매출합계 / 영업3팀 정산액 / 합계 매출합계 / 합계 정산액
   엑셀 칸은 이 파일 정산 시트의 값, 화면 칸은 24장 CSV 의 값(합계 매출합계는 세 부서를 더한 값), 같은가는 「같음」이나 「다름」.
   ```

3. 엑셀 칸이 비어 있으면 25.1 의 시킬 말을 책 그대로 칩니다. 이 실습 파일은 정산 시트에 저장된 계산값이 0 입니다. 저장된 값을 그대로 읽으면 엑셀 칸이 0 으로 나옵니다.

   ```prompt
   통합문서를 엑셀로 열어서 전체 다시 계산하고 저장해 줘.
   저장 전에 사본을 두고, 저장한 뒤에 계산값이 실제로 채워졌는지 세어 줘.
   ```

4. 25.2 의 대조기 시험 시킬 말을 책 그대로 칩니다.

   ```prompt
   대조기가 살아 있는지 시험해 줘.
   화면 쪽 값 하나를 일부러 천 원 올린 다음, 대조기가 그 줄을 잡는지 봐 줘.
   잡은 뒤에는 원래대로 되돌려 줘.
   ```

   > [그림 25-01-A] 일부러 어긋나게 한 줄을 대조기가 잡은 화면 (촬영 예정)

   잡힌 줄이 **내가 건드린 그 줄**인지도 봅니다.

5. 25.2 의 「손으로」 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 말을 칩니다.

   ```prompt
   대조표에 「손으로」 칸을 하나 더 만들어 줘.
   부서별 건수와 매출합계를 대장에서 직접 세어 넣어 줘 — 정산 수식을 거치지 말고.
   그 값이 어느 쪽과 같은지 표시해 줘.
   ```

   ```prompt
   「손으로」 칸은 매출합계 줄에만 넣어 줘. 합계 매출합계 줄은 세 부서의 손으로 값을 더한 값.
   정산액 줄의 「손으로」 칸은 비워 둬 — 그냥 더해서 나오는 값이 아니라서 심판을 못 세우는 줄이야.
   ```

6. `25-01_대조.xlsx` 를 **엑셀로 한 번 열고, 저장하고, 닫습니다.** 그리고 채점합니다.

   ```
   python grader/check.py 25-01 25-01_대조.xlsx
   ```

## 확인법 — 25장에서 배운 것

- 「「합계가 같다」는 확인이 아니다. 두 군데가 반대로 틀리면 합계는 같아진다.」 — 여덟 줄이 다 있는지 채점기가 봅니다.
- 「**파일이 멀쩡해 보이는데 값이 없다.**」 — 3번에서 계산값을 되채웠는지 봅니다.
- 「**둘 다 확인한다** — 잡는 것과 «맞는 것을 잡는 것» 은 다르다.」 — 4번에서 잡힌 줄이 건드린 줄인지 봅니다.
- 「**심판을 못 세우는 줄이 있다는 것을 아는 것도 판정이다.**」 — 정산액 줄의 「손으로」가 비었는지 채점기가 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 대조 머리글 여섯 칸 · 2~9행의 부서·항목 | 이 과제에서 정한 순서 |
| 줄마다 엑셀 · 화면 값 | 원본 대장·기준의 입력 칸에서 지금 정산 수식과 같은 규칙(부서 이름 정확히 일치, 엑셀 `ROUND`)으로 채점기가 계산한 값 |
| 매출합계 줄의 「손으로」 = 대장을 직접 더한 값 | 원본 대장 D 를 부서 이름이 정확히 같은 줄만 채점기가 더한 값 |
| 정산액 줄의 「손으로」는 비어 있다 | 심판을 못 세우는 줄 |
| 줄마다 같은가 = 「같음」 | — |
| practice 의 원본이 그대로다 | 원본 파일의 지문 |

## 정답·오답 예시

- `solution/25-01_대조.xlsx` — 원본 사본에 엑셀로 대조 시트를 실제로 만든 파일. 엑셀 칸은 정산 시트를 가리키는 수식(엑셀이 다시 계산한 값), 화면 칸은 24-02 정답 프로그램이 낸 CSV 값, 「손으로」는 대장을 직접 더하는 `SUMIF`. 전부 ✓ — 여덟 줄이 모두 같았습니다.
- `wrong/25-01_대조.xlsx` — **정산액 줄의 「손으로」 칸에 엑셀 값을 옮겨 적은** 파일. 겉으로는 세 값이 다 같아 보이지만 심판이 아니라 엑셀의 복사본입니다. 정산액 「손으로」 네 항목만 ✗.
- `_verify.txt` — 두 파일을 채점한 출력 원문.
