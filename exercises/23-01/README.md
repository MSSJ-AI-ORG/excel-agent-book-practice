# 23-01 도구함 목록을 열어 보고 적기

- **어느 장**: 23장 「23.1 도구함에 무엇이 있는지 세기」
- **기본 과제** · 채점: 스스로 확인하는 과제(manual)
- **시작 파일**: 내 작업 폴더(앞 장들에서 만든 것들) — 이 과제는 파일을 고치지 않습니다.
- **낼 파일**: 없음(그 폴더 안에 `도구목록.xlsx` 가 생깁니다)

---

## 왜 하나

23.1 은 도구함 폴더를 훑어 목록을 받는 절입니다. 핵심은 시킬 말의 마지막 줄입니다.
「내용을 열어서 보고 적어 줘. 파일 이름만 보고 짐작하지 마.」

폴더 안에 무엇이 있는지는 사람마다 다릅니다. 그래서 채점기가 기대값을 미리 가질 수 없습니다.
이 과제는 스스로 확인합니다. 아래 확인 목록을 하나씩 짚어 봅니다.

## 할 일

1. 작업 폴더에서 `claude` 를 실행하고, 23.1 의 목록 시킬 말을 책 그대로 칩니다.
   이어서 이 과제에서 새로 붙인 말을 칩니다.

   ```prompt
   이 작업 폴더에 있는 파일을 전부 훑어서 목록을 만들어 줘.
   파일 이름 · 무엇을 하는 것인지 한 줄 · 언제 만들었는지 · 마지막으로 고친 날.
   내용을 열어서 보고 적어 줘. 파일 이름만 보고 짐작하지 마.
   ```

   ```prompt
   목록은 이 폴더에 「도구목록.xlsx」로 저장해 줘. 1행 머리글, 2행부터 파일 하나에 한 줄씩.
   도구목록.xlsx 자기 자신과 ~$ 로 시작하는 잠금 파일은 빼 줘.
   ```

   > [그림 23-01-A] 도구 목록을 받아 본 화면 (촬영 예정)

2. 「하는 일」 칸이 파일 이름을 되풀이한 줄을 찾습니다. 있으면 23.1 의 시킬 말로 다시 받습니다.
   책에는 「셋」이라고 적혀 있습니다. 여러분 목록에서 센 수로 바꿔 칩니다.

   ```prompt
   설명이 파일 이름을 되풀이한 줄이 셋 있어.
   그 셋은 안을 다시 읽고, 「이 파일이 없으면 사람이 무엇을 해야 하나」로 적어 줘.
   ```

3. 23.1 의 쓰임 표시 시킬 말을 책 그대로 칩니다. 이 과제에서는 칸 이름을 「쓰임」으로, 값을 예·아니오로 정합니다.

   ```prompt
   목록의 각 줄에 「최근 석 달 안에 실제로 돌렸거나 읽었나」를 표시해 줘.
   돌린 흔적은 그 파일이 만들어 내는 결과 파일의 날짜로 판단해 줘.
   ```

   ```prompt
   그 칸 이름은 「쓰임」으로 하고, 값은 「예」나 「아니오」 둘 중 하나로만 적어 줘.
   ```

4. 23.1 의 겹치는 짝 시킬 말을 책 그대로 칩니다.

   ```prompt
   목록에서 같은 일을 하는 파일이 둘 이상인 곳을 찾아 줘.
   찾으면 짝으로 묶고, 그중 어느 쪽이 지금 쓰이는지 표시해 줘.
   ```

5. 채점기로 확인 목록을 띄웁니다.

   ```
   python grader/check.py 23-01
   ```

## 스스로 확인할 것

- □ 도구목록.xlsx 의 파일 이름 줄 수가 폴더에 실제로 있는 파일 수와 같다(도구목록.xlsx 자신과 `~$` 로 시작하는 잠금 파일은 빼고 센다)
- □ 폴더에 있는데 목록에 없는 파일, 목록에 있는데 폴더에 없는 파일이 하나도 없다
- □ 「하는 일」 칸이 파일 이름을 말만 바꿔 되풀이한 줄이 없다 — 있었다면 「이 파일이 없으면 사람이 무엇을 해야 하나」로 다시 받았다
- □ 「쓰임」 칸이 예·아니오 둘 중 하나이고, 고친 날이 아니라 «결과가 나온 날» 로 판단했다
- □ 같은 일을 하는 파일 짝을 찾았으면 지우지 않고, 한쪽에 「이제 이것이 한다」를 적었다

폴더 안의 파일은 탐색기에서 그 폴더를 열어 직접 세고, 목록의 줄 수와 댑니다.

## 확인법 — 23장에서 배운 것

- 「**「없으면 무엇을 해야 하나」로 물으면 대신해 주는 일이 드러난다.**」
- 「**안 열어 봤다는 것이 안 쓴다는 뜻은 아니다.**」 · 「**고친 날이 아니라 «결과가 나온 날» 로 본다.**」
- 「**겹치면 지우지 않고 한쪽에 「이제 이것이 한다」를 적는다.**」

## 채점기가 이 과제를 못 보는 이유

기대값이 여러분 폴더에 따라 달라집니다. 목록과 폴더를 대 보는 채점 규칙(폴더 목록 대조)이 아직 채점기에 없습니다.
그래서 스스로 확인하는 과제로 두었습니다.

## 여기서 쓴 엑셀 기능

없다. 이 절은 폴더와 파일만 다룹니다(목록을 담는 통합 문서 하나만 만듭니다).
