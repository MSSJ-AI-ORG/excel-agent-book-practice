# 05-01 세는 기준을 적어 구조 목록 받기

- **어느 장**: 5장 「5.1 시트·이름정의·표를 목록으로 뽑기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 열지 않습니다. 이 과제는 구조만 읽히고, 관리대장 파일은 사본도 만들지 않습니다.
- **낼 파일**: `05-01_구조.xlsx` (새로 만드는 엑셀 파일)

---

## 왜 하나

5.1 에서 물려받은 파일을 열지 않고 목록으로 받았습니다. 시트·이름 정의·표·차트가 몇 개인지.

그런데 이름 정의는 세는 쪽마다 개수가 달랐습니다. 이름 관리자를 직접 열면 넷이 보이고,
엑셀을 제어해 세면 다섯이 나올 때가 있습니다. 다섯 번째는 엑셀이 파일을 열 때 스스로 만든 **숨김 이름**입니다.

이 과제에서는 **무엇을 세는지 적어서** 개수를 받고, 그 개수를 파일에 남깁니다.
채점기가 원본을 따로 세어 대 봅니다.

## 할 일

1. 저장소 폴더(이 README 가 있는 곳 두 단계 위)에서 명령 프롬프트를 열고 `claude` 를 실행합니다.

2. 5.1 의 첫 시킬 말을 칩니다. 책의 「작업 폴더의 관리대장.xlsx」 자리만 이 저장소의 파일 이름으로 바꿨습니다.

   ```prompt
   practice 폴더의 부서 관리대장.xlsx 를 열지 말고 구조만 읽어서,
   시트·이름 정의·표·차트를 목록으로 만들어 줘.
   각 항목마다 어디에 있는지 위치도 함께 적어 줘. 값은 바꾸지 마.
   ```

3. 세는 기준을 적는 시킬 말을 책 그대로 칩니다.

   ```prompt
   이름 정의를 세되, 숨김 이름은 빼고 이름 관리자에 보이는 것만 세어 줘.
   숨김 이름이 있으면 개수와 이름을 따로 알려 줘.
   ```

4. 받은 목록을 파일로 남깁니다. 아래는 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   이 폴더에 새 엑셀 파일 「05-01_구조.xlsx」를 만들고, 시트 이름을 「구조」로 해 줘.
   A1 에 「시트 수」, A2 에 「이름 정의 수」, A3 에 「표 수」, A4 에 「차트 수」라고 적고,
   B1:B4 에 방금 받은 개수를 적어 줘. 이름 정의 수는 숨김 이름을 뺀 것으로.
   A6·B6·C6 에 「이름」·「가리키는 곳」·「값」을 적고, 7행부터 이름 정의를
   이름 관리자에 보이는 차례(가나다순)로 한 줄에 하나씩 적어 줘.
   「값」 칸에는 이름이 칸 하나나 고정값을 가리키면 그 값을, 여러 칸을 가리키면 「(범위)」라고 적어 줘.
   관리대장 파일은 열지도 말고 고치지도 마.
   ```

5. 엑셀에서 `practice/부서 관리대장.xlsx` 를 **읽기 전용으로** 열고 [수식] - [이름 관리자]를 눌러 봅니다.
   보이는 이름 수를 구조!B2 와 댑니다. 닫을 때 저장하지 않습니다.

6. 채점합니다.

   ```
   python grader/check.py 05-01 05-01_구조.xlsx
   ```

## 확인법 — 5.1 에서 배운 것

- 「「몇 개야?」라고 묻지 않는다」 — 3번에서 «숨김 이름은 빼고 이름 관리자에 보이는 것만»이라고 세는 기준을 적었는지 봅니다.
- 「셀을 가리키지 않고 값을 직접 담은 이름」 — `성과가산` 이 그런 이름입니다. 「가리키는 곳」이 칸 주소가 아니라 고정값으로 적혔는지 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「구조」 시트가 있다 | — |
| 구조!B1 시트 수 | 채점기가 원본의 시트를 직접 센다 |
| 구조!B2 이름 정의 수 | 채점기가 원본에서 숨김이 아닌 이름 정의를 직접 센다 |
| 구조!B3 표 수 · B4 차트 수 | 원본에서 센 개수. 세는 스크립트가 [`_expected.py`](_expected.py) 에 있다 |
| 구조!A7:A10 이름 네 개의 차례 | 원본 이름 정의를 가나다순으로 늘어놓은 것 — `_expected.py` |
| 구조!C7 기준요율의 값 · C9 성과가산의 값 | 채점기가 원본 이름 정의를 직접 읽는다(기준요율은 가리키는 칸의 값, 성과가산은 담긴 고정값) |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

## 스스로 확인할 것

- □ 「숨김 이름은 빼고 이름 관리자에 보이는 것만」을 붙여 시켰고, 숨김 이름은 따로 받았다(없으면 없다는 답)
- □ [수식] - [이름 관리자]를 직접 열어 이름이 몇 개 보이는지 구조!B2 와 댔다

## 막혔을 때

`solution/` 에 정답 예시 파일이, `wrong/` 에 흔한 실수 하나(숨김 이름까지 세어 이름 정의 수를 5 로 적은 파일)가 있습니다.
`wrong/` 파일을 채점기에 넣으면 어느 항목이 ✗ 로 나오는지 볼 수 있습니다. 출력 원문은 [`_verify.txt`](_verify.txt) 에 있습니다.
