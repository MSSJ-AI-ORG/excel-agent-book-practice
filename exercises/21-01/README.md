# 21-01 여덟 줄짜리 검사기

- **어느 장**: 21장 「21.1 합계·건수가 맞는지 스스로 세게 하기」 · 「21.2 값의 범위·자릿수를 벗어나면 잡아내기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `21-01_검사기.xlsx`

---

## 왜 하나

21장의 검사기는 「**시트 한 장에 수식 몇 줄**」입니다. 이 과제에서 여덟 줄을 만듭니다.
그리고 21.1 의 두 문장을 채점기가 칸마다 확인합니다.

- 「**「수식으로」를 붙인다.**」 — 값(B열)은 수식이어야 합니다.
- 「**기준은 수식이 아니라 숫자로 적는다.**」 — 기준(C열)은 손으로 적은 숫자여야 합니다. 기준이 수식이면 자료가 바뀔 때 같이 바뀌어 영원히 통과합니다.

여덟 줄은 책 21.3 표의 여덟 항목을 따릅니다. 다만 「금액 자릿수 이상」 대신 21.2 의 「금액이 1억을 넘는 줄」을 씁니다.
자릿수 이상은 기준이 업무마다 달라서 채점기가 셀 수 없기 때문입니다.

## 할 일

1. 사본을 만듭니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 복사해서 「21-01_검사기.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마. 이 과제에서는 사본만 고쳐 줘. 대장 시트는 고치지 마.
   ```

2. 21.1 의 첫 시킬 말을 책 그대로 칩니다.

   ```prompt
   「검사기」 시트를 만들고 다음 세 가지를 세는 수식을 넣어 줘.
   ① 대장에서 부서가 적힌 행이 몇 개인가
   ② 금액 열의 총합이 얼마인가
   ③ 부서가 적혀 있는데 금액이 비어 있는 행이 몇 개인가
   각 줄에 항목 이름과 값을 나란히 두고, 값은 항상 다시 계산되게 수식으로 넣어 줘.
   ```

3. 21.1 의 기준 시킬 말을 책 그대로 칩니다.

   ```prompt
   검사기 시트에 「기준」 열을 하나 더 만들어 줘.
   지금 값을 기준으로 적어 두고, 값이 기준과 다르면 「확인」이라고 표시되게 해 줘.
   기준은 내가 손으로 바꿀 수 있게 숫자로 적어 줘.
   ```

4. 21.2 의 범위 검사 시킬 말과 21.3 의 중복 시킬 말을 책 그대로 칩니다.

   ```prompt
   대장 금액 열에서 있을 수 없는 값을 세는 검사 항목을 더해 줘.
   ① 금액이 음수인 행
   ② 금액이 1억을 넘는 행
   ③ 금액이 0인 행
   각각 몇 건인지 세고, 0이 아니면 「확인」이 뜨게 해 줘.
   ```

   ```prompt
   대장에서 일자·부서·금액이 모두 같은 행이 있는지 세어 줘.
   몇 건인지 세고, 있으면 몇 행과 몇 행인지 알려 줘.
   ```

5. 여덟 줄로 모양을 맞춥니다. 이 과제에서 새로 붙인 시킬 말입니다. 채점기가 칸 위치로 찾기 때문에 순서를 지킵니다.

   ```prompt
   검사기 시트를 이렇게 정리해 줘.
   1행 머리글: 「항목」「값」「기준」「판정」
   2~9행은 이 순서로 여덟 줄:
   부서가 적힌 줄 수 / 금액 총합 / 부서는 있는데 금액이 빈 줄 수 / 금액이 음수인 줄 수 /
   금액이 1억을 넘는 줄 수 / 부서 표기 가짓수 / 부서는 있는데 담당이 빈 줄 수 /
   중복 줄 수(일자·부서·금액이 모두 같은 줄의 수)
   값(B열)은 수식, 기준(C열)은 지금 값을 숫자로, 판정(D열)은 값이 기준과 같으면 「통과」, 다르면 「확인」.
   금액이 0인 줄은 이 여덟 줄에서 빼도 돼.
   ```

   이어서 21.1 의 열 너비 시킬 말을 책 그대로 칩니다.

   ```prompt
   검사기 시트의 열 너비를 값이 다 보이게 맞춰 주고,
   앞으로 값을 비교할 때는 화면에 보이는 글자가 아니라 셀에 든 값으로 비교해 줘.
   ```

6. `21-01_검사기.xlsx` 를 **엑셀로 한 번 열고, 저장하고, 닫습니다.**
   클로드가 파이썬으로 저장한 파일에는 수식의 계산 결과가 비어 있을 수 있습니다(25.1).

7. 채점합니다.

   ```
   python grader/check.py 21-01 21-01_검사기.xlsx
   ```

## 확인법 — 21장에서 배운 것

- 「**「수식으로」를 붙인다.**」 · 「**기준은 수식이 아니라 숫자로 적는다.**」 — 채점기가 B열과 C열을 칸마다 봅니다.
- 「**검사기는 화면이 아니라 값으로 판정한다.**」 — 채점기도 칸에 든 값으로 댑니다. `#####` 로 보여도 값은 읽힙니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「검사기」 시트가 있다 | — |
| 여덟 줄 모두 B 는 수식, C 는 손으로 적은 값, D 는 「통과」 | — |
| 여덟 줄의 B 값 · C 값 | 원본 대장의 입력 칸에서 채점기가 직접 센다 — 부서가 적힌 줄 수 · 금액 합 · 부서는 있고 금액이 빈 줄 · 금액 &lt; 0 · 금액 &gt; 1억 · 서로 다른 부서 표기 수 · 부서는 있고 담당이 빈 줄 |
| 8번 줄(중복 줄 수)의 B·C = 0 | 채점기에 아직 중복을 세는 방법이 없어 0 을 적었다. 그 0 은 `_expected.py` 가 원본에서 따로 센 값 |
| 사본의 대장 시트가 한 칸도 안 바뀌었다 · practice 원본이 그대로다 | 원본과 칸마다 · 원본 지문 |

`!` 가 나오면 6번(엑셀로 열고 저장)을 하지 않은 것입니다. 틀린 것이 아닙니다.

## 정답·오답 예시

- `solution/21-01_검사기.xlsx` — 원본 사본에 엑셀로 검사기 여덟 줄을 실제로 넣고 저장한 파일. 전부 ✓.
