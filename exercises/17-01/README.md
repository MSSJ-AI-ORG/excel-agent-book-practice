# 17-01 판단하지 말고 세기만 하기

- **어느 장**: 17장 「17.1 내 코드에서 되풀이되는 방식 찾아내기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: 16-01 에서 만든 `코드모음` 폴더(〔대장m〕에서 꺼낸 `.bas` 네 개)
- **낼 파일**: `17-01_버릇세기.xlsx`

---

## 왜 하나

코드의 버릇은 읽어서는 안 보이고 **세어야 보입니다.**
17.1 은 세면서 판단을 같이 시키지 않습니다. 판단을 같이 시키면 「이렇게 고치세요」가 돌아오는데, 지금 하려는 것은 고치는 것이 아니라 알아내는 것이기 때문입니다.
이 과제에서는 〔대장m〕의 네 모듈을 세고, 센 값을 시트에 남깁니다.

## 할 일

1. 17.1 의 시킬 말을 책 그대로 칩니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   코드모음 폴더의 파일들을 읽고 다음을 세어 줘.
   ① 프로시저 이름이 어떤 방식으로 지어졌나 — 방식별로 몇 개씩
   ② 파일마다 주석 줄이 전체의 몇 퍼센트인가
   ③ Option Explicit 을 쓴 파일이 몇 개인가
   ④ On Error 로 오류를 처리한 파일이 몇 개인가
   ⑤ 코드에 숫자가 직접 박힌 줄이 몇 개인가
   ★세기만 하고 좋다 나쁘다 판단은 하지 마.
   ```

2. 과제에서 붙인 말로 센 값을 시트에 적게 합니다. 주석 비율은 **세는 방법을 정해서** 시킵니다.

   ```prompt
   센 값을 「17-01_버릇세기.xlsx」의 「세기」 시트에 적어 줘.
   A1~A4 에 이름, B1~B4 에 값 — 모듈 수 · 프로시저 수 · Option Explicit 쓴 모듈 수 · On Error 쓴 모듈 수.
   A6 「모듈」, B6 「주석 줄 비율」을 머리글로 두고, 7행부터 모듈 이름 가나다순으로 한 줄씩 적어 줘.
   주석 줄 비율은 «'로 시작하는 줄 수 ÷ 빈 줄을 뺀 전체 줄 수»로 세고, 0.25 처럼 소수로 적어 줘(표시 형식은 백분율이어도 돼).
   Attribute 로 시작하는 줄은 VBA 편집기에 안 보이는 줄이니 세지 마.
   ```

3. 채점합니다.

   ```
   python grader/check.py 17-01 17-01_버릇세기.xlsx
   ```

4. **내 매크로 파일로도 해 보기** — 내 코드모음에서 같은 것을 세어 봅니다. 섞여 있다는 것도 적습니다.

## 확인법 — 17장에서 배운 것

- 「버릇은 세어야 보인다」
- 「★세기만 하고 좋다 나쁘다 판단은 하지 마.」
- 「섞여 있다는 것도 사실이다」 — 「통일해야 한다」로 바로 넘어가지 않고, 섞여 있다는 사실부터 기록합니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「세기」 시트가 있다 | — |
| B1~B4 의 네 개수 | `_expected.py` 가 원본 파일에서 코드를 따로 꺼내 센 값(주석 줄은 빼고 `Option Explicit`·`On Error` 를 찾는다) |
| A7~A10 모듈 이름(가나다순) | 같다 |
| B7~B10 모듈별 주석 줄 비율 | 같은 정의로 센 값. ±0.01(1%p)까지는 맞은 것으로 본다 |
| practice 원본이 그대로다 | 원본 파일 지문 |

## 여기서 쓴 엑셀 기능

VBA `Option Explicit` · `On Error` · 주석(`'`) · 백분율 표시 형식
