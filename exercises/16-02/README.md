# 16-02 「호출 안 됨」과 「안 씀」을 가르고 상태 칸 걸기

- **어느 장**: 16장 「16.3 겹치는 매크로 묶고 버릴 것 가르기」 · 「16.4 목록을 시트로 만들어 찾아 쓰게 하기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: 16-01 에서 만든 `16-01_매크로목록.xlsx` 와 `코드모음` 폴더
- **낼 파일**: `16-02_매크로목록.xlsx`

---

## 왜 하나

목록이 생기면 버려도 될 것 같은 프로시저가 눈에 띕니다. 가장 흔한 근거가 「어느 코드에서도 부르지 않는다」입니다.
그런데 16.3 에서 말한 대로 **「호출되지 않는다」가 「안 쓴다」가 아닙니다.** 단추에 걸려 있거나, 시트 이벤트에서 부르거나, 다른 파일에서 부를 수 있습니다.
이 과제에서는 호출 여부를 따로 적고, 확인이 안 되는 것은 「모름」으로 남기고, 정리후보에는 근거를 붙입니다.

## 할 일

1. 16-01 의 목록을 `16-02_매크로목록.xlsx` 로 복사하게 합니다(과제에서 붙인 말입니다). 16-01 파일은 그대로 둡니다.

2. 16.3 의 찾기 시킬 말을 책 그대로 칩니다.

   ```prompt
   ① 어느 프로시저에서도 호출되지 않는 것
   ② 전체가 주석 처리된 것
   ③ 이름에 Test·Temp·old 가 들어간 것
   셋을 각각 찾아서 목록으로 만들어 줘. 지우지는 마.
   ```

3. 16.3 의 이어지는 시킬 말을 책 그대로 칩니다.

   ```prompt
   호출되지 않는 것으로 나온 프로시저에 대해,
   버튼·시트 이벤트·다른 파일에서 부를 가능성이 있는지도 확인해 줘.
   확인이 안 되는 것은 「모름」으로 남겨 줘.
   ```

4. 과제에서 붙인 말로 목록에 칸을 더합니다.

   ```prompt
   매크로목록 시트에 칸 셋을 더해 줘.
   F 호출됨 — 다른 프로시저의 코드 안에서 그 이름을 부르면 「예」, 아니면 「아니오」. 자기 자신 안에 나오는 이름은 세지 마.
   G 상태 — 사용중·모름·정리후보 셋 중 하나만 고를 수 있게 데이터 유효성 검사 목록을 걸어 줘.
   H 근거 — 상태를 그렇게 정한 이유. 정리후보인 줄은 반드시 적어 줘.
   ```

5. 16.4 의 시킬 말도 칩니다.

   ```prompt
   앞으로 매크로를 새로 만들거나 고치면 매크로목록에도 한 줄 추가하거나 고쳐 줘.
   그리고 한 달에 한 번, 목록에 있는 파일이 실제로 있는지 확인해 줘.
   ```

6. 채점합니다.

   ```
   python grader/check.py 16-02 16-02_매크로목록.xlsx
   ```

7. **내 매크로 파일로도 해 보기** — 16-01 에서 만든 내 목록에 같은 칸 셋을 더해 봅니다.

## 확인법 — 16장에서 배운 것

- 「「호출 안 됨」이 「안 씀」이 아니다」 — 버튼에 연결돼 있거나, 시트 이벤트에서 부르거나, 다른 파일에서 부를 수 있습니다. 코드만 봐서는 안 보입니다.
- 「두 방향을 다 본다」 — 목록에 있는데 파일이 없는 것과, 파일은 있는데 목록에 없는 것.
