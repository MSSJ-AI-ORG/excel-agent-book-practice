# 09-01 「아래로 복사해도 항상 ~을 보게」를 말로 시키기

- **어느 장**: 9장 「9.2 상대·절대 참조를 의도대로 고치기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `09-01_참조.xlsx`

---

## 왜 하나

`$` 는 붙이면 되는 것 같고 안 붙이면 안 되는 것 같아서, 안 되면 붙여 보는 식으로 쓰기 쉽습니다.

9.2 에서 같은 계산을 두 가지로 적고 한 칸 아래로 복사해 봤습니다. `$` 를 붙인 쪽은 3행에 복사해도 2행 값을 보여 줬습니다.
**오류 표시 없이, 틀린 줄의 숫자가** 들어갑니다.

기호를 외우는 대신 문장을 씁니다. 「아래로 복사해도 항상 ~을 보게」. 이 과제에서 그 문장으로 수식을 받고, 열 줄 모두 제 줄을 보는지 채점기가 댑니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 복사해서 「09-01_참조.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「매출 시트」라고 하면 이 사본의 매출 시트를 가리키는 걸로 해 줘.
   ```

2. 9.2 의 시킬 말 둘을 책 그대로 칩니다.

   ```prompt
   매출 시트 G2 에 `=C2*D2` 를, H2 에 `=$C$2*$D$2` 를 넣어 줘.
   두 칸의 값이 같은지 알려 줘.
   ```

   ```prompt
   G2 와 H2 를 복사해서 G3 과 H3 에 붙여 넣어 줘.
   붙여 넣은 뒤 두 칸의 수식과 값을 알려 줘.
   ```

   H3 이 3행이 아니라 2행 값을 보이는지 봅니다. 보았으면 지우게 합니다(이 과제에서 새로 붙인 말).

   ```prompt
   시험으로 넣은 G2:H3 은 지워 줘.
   ```

3. 9.2 의 말로 시키는 시킬 말을 책 그대로 칩니다. 이어서 H열을 이 과제에서 새로 붙인 말로 정해 줍니다.

   ```prompt
   G열 수식을 아래로 복사해도 각 행의 수량과 단가를 곱하게 해 줘.
   세율 10% 는 K1 한 칸에 적어 두고, 아래로 복사해도 항상 K1 을 보게 해 줘.
   ```

   ```prompt
   G2:G11 에 각 행의 수량×단가를, H2:H11 에는 G열 금액에 K1 세율을 곱한 세액을 수식으로 넣어 줘.
   J1 에는 「세율」이라고 적어 줘. A:E열은 고치지 마.
   ```

4. `09-01_참조.xlsx` 를 엑셀로 엽니다. H11 을 눌러 수식이 `$K$1` 을 보는지 봅니다. 저장하고 닫습니다.

5. 채점합니다.

   ```
   python grader/check.py 09-01 09-01_참조.xlsx
   ```

## 확인법 — 9.2 에서 배운 것

- 「H3 은 오류가 아니다」 — 오류 표시도 없고 숫자도 멀쩡한데 틀린 줄의 값입니다. 2번에서 직접 봅니다.
- 「「아래로 복사해도 항상 ~을 보게」가 절대 참조를 말로 표현한 것」 — 3번.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| G2·G11·H2·H11 이 수식이다(아래로 복사됐다) | — |
| K1 이 0.1 이고, 수식이 아니라 적어 둔 값이다 | 시킬 말의 10% |
| G2:G11 줄마다 그 줄의 수량×단가 | 채점기가 원본 매출의 그 줄 C×D 를 직접 곱한다 |
| H2:H11 줄마다 그 줄 금액×10% | 채점기가 원본 그 줄 C×D 에 시킨 세율 10% 를 곱한다 |
| 매출 A1:E12 가 원본과 같다 | 원본과 칸마다 댄다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

`!` 가 나오면 엑셀로 한 번 열고 저장하지 않은 것입니다. 틀린 것이 아닙니다.

## 스스로 확인할 것

- □ G2:H3 시험에서 H3(=$C$2*$D$2)이 오류 없이 2행 값 3,870,000 을 보이는 것을 본 뒤 지웠다
- □ G열 수식이 줄마다 자기 줄을 가리키고(=C5*D5 처럼), H열 수식이 $K$1 을 가리킨다

## 막혔을 때

`solution/` 에 정답 예시 파일이, `wrong/` 에 흔한 실수 하나(H열이 K1 을 절대 참조로 보지 않아, 아래로 복사하자 K2·K3… 을 보게 된 파일)가 있습니다.
H3 부터 H11 까지 아홉 줄이 한꺼번에 ✗ 가 됩니다 — 실수 하나가 복사된 줄 수만큼 번진 것입니다. 채점기 출력 원문은 [`_verify.txt`](_verify.txt) 에 있습니다.
