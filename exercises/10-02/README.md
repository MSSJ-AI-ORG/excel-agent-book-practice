# 10-02 찾아오기·여러 조건·중복 빼고 세기, 그리고 함수 메모

- **어느 장**: 10장 「10.2 다른 표에서 값 찾아오게 시키기」 · 「10.3 여러 조건을 겹쳐 세게 시키기」 · 「10.4 받은 수식의 함수 이름과 뜻 배우기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `10-02_함수.xlsx`

---

## 왜 하나

10장에서 수식 넷을 받았습니다. 찾아오기(`VLOOKUP`), 여러 조건으로 더하기(`SUMIFS`), 같은 사람은 한 번만 세기.

그중 `VLOOKUP` 은 마지막 `FALSE` 를 빼면 **넷 중 셋은 맞고 하나만 틀립니다.** 이 표에서는 「모니터」가 그 하나입니다.
틀린 값도 표 안에 실제로 있는 단가라 눈에 잘 안 띕니다. 그래서 이 과제는 찾는 품목을 일부러 「모니터」로 둡니다.

마지막으로 받은 함수를 「함수 메모」 시트에 정리해 파일 안에 남깁니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 복사해서 「10-02_함수.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「매출 시트」라고 하면 이 사본의 매출 시트를 가리키는 걸로 해 줘.
   ```

2. 10.2 의 시킬 말을 책 그대로 칩니다. 이어서 찾을 품목을 이 과제에서 새로 붙인 말로 정해 줍니다.

   ```prompt
   품목 이름을 주면 그 품목의 단가를 찾아오는 수식을 VLOOKUP 으로 만들어 줘.
   찾는 품목은 N3 칸에 적을 테니까, 수식은 N4 에 넣어 줘.
   ```

   ```prompt
   N3 에는 「모니터」라고 적어 줘.
   ```

3. 10.2 의 둘째 시킬 말을 책 그대로 칩니다. 옆 칸은 N5 로 정해 줍니다(이 과제에서 새로 붙인 말).

   ```prompt
   방금 수식에서 마지막 FALSE 를 빼면 무엇이 달라지는지 설명해 주고,
   실제로 빼 본 결과도 옆 칸에 넣어서 비교해 줘.
   ```

   ```prompt
   FALSE 를 뺀 수식은 N5 에 넣어 줘. N4 는 그대로 둬.
   ```

4. 10.3 의 시킬 말 둘을 책 그대로 칩니다. 담당자 수를 둘 칸은 이 과제에서 새로 붙인 말로 정해 줍니다.

   ```prompt
   담당자가 「이현우」이면서 품목이 「마우스」인 행의 수량을 더해 줘.
   수식으로 만들어서 N6 에 넣어 줘.
   ```

   ```prompt
   담당자별로 거래가 몇 건인지 세는 수식을 만들어 줘.
   그리고 담당자가 모두 몇 명인지도 세어 줘 — 같은 사람은 한 번만.
   ```

   ```prompt
   담당자가 모두 몇 명인지 세는 수식은 N7 에 넣어 줘. A:E열은 고치지 마.
   ```

5. 10.4 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   이 시트에서 오늘 만든 수식을 전부 찾아서,
   「함수 이름 / 하는 일 / 인수 / 주의할 점」 네 칸짜리 표로 만들어 줘.
   그 표를 「함수 메모」라는 새 시트에 남겨 줘.
   ```

6. `10-02_함수.xlsx` 를 엑셀로 엽니다. N4 와 N5 의 값이 다른지 봅니다. N3 을 「노트북」으로 바꿔 보면 둘이 같아지는 것도 볼 수 있습니다. **N3 을 다시 「모니터」로 돌려놓고** 저장한 뒤 닫습니다.

7. 채점합니다.

   ```
   python grader/check.py 10-02 10-02_함수.xlsx
   ```

## 확인법 — 10장에서 배운 것

- 「넷째가 없으면 조용히 틀린다」 — 6번에서 N4 와 N5 를 댑니다.
- `SUMIF` 와 `SUMIFS` 는 인수 순서가 반대입니다. `SUMIFS` 는 **더하는 범위가 첫째 자리**입니다.
- 「「안 통하는 경우」를 물으면 그 함수의 경계가 드러난다」 — 함수 메모의 「주의할 점」 칸에 그 답을 남깁니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| N3 이 「모니터」 | 과제의 품목 |
| N4 가 VLOOKUP 수식이고, 값 = N3 품목의 단가 | 채점기가 원본 매출 B열에서 **제출 파일 N3** 의 품목을 찾아 같은 줄 D열 단가를 읽는다 |
| N6 이 SUMIFS 수식이고, 값 = 이현우·마우스 수량 합 | 채점기가 원본에서 두 조건에 맞는 줄의 수량을 직접 더한다 |
| N7 이 수식이고, 값 = 담당자 수(같은 사람은 한 번만) | 채점기가 원본 A2:A11 의 서로 다른 이름을 직접 센다 |
| 「함수 메모」 시트가 있다 | — |
| 매출 A1:E12 가 원본과 같다 · practice 의 원본이 그대로다 | 원본과 댄다 |

## 스스로 확인할 것

- □ N4 수식의 넷째 자리에 FALSE(또는 0)가 있다
- □ N5(FALSE 를 뺀 수식)의 값이 N4 와 다르다 — 모니터는 FALSE 가 없으면 엉뚱한 단가가 나온다
- □ 「함수 메모」 시트에 SUMIF · VLOOKUP · SUMIFS · SUMPRODUCT 가 함수 이름 / 하는 일 / 인수 / 주의할 점 네 칸으로 적혀 있다

채점기는 아직 수식 «글자» 안의 넷째 인수와 함수 메모의 글을 읽지 못합니다. 그래서 위 세 줄은 눈으로 봅니다.
