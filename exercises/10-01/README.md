# 10-01 조건을 셀로 빼 두고 직접 한 칸 고쳐 보기

- **어느 장**: 10장 「10.1 조건에 맞는 값만 더하게 시키기」 · 「10.4 받은 수식의 함수 이름과 뜻 배우기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `10-01_조건합.xlsx`

---

## 왜 하나

10.1 에서 함수 이름을 모른 채 「이현우인 행의 금액만 더해 줘」라고 말해 `SUMIF` 수식을 받았습니다.
그리고 조건 「이현우」를 수식 밖, 칸 하나로 뺐습니다. 수식을 고치는 것과 칸에 적힌 값을 고치는 것은 위험도가 다르기 때문입니다.

이 과제의 마지막 한 칸은 **여러분이 직접** 고칩니다. 10.4 에서 「알려만 줘, 고치지는 마」라고 한 이유입니다.
채점기는 N1 에 적힌 이름으로 원본을 다시 세어, N2 가 정말 N1 을 따라가는지 봅니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 복사해서 「10-01_조건합.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「매출 시트」라고 하면 이 사본의 매출 시트를 가리키는 걸로 해 줘.
   ```

2. 10.1 의 시킬 말 둘을 책 그대로 칩니다.

   ```prompt
   매출 시트에서 담당자가 「이현우」인 행의 금액만 더해 줘.
   수식으로 만들어서 N2 칸에 넣고, 어떤 수식을 썼는지도 알려 줘.
   ```

   ```prompt
   조건인 「이현우」를 수식에 직접 쓰지 말고, N1 칸에 담당자 이름을 적으면
   그 담당자 금액이 나오게 고쳐 줘.
   ```

3. 10.4 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   N2 수식을 내가 직접 고쳐서 「강민서」 금액이 나오게 하려고 해.
   어디를 어떻게 고치면 되는지 알려만 줘. 고치지는 마.
   ```

4. `10-01_조건합.xlsx` 를 엑셀로 열고, 받은 설명대로 **직접** 고칩니다. N1 에 `강민서` 를 적고 Enter 를 누릅니다.
   N2 값이 바뀌는지 봅니다. 저장하고 닫습니다.

5. 채점합니다.

   ```
   python grader/check.py 10-01 10-01_조건합.xlsx
   ```

## 확인법 — 10.1·10.4 에서 배운 것

- 「「수식으로 만들어서」를 꼭 붙인다」 — 이 말이 없으면 계산한 숫자만 돌아옵니다. 채점기는 N2 가 `SUMIF` 수식인지 봅니다.
- 「조건을 셀로 빼는 것이 이 장에서 가장 자주 쓰는 손질」 — N1 을 바꾸면 N2 가 따라 바뀌어야 합니다.
- 「「알려만 줘, 고치지는 마」」 — 4번은 여러분 손으로 합니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| N2 가 SUMIF 수식이다 | — |
| N1 이 「강민서」이고, 수식이 아니라 적어 둔 이름이다 | 과제의 이름 |
| N2 값 = N1 에 적은 담당자의 금액 합계 | 채점기가 **제출 파일 N1 의 이름**으로 원본 매출에서 줄을 골라 수량×단가를 직접 더한다 |
| 매출 A1:E12 가 원본과 같다 | 원본과 칸마다 댄다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

## 스스로 확인할 것

- □ N2 수식에 「이현우」나 「강민서」가 글자로 박혀 있지 않고 N1 을 가리킨다
- □ 「알려만 줘. 고치지는 마.」를 붙여 받았고, N1 은 내가 손으로 고쳤다

## 막혔을 때

`solution/` 에 정답 예시 파일이, `wrong/` 에 흔한 실수 하나(조건 「이현우」를 수식에 박아 둔 채 N1 만 「강민서」로 바꾼 파일)가 있습니다.
N1 은 강민서인데 N2 는 여전히 이현우 금액이라, N2 항목만 ✗ 가 됩니다. 채점기 출력 원문은 [`_verify.txt`](_verify.txt) 에 있습니다.
