# 19-01 지우기 전에 미리 보고, 지우는 대신 옮기기

- **어느 장**: 19장 「19.2 실행 전에 무엇이 지워지는지 먼저 받기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `19-01_옮기기.xlsx`

---

## 왜 하나

19.2 에서 지우기 전에 할 일 세 가지를 배웠습니다.
지워질 줄을 먼저 받아 보기, 개수가 이상하면 멈추기, 지우는 대신 다른 시트로 옮기기.
이 과제에서 셋을 한 번에 해 봅니다.

이 대장에는 함정이 하나 있습니다. **구분(C열)에는 「특판」이 한 줄도 없습니다.**
「특판」이라는 글자는 비고(F열)에 한 번 나올 뿐입니다.
그래서 4번의 「특판 행을 지워 줘」는 0건이어야 하고, 멈춰야 맞습니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본부터 만듭니다. 아래는 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 복사해서 「19-01_옮기기.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마. 이 과제에서는 사본만 고쳐 줘.
   ```

2. 19.2 의 첫 시킬 말을 책 그대로 칩니다. 셋째 줄(멈춤)을 빼지 않습니다.

   ```prompt
   대장에서 2026년 1월 자료를 지워 줘.
   ★지우기 전에, 지워질 행이 몇 개이고 각 행에 무엇이 적혀 있는지 먼저 보여 줘.
   보여 준 다음에 내가 「진행」이라고 하면 그때 지워 줘.
   ```

   > [그림 19-01-A] 지워질 행 목록을 보여 주고 멈춘 화면 (촬영 예정)

   받은 목록을 사본과 대 봅니다. 대장의 일자 칸은 적힌 모양이 섞여 있습니다(`2026-01-08` · `2026.01.22` · `2026년 2월 14일`).
   점으로 적힌 1월 날짜가 목록에서 빠지지 않았는지 봅니다.

3. 아직 「진행」이라고 하지 않습니다. 19.2 의 영향 확인 시킬 말을 책 그대로 칩니다.

   ```prompt
   지우면 다른 시트의 어느 값이 바뀌는지도 같이 알려 줘.
   바뀌기 전 값과 바뀐 뒤 값을 나란히 보여 줘.
   ```

4. 이제 옮겨 두고 지우게 합니다. 첫 줄은 책 그대로, 둘째·셋째 줄은 이 과제에서 새로 붙인 말입니다.

   ```prompt
   지우기 전에 지워질 행들을 「삭제_2026-09-19」 시트에 복사해 두고 지워 줘.
   보관 시트 1행에는 대장의 머리글(일자·부서·구분·금액·담당·비고)을, 2행부터 옮긴 줄을 그대로 적어 줘.
   대장에서는 그 행들을 통째로 지워서 아래 줄이 위로 올라오게 해 줘.
   ```

   보관 시트 이름은 책에 적힌 그대로 둡니다. 채점기가 이 이름으로 시트를 찾습니다.
   목록이 맞으면 「진행」이라고 합니다.

5. 19.2 의 멈춤 시킬 말을 책 그대로 칩니다.

   ```prompt
   지울 행이 0건이거나, 전체 행의 절반이 넘으면 지우지 말고 멈춰서 알려 줘.
   그리고 대장에서 구분이 「특판」인 행을 지워 줘.
   ```

   > [그림 19-01-B] 개수가 이상해서 멈춘 화면 (촬영 예정)

   구분이 「특판」인 줄은 0건입니다. 멈추고 알려 왔으면 맞습니다.
   비고가 「특판」인 줄을 지웠다면 그것이 이 과제가 겨눈 실수입니다. 사본을 처음부터 다시 만들어 합니다.

6. 채점합니다.

   ```
   python grader/check.py 19-01 19-01_옮기기.xlsx
   ```

## 확인법 — 19장에서 배운 것

- 「세 줄이 각각 다르다. 첫 줄은 할 일, 둘째 줄은 미리 보기, 셋째 줄은 **멈춤**이다.」 — 2번에서 목록만 받고 멈췄는지 봅니다.
- 「**0건과 전부**가 가장 위험한 두 값이다.」 — 5번에서 0건에 멈췄는지 봅니다.
- 「**지우는 대신 옮긴다.**」 — 지운 줄이 보관 시트에 남아 있는지 채점기가 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 보관 시트 「삭제_2026-09-19」가 있다 | — |
| 보관 시트 1행이 대장 머리글이다 | 원본 대장!A3 |
| 보관 시트 2~4행의 일자·금액이 원본 대장 4·5·6행과 같다 | 원본 대장의 그 칸. 1월 줄이 4·5·6행이라는 것은 `_expected.py` 가 일자 글자를 날짜로 읽어 따로 센 것 |
| 보관 시트 5행은 비어 있다(1월이 아닌 줄은 옮기지 않았다) | — |
| 대장 첫 줄이 2월 자료(원본 7행)다 | 원본 대장!A7 |
| 대장 6행 금액이 원본 9행(비고 「특판」 줄)과 같다 — 그 줄을 지우지 않았다 | 원본 대장!D9 |
| 대장 16행이 원본 마지막 줄(19행)이고 17행은 비어 있다 — 딱 세 줄만 빠졌다 | 원본 대장!A19·D19 |
| practice 의 원본이 그대로다 | 원본 파일의 지문 |

채점기가 못 보는 것(미리 보기를 받았나, 「진행」 전에 멈췄나, 0건에서 멈췄나)은 채점 결과 아래에 확인 목록으로 나옵니다.

## 정답·오답 예시
