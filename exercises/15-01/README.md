# 15-01 부서별 파일 셋을 한 장으로 합치고 검산하기

- **어느 장**: 15장 「15.2 여러 파일을 열어 한 장으로 모으기」 · 「15.3 결과를 새 파일로 저장하고 이름 규칙 걸기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/받은파일/` 의 세 파일(영업1팀·영업2팀·영업3팀) — 읽기만 합니다. 받은 파일은 저장하지 않습니다.
- **낼 파일**: `부서합계_YYYYMMDD_HHMM.xlsx` (예: `부서합계_20260921_1430.xlsx` — 만든 날짜와 시각)

---

## 왜 하나

매달 부서마다 파일이 오고 그것을 한 장으로 합치는 일이 있습니다. 15.2 에서 말한 대로 합칠 때 가장 조용히 틀리는 것은 **열 순서**입니다.
부서마다 열 순서를 조금씩 다르게 쓰면 금액 칸에 다른 값이 들어가고, 오류는 나지 않습니다.
이 과제에서는 합치기 전에 열 순서를 확인하고, 어느 파일에서 온 줄인지 적고, 합친 뒤 행 수와 금액 합계로 검산합니다.

## 할 일

1. 15.2 의 첫 시킬 말을 책 그대로 칩니다.

   ```prompt
   「받은파일」 폴더의 엑셀 파일들을 열어서, 각 파일의 「대장」 시트 내용을
   한 시트에 이어 붙이는 매크로를 만들어 줘.
   ★먼저 무엇을 할 것인지 단계로 적어 주고, 코드는 그다음에.
   ```

   이 저장소에서는 받은 파일이 `practice/받은파일/` 에 있습니다. 클로드에게 그 폴더를 알려 줍니다.

2. 15.2 의 열 확인 시킬 말을 책 그대로 칩니다.

   ```prompt
   합치기 전에 각 파일의 열 이름과 순서가 같은지 먼저 확인해 줘.
   다른 파일이 있으면 어느 파일이 어떻게 다른지 알려 주고 멈춰 줘.
   ```

   다른 파일이 있다는 답을 받으면, 과제에서 붙인 말로 이어 갑니다.

   ```prompt
   열 순서는 영업1팀 파일의 순서(일자·부서·구분·금액·담당·비고)로 맞춰 줘.
   다른 파일은 열 번호가 아니라 머리글 이름으로 열을 찾아서 붙여 줘.
   파일은 영업1팀 → 영업2팀 → 영업3팀 차례로 붙이고, 합친 시트 이름은 「합친자료」로 해 줘.
   ```

3. 15.2 의 출처·닫기·검산 시킬 말을 책 그대로 칩니다.

   ```prompt
   합칠 때 맨 오른쪽에 「출처파일」 열을 더해서 어느 파일에서 온 행인지 적어 줘.
   그리고 「가져온시각」도 같이 적어 줘.
   ```

   ```prompt
   읽은 파일은 반드시 닫아 줘. 저장하지 말고 닫아 줘.
   그리고 모든 파일을 다 닫았는지 마지막에 확인해서 알려 줘.
   ```

   ```prompt
   합치기 전 각 파일의 행 수와 금액 합계를 미리 세어 두고,
   합친 뒤 전체 행 수와 합계가 그 합과 맞는지 대조해 줘.
   ```

   과제에서 붙인 말(채점기가 볼 수 있게 검산을 파일에 남깁니다):

   ```prompt
   결과 파일에 「검산」 시트를 만들어 줘.
   B1 에 합친 행 수를 =COUNTA(합친자료!A2:A1000) 수식으로, B2 에 합친 금액 합을 =SUM(합친자료!D2:D1000) 수식으로 넣고,
   B3·B4 에 합치기 전에 세어 둔 행 수 합과 금액 합을 적어 줘.
   ```

4. 15.3 의 저장 시킬 말을 책 그대로 칩니다. 이어서 15.3 의 확인 시킬 말 두 개도 칩니다.

   ```prompt
   합친 결과를 새 파일로 저장해 줘.
   파일 이름은 「부서합계_YYYYMMDD_HHMM.xlsx」 로 해 줘.
   ★같은 이름의 파일이 이미 있으면 덮어쓰지 말고 멈춰서 알려 줘.
   ```

   ```prompt
   저장할 때 매크로가 빠지는지 확인해 줘. 빠진다면 그 사실을 알려 주고 진행해 줘.
   ```

   ```prompt
   저장이 끝나면 그 파일을 다시 열어서, 시트 수와 행 수가 맞는지 확인해 줘.
   ```

5. 결과 파일을 **엑셀로 한 번 열고, 저장하고, 닫습니다.**(검산 시트 수식의 계산값이 파일에 들어가게 합니다.)

6. 채점합니다. 파일 이름은 자기가 만든 이름을 씁니다.

   ```
   python grader/check.py 15-01 부서합계_20260921_1430.xlsx
   ```

## 확인법 — 15장에서 배운 것

- 「세 번째가 가장 조용히 틀린다」 — 열 순서가 다르면 엉뚱한 열에 붙고, 오류는 안 납니다.
- 「출처가 없으면 되돌릴 수 없다」 — 어느 부서 자료가 틀렸다는 연락이 오면 출처 열로 찾습니다.
- 「「저장하지 말고」와 「다 닫았는지 확인」 둘 다 필요하다」
- 「합치는 작업은 반드시 검산한다」 — 행이 빠지거나 두 번 들어가도 화면으로는 안 보입니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「합친자료」·「검산」 시트가 있다 · 머리글 D1 「금액」, E1 「담당」, G1 「출처파일」 | 영업1팀 파일의 머리글 |
| 검산 B1 이 COUNTA 수식이고 값 = 세 파일의 데이터 줄 수 합 | 채점기가 받은 파일 세 개에서 일자가 적힌 줄을 직접 센다 |
| 검산 B2 가 SUM 수식이고 값 = 세 파일의 금액 합 | 영업1·2팀은 D열, 영업3팀은 E열(그 파일만 금액·담당 열 순서가 다르다)을 채점기가 직접 더한다 |
| 합친자료 G2 = 영업1팀 파일 이름 | — |
| 영업3팀 첫 줄·마지막 줄이 들어간 행의 금액·담당·출처파일 | 영업3팀 파일의 그 칸을 채점기가 직접 읽는다. 행 번호는 `_expected.py` 가 파일별 줄 수로 센다 |
| 데이터가 끝난 다음 행이 비어 있다 | 머리글이 끼어들거나 줄이 두 번 들어가지 않았나 |
| 받은 파일 세 개가 처음 그대로다 | 파일 지문 |

파일 이름 모양(`부서합계_날짜8자리_시각4자리.xlsx`)과 매크로가 들어 있지 않은지는 채점기가 보지 않습니다. 채점 결과 아래 □ 목록으로 스스로 봅니다.

## 만드는 사람을 위한 기록

- `solution/부서합계_20260922_0001.xlsx`: 엑셀 COM 으로 받은 파일 세 개를 읽기 전용으로 열어 머리글 이름으로 열을 찾아 이어 붙이고(출처파일·가져온시각 포함), 저장하지 않고 닫은 뒤 새 통합 문서로 저장. 다시 열어 시트 2개·마지막 행 16 을 확인했다. 검산 B1:B5 = 15 · 34,320,000 · 15 · 34,320,000 · 맞음. 끝난 뒤 받은 파일 세 개의 지문이 그대로였다.
- `wrong/…xlsx`: 흔한 실수 하나 — 열을 머리글 이름이 아니라 열 번호 그대로 붙였다(영업3팀의 금액과 담당이 뒤바뀐다). 검산 B2 와 영업3팀 줄의 금액·담당 칸이 ✗.
- 카탈로그의 `filename_matches`·`zip_member_absent`·`merged_rows_match_sources` 규칙은 채점기에 없어서, 파일 이름·매크로 없음은 확인 목록으로, 줄 대조는 영업3팀 첫 줄·마지막 줄 대조와 검산 시트로 대신했다.
- 채점 출력 원문: `_verify.txt`
