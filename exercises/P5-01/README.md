# P5-01 매크로 목록에 규칙 판(현행·구판)까지 달아 두기

- **어느 장**: 5부 종합 — 「16.4 목록을 시트로 만들어 찾아 쓰게 하기」 · 「18.4 규칙이 바뀌면 옛 코드도 같이 고치기」
- **5부 종합 과제** · 채점: 자동(auto)
- **시작 파일**: 16-02 에서 만든 `16-02_매크로목록.xlsx` · 18-01 에서 만든 `18-01_규칙검사.xlsx`
- **낼 파일**: `P5-01_매크로목록.xlsx`

---

## 왜 하나

규칙을 정하면 옛 코드를 전부 고치고 싶어집니다. 18.4 는 그러지 않았습니다. 잘 돌던 코드를 규칙에 맞추려다 깨뜨릴 수 있기 때문입니다.
대신 **표시만** 합니다. 목록에 「규칙 판」 칸을 두고 지금 규칙을 지키면 「현행」, 아니면 「구판」이라고 적습니다.
표시가 있으면 다음에 그 코드를 손댈 때 알게 되고, 그 김에 규칙에 맞추면 됩니다.

## 할 일

1. 16-02 의 목록을 `P5-01_매크로목록.xlsx` 로 복사하게 합니다(과제에서 붙인 말입니다). 16-02 파일은 그대로 둡니다.

2. 18.4 의 시킬 말을 책 그대로 칩니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   매크로목록 시트에 「규칙 판」 열을 하나 더해 줘.
   지금 규칙으로 검사해서 통과하면 「현행」, 아니면 「구판」이라고 적어 줘.
   그리고 구판인 것도 지금은 고치지 말고 표시만 해 줘.
   ```

   과제에서 붙인 말(무엇을 «통과»로 볼지 정합니다):

   ```prompt
   규칙 판은 I열에 적어 줘. 판정은 모듈 단위로 해 줘 —
   18-01 결과에서 그 프로시저가 든 모듈이 R2 「있음」이고 R4 통과 수가 프로시저 수와 같으면 「현행」, 아니면 「구판」.
   같은 모듈의 프로시저는 모두 같은 판을 받아.
   ```

3. 18.4 의 이력 시킬 말을 책 그대로 칩니다.

   ```prompt
   코드규칙.md 맨 아래에 「판 이력」을 만들어 줘.
   언제 · 무엇이 바뀌었나 · 왜 바뀌었나.
   ```

4. 채점합니다.

   ```
   python grader/check.py P5-01 P5-01_매크로목록.xlsx
   ```

## 확인법 — 5부에서 배운 것

- 「표시가 있으면 손댈 때 알게 된다」 — 고치려고 일부러 열지는 않습니다.
- 「「왜」가 있어야 다음 사람이 예외를 안 지운다」
- 「「호출 안 됨」이 「안 씀」이 아니다」(16-02) — 규칙 판을 더해도 상태·근거 칸은 그대로 둡니다.
