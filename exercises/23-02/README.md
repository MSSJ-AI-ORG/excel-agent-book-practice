# 23-02 먹는 것·내놓는 것을 적고 돌리는 순서를 끌어내기

- **어느 장**: 23장 「23.2 무엇이 무엇을 먹고 무엇을 내놓는가」 · 「23.3 손이 남은 자리 찾아내기」
- **응용 과제** · 채점: 스스로 확인하는 과제(manual)
- **시작 파일**: 23-01 에서 만든 `도구목록.xlsx`
- **낼 파일**: 없음(`도구목록.xlsx` 에 칸이 더해집니다)

---

## 왜 하나

23.2 에서 도구마다 먹는 것(읽는 파일·시트)과 내놓는 것(쓰는 파일·시트)을 적었습니다.
그러자 두 가지가 드러났습니다. 같은 시트를 두 이름으로 부르고 있었고, 순서가 저절로 나왔습니다.

23.3 에서는 그 순서 사이에 사람이 손대는 곳을 세고, 판단·아직 안 만든 것·습관 셋으로 갈랐습니다.

이 과제도 여러분 폴더에 따라 답이 다릅니다. 스스로 확인합니다.

## 할 일

1. 23.2 의 입력·출력 시킬 말을 책 그대로 칩니다. 「없음」 줄을 빼지 않습니다.

   ```prompt
   도구 목록의 각 줄에 두 칸을 더해 줘.
   먹는 것 — 어느 파일이나 어느 시트를 읽나
   내놓는 것 — 어느 파일이나 어느 시트에 쓰나
   읽기만 하고 아무것도 안 쓰는 것은 「없음」으로 적어 줘.
   ```

2. 23.2 의 이름 통일 시킬 말을 책 그대로 칩니다.

   ```prompt
   먹는 것·내놓는 것 칸에서 같은 시트를 다르게 부른 곳이 있는지 찾아 줘.
   찾으면 실제 통합문서에 있는 시트 이름으로 통일하고,
   어느 문서의 어느 줄을 고쳤는지 알려 줘.
   ```

   `부서 관리대장.xlsx` 의 실제 시트 이름은 일곱 개입니다 — 대장 · 기준 · 정산 · 월별 · 담당자 · 백업_0402 · 읽어주세요.
   앞 장에서 시트를 더했다면(검사기 · 검사이력 · 승인이력 같은 것) 그 이름도 실제 이름입니다.

3. 23.2 의 순서 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 말을 칩니다.

   ```prompt
   먹는 것·내놓는 것을 보고 돌리는 순서를 정해 줘.
   같은 단계에서 같이 돌려도 되는 것은 묶어서 보여 주고,
   반드시 앞에 끝나 있어야 하는 것은 화살표로 이어 줘.
   ```

   ```prompt
   도구목록에 「순서」와 「성격」 칸을 더해 줘.
   성격은 「돌아가는 것」·「규칙」·「사람이 보는 것」 셋 중 하나로 적고,
   순서는 돌아가는 것에만 단계 번호로 적어 줘. 규칙과 사람이 보는 것은 순서 칸을 비워 둬.
   ```

   > [그림 23-02-A] 단계로 묶인 순서 (촬영 예정)

4. 23.3 의 손일 시킬 말을 책 그대로 칩니다. 책에는 「다섯 단계」라고 적혀 있습니다. 3번에서 나온 단계 수로 바꿔 칩니다.

   ```prompt
   다섯 단계를 돌리는 동안 사람이 손을 대야 하는 자리를 전부 적어 줘.
   무슨 일을 하나 · 얼마나 걸리나 · 안 하면 어떻게 되나.
   「확인만 하는 것」도 빼놓지 말고 적어 줘.
   ```

5. 23.3 의 실행 기록 시킬 말을 책 그대로 칩니다. 책에 적힌 「3단계 뒤」는 여러분 목록에서 사람이 보기로 한 곳으로 바꿔 칩니다.

   ```prompt
   3단계 뒤 확인 자리가 지난 석 달 동안 실제로 실행됐는지 확인해 줘.
   검사기 결과가 어딘가에 남아 있는지, 남아 있다면 몇 번인지 세어 줘.
   ```

6. 손일 목록을 판단(남긴다) · 아직 안 만든 것(만든다) · 습관(뗀다) 셋으로 가르게 합니다. 이 과제에서 새로 붙인 말입니다.

   ```prompt
   방금 받은 손일 목록을 23.3 의 세 가지로 갈라 줘 — 판단이 필요한 것(남긴다) / 아직 안 만든 것(만든다) / 습관으로 남은 것(뗀다).
   ```

7. 채점기로 확인 목록을 띄웁니다.

   ```
   python grader/check.py 23-02
   ```

## 스스로 확인할 것

- □ 먹는 것·내놓는 것 칸에 적힌 시트 이름이 모두 실제 통합문서에 있는 이름이거나, 「없음」이거나, 폴더에 있는 파일 이름이다(「부서별 대장」처럼 문서에서 온 다른 이름이 남아 있지 않다)
- □ 읽기만 하고 아무것도 안 쓰는 도구는 내놓는 것이 「없음」이다(없는 출력을 지어 채우지 않았다)
- □ 어떤 도구가 먹는 것을 내놓는 도구는 순서가 더 앞이다 — 줄마다 한 번씩 짚어 보았다
- □ 성격이 「규칙」이나 「사람이 보는 것」인 줄은 순서 칸이 비어 있다(셋을 한 줄에 세우지 않았다)
- □ 손일 목록에 「확인만 하는 것」도 들어 있다
- □ 보기로 한 확인이 실제로 실행된 기록(검사이력·승인이력)이 몇 번 있는지 세어 보았다 — 「보기로 했다」와 「봤다」를 갈랐다
- □ 손일을 판단 · 아직 안 만든 것 · 습관 셋으로 갈랐다

## 확인법 — 23장에서 배운 것

- 「**실제 파일에 있는 이름으로 통일한다.** 문서끼리 맞추면 둘 다 틀린 채로 맞춰질 수 있다.」
- 「**셋을 한 줄에 세우지 않는다.**」
- 「**「보기로 했다」와 「봤다」는 다른 값이다.**」

## 채점기가 이 과제를 못 보는 이유

시트 이름이 실제로 있는지, 순서가 앞뒤가 맞는지를 대 보는 채점 규칙이 아직 채점기에 없습니다.
도구목록의 모양도 사람마다 다릅니다. 그래서 스스로 확인하는 과제로 두었습니다.
