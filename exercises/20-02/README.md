# 20-02 일부러 망가뜨리고 복구 절차대로 되돌리기

- **어느 장**: 20장 「20.3 날짜별 백업 규칙 만들기」 · 「20.4 되돌리는 절차를 문서로 남기기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` 를 파일째 복사한 작업본 — 원본은 열지 않습니다.
- **낼 파일**: 되돌린 작업본 `20-02_복구.xlsx`

---

## 왜 하나

20.4 는 이렇게 끝났습니다. 「**절차는 한 번 돌려 봐야 산다.** 안 돌려 본 절차에는 빠진 단계가 반드시 있다.」
이 과제에서 절차서를 만들고, 작업본을 일부러 망가뜨리고, 절차서대로 되돌립니다.

채점기는 되돌린 작업본의 대장·정산 시트가 원본과 한 칸도 다르지 않은지 봅니다.
0 으로 바꾼 세 칸 가운데 하나라도 덜 되돌아왔으면 ✗ 가 납니다.

## 할 일

1. 작업본을 만듭니다. 아래는 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 파일째 복사해서 「20-02_복구.xlsx」로 만들어 줘.
   엑셀로 열어서 다시 저장하지 말고 파일 복사로만 해 줘. 원본은 건드리지 마.
   ```

   20-01 의 사본 규칙(「고치기 전에는 반드시 「_백업」 폴더에 사본을 먼저」)이 걸려 있어야 합니다.
   새로 `claude` 를 띄웠다면 20.1 의 규칙 시킬 말을 다시 칩니다.

2. 20.4 의 절차서 시킬 말을 책 그대로 칩니다. 마지막 줄(칠 문장)을 빼지 않습니다.

   ```prompt
   「복구절차.md」를 작업 폴더에 만들어 줘.
   내용은 이렇게 —
   ① 무엇이 잘못됐는지 확인하는 법
   ② _백업에서 어느 사본을 고를지 정하는 법
   ③ 되돌리기 전에 지금 상태를 남기는 법
   ④ 되돌린 뒤에 맞게 됐는지 확인하는 법
   각 단계에 실제로 칠 문장도 같이 적어 줘.
   ```

3. 20.3 의 백업 목록 시킬 말을 책 그대로 칩니다.

   ```prompt
   사본을 만들 때 「_백업\목록.md」에 한 줄씩 적어 줘.
   시각 · 사본 파일 이름 · 이 사본을 뜬 뒤에 무슨 작업을 했는지.
   ```

4. 20.4 의 「한 번 돌려 본다」 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금 작업본을 일부러 망가뜨려 줘 — 대장 D열 값 세 개를 0으로 바꿔 줘.
   그리고 복구절차.md 대로 되돌려 줘. 각 단계를 하면서 무엇을 했는지 알려 줘.
   ```

   > [그림 20-02-A] 복구 절차를 단계마다 보고하는 화면 (촬영 예정)

   ③ 단계에서 망가진 상태가 「_되돌리기전」 이름으로 남았는지 봅니다.
   되돌린 뒤 대장 금액 총합이 망가뜨리기 전과 같은지도 받습니다(④ 단계).

5. 되돌린 작업본을 채점합니다.

   ```
   python grader/check.py 20-02 20-02_복구.xlsx
   ```

## 확인법 — 20장에서 배운 것

- 「**「실제로 칠 문장도」가 핵심이다.**」 — 복구절차.md 네 단계에 칠 문장이 있는지 봅니다.
- 「**되돌리는 작업도 되돌릴 수 있어야 한다**」 — ③ 단계에서 지금 상태를 남겼는지 봅니다.
- 「**「그 뒤에 한 작업」이 있어야 고를 수 있다.**」 — 목록.md 에 그 칸이 있는지 봅니다.
- 「**절차는 한 번 돌려 봐야 산다.**」 — 돌려 본 결과가 원본과 같은지 채점기가 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 대장 시트 A1:F19 가 원본과 한 칸도 다르지 않다(0 으로 바꾼 세 칸이 다 돌아왔다) | 원본 대장과 칸마다 |
| 정산 시트 A1:D7 의 수식도 원본 그대로다 | 원본 정산 시트의 수식 글자 |
| practice 의 원본이 그대로다 | 원본 파일의 지문 |

## 정답·오답 예시

- `solution/20-02_복구.xlsx` — 작업본을 엑셀로 열어 대장 D5·D9·D15 를 0 으로 바꿔 저장한 뒤(망가뜨리기), 망가뜨리기 전에 떠 둔 `_백업` 사본으로 되돌린 파일. 전부 ✓.
- `wrong/20-02_복구.xlsx` — 사본으로 되돌리지 않고 **기억나는 값을 손으로 다시 적다가 한 칸(D15)을 빠뜨린** 파일. 대장 항목 하나만 ✗.
- `_verify.txt` — 두 파일을 채점한 출력 원문.
