# 05-02 수식 칸에만 회색을 칠한 수식 지도 사본

- **어느 장**: 5장 「5.2 입력 셀과 계산 셀을 갈라내기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `관리대장_수식지도.xlsx` (책에 나온 이름 그대로)

---

## 왜 하나

물려받은 파일에서 가장 흔한 사고는 수식이 든 칸에 숫자를 덮어쓰는 것입니다.
화면만 봐서는 입력한 값인지 계산된 값인지 모릅니다.

5.2 에서는 수식이 든 칸에만 연한 회색을 칠한 «수식 지도» 사본을 만들었습니다.
이 과제에서 같은 사본을 만들고, 두 가지를 파일로 확인합니다.

- 수식 칸이 빠짐없이 칠해졌나
- 색만 칠했을 뿐, 값과 수식은 한 칸도 안 바뀌었나

## 할 일

1. 저장소 폴더에서 `claude` 를 실행합니다.

2. 5.2 의 시킬 말을 책 그대로 칩니다. 책의 「관리대장」은 이 저장소의 `practice/부서 관리대장.xlsx` 입니다.
   사본은 저장소 폴더(이 README 두 단계 위)에 만들어지게 합니다.

   ```prompt
   관리대장의 사본을 만들고, 사본에서 수식이 들어 있는 셀에만 연한 회색 채우기를 해 줘.
   원본 파일은 건드리지 마.
   사본 이름은 「관리대장_수식지도.xlsx」로 해 줘.
   ```

   관리대장이 어디 있는지 되묻는다면 「practice 폴더의 부서 관리대장.xlsx 야. 사본은 이 폴더에 만들어 줘.」라고 답합니다.

3. 원본 `practice/부서 관리대장.xlsx` 을 오른쪽 클릭해 [속성]을 열고 **수정한 날짜**를 봅니다. 오늘 날짜가 찍혀 있으면 원본에 손을 댄 것입니다.

4. `관리대장_수식지도.xlsx` 를 엑셀로 열고, 정산 시트에서 F5 를 누른 뒤 [이동 옵션] - [수식]을 고릅니다.
   상태 표시줄에 뜨는 개수가 회색으로 칠해진 칸 수와 같은지 봅니다. 저장하고 닫습니다.

5. 채점합니다.

   ```
   python grader/check.py 05-02 관리대장_수식지도.xlsx
   ```

## 확인법 — 5.2 에서 배운 것

- 「「원본을 안 건드렸다」는 말을 받는 것과 원본이 안 바뀐 것은 다르다」 — 3번에서 수정한 날짜로, 채점에서는 원본 파일의 지문으로 확인합니다.
- F5 이동 옵션으로 고른 개수와 칠한 칸 수가 다르면 둘 중 하나가 틀린 것입니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 정산 B3:D5 · B7 · D7 에 채우기 색이 있다 | 원본에서 수식이 든 칸. 원본에서는 이 칸들에 색이 없다 |
| 일곱 시트 모두 값·수식이 원본과 같다 | 원본의 같은 범위와 칸마다 댄다 — 값 칸은 값, 수식 칸은 수식 글자 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

## 스스로 확인할 것

- □ 수식이 없는 칸에는 새로 칠한 색이 없다 — F5 [이동 옵션] - [수식]으로 고른 칸 수(상태 표시줄)가 칠한 칸 수와 같다
- □ practice 폴더 원본 파일 속성의 「수정한 날짜」가 작업 전과 같다

채점기는 «칠해야 할 칸에 색이 있는가»는 보지만, «칠하지 말아야 할 칸에 새 색이 없는가»는 아직 보지 못합니다.
그래서 위 첫째 줄은 꼭 눈으로 확인합니다. 원본에도 머리글 칸에는 원래 색이 있으니, 새로 칠해진 칸만 봅니다.

## 막혔을 때

`solution/` 에 정답 예시 파일이, `wrong/` 에 흔한 실수 하나(정산 합계 줄 B7·D7 을 칠하지 않은 파일)가 있습니다.
채점기 출력 원문은 [`_verify.txt`](_verify.txt) 에 있습니다.
