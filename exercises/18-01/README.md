# 18-01 규칙 검사기를 만들고, 자가 작동부터 확인하기

- **어느 장**: 18장 「18.2 받은 코드가 규칙을 지켰는지 대조하기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: 16-01 에서 만든 `코드모음` 폴더(〔대장m〕에서 꺼낸 `.bas` 네 개)
- **낼 파일**: `18-01_규칙검사.xlsx`

---

## 왜 하나

「규칙대로 만들었습니다」는 확인이 아닙니다. **셉니다.** 그래서 규칙을 세는 검사기를 만듭니다.
그런데 검사기도 틀릴 수 있습니다. 18.2 는 새 코드에 대기 전에 **이미 있는 코드에 먼저 대 보고**, 자가 작동하는지부터 봤습니다.
이 과제에서는 한 걸음 더 갑니다. 답을 이미 아는 시험 파일(Option Explicit 한 줄만 뺀 사본)을 만들어, 검사기가 그것을 정말 잡는지 봅니다.

## 할 일

1. 18.2 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   코드규칙.md 의 네 규칙을 검사하는 도구를 만들어 줘.
   .bas·.cls 파일을 읽어서 규칙별로 몇 개가 통과했는지 세고,
   통과 못 한 것은 파일과 줄 번호를 알려 줘.
   ```

   이 과제에서는 네 규칙 가운데 둘만 씁니다(과제에서 붙인 말입니다). 17-02 를 아직 안 했으면 이 말만으로 시킵니다.

   ```prompt
   이번에는 두 규칙만 검사해 줘.
   R2 — 파일에 Option Explicit 줄이 있는가.
   R4 — Sub·Function 선언 바로 윗줄이 ' 로 시작하고, ' 뒤에 글자가 있는가(「'」 한 글자만 있는 줄은 통과가 아니다).
   ```

2. 과제에서 붙인 말로 시험 파일을 만듭니다.

   ```prompt
   코드모음의 기록매크로.bas 를 복사해서 「기록매크로_시험.bas」를 만들고, 거기서 Option Explicit 줄 하나만 지워 줘.
   원래 기록매크로.bas 는 건드리지 마.
   ```

3. 과제에서 붙인 말로 결과를 시트에 남깁니다.

   ```prompt
   검사기를 코드모음의 다섯 파일(원래 네 개와 시험 파일)에 걸어서, 「18-01_규칙검사.xlsx」의 「결과」 시트에 적어 줘.
   1행 머리글 — A 모듈 · B R2 Option Explicit · C R4 통과 수 · D 프로시저 수.
   2행부터 원래 네 모듈을 모듈 이름 가나다순으로, 맨 아래 줄에 기록매크로_시험 을 적어 줘.
   A 칸에는 .bas 를 뺀 모듈 이름만, B 칸에는 「있음」이나 「없음」을 적어 줘.
   ```

4. 채점합니다.

   ```
   python grader/check.py 18-01 18-01_규칙검사.xlsx
   ```

5. **내 매크로 파일로도 해 보기** — 내 코드모음에 검사기를 걸고, 고칠 수 없는 이름(이벤트 프로시저 같은 것)이 걸렸는지 봅니다.

## 확인법 — 18장에서 배운 것

- 「「규칙대로 만들었습니다」는 확인이 아니다. 센다.」
- 「자가 작동하는지 먼저 확인한다」 — 전부 통과하면 검사기가 고장 난 것이고, 전부 실패해도 이상합니다.
- 시험 파일은 **답을 미리 아는 입력**입니다. 검사기가 그 한 줄을 못 잡으면, 다른 파일에서 「통과」가 나와도 믿지 않습니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「결과」 시트가 있다 · 줄마다 A 모듈 이름 | 원래 네 모듈 가나다순, 맨 아래 기록매크로_시험 |
| 줄마다 B R2 · C R4 통과 수 · D 프로시저 수 | `_expected.py` 가 원본 파일에서 코드를 따로 꺼내 같은 정의로 센 값. 시험 줄은 기록매크로에서 Option Explicit 한 줄을 뺀 것을 센다 |
| practice 원본이 그대로다 | 원본 파일 지문 |

## 여기서 쓴 엑셀 기능

VBA `Option Explicit` · 주석(`'`) · `Sub`·`Function` 선언
