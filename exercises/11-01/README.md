# 11-01 손으로 세고, 일부러 틀리게 하고, 되돌려 놓기

- **어느 장**: 11장 「11.1 손으로 셀 수 있는 작은 표로 먼저 시험하기」 · 「11.2 일부러 틀린 값 넣어 반응 보기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `11-01_검산.xlsx`

---

## 왜 하나

10장에서 받은 이현우 담당 금액이 맞는지 아직 아무도 확인하지 않았습니다.
같은 방식으로 다시 계산하면 같은 오류가 다시 나오므로, 다른 방법으로 확인합니다.

- **손으로 센다** — 합계는 받지 않고 행만 받아서 직접 더합니다.
- **일부러 틀리게 한다** — 한 줄을 바꿔 합계가 **그 줄 금액만큼** 줄어드는지 봅니다.
- **되돌린다** — 돌려놓는 것까지가 시험입니다. 채점기는 매출 시트가 원본과 같은지 칸마다 댑니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본과 검산할 수식을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 복사해서 「11-01_검산.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「매출 시트」라고 하면 이 사본의 매출 시트를 가리키는 걸로 해 줘.
   매출 시트 N1 에 「이현우」라고 적고, N2 에 =SUMIF(A2:A11,N1,E2:E11) 을 넣어 줘.
   ```

2. 11.1 의 시킬 말을 책 그대로 칩니다. 돌아온 행의 금액을 **여러분이 직접** 더합니다(계산기나 종이).

   ```prompt
   매출 시트에서 담당자가 「이현우」인 행만 골라서,
   행 번호와 품목, 금액을 표로 보여 줘. 합계는 내지 말고 행만 보여 줘.
   ```

3. 11.2 의 시킬 말을 책 그대로 칩니다. 합계가 얼마 줄었는지, 그 차이가 4행 금액과 같은지 봅니다.

   ```prompt
   매출 시트 A4 의 담당자를 「이현우」에서 「이현우아님」으로 바꿔 줘.
   그리고 N2 의 합계가 어떻게 되는지 알려 줘.
   ```

4. 11.2 의 되돌리는 시킬 말을 책 그대로 칩니다.

   ```prompt
   A4 를 원래대로 「이현우」로 돌려놓고, 합계가 5,194,000 으로 돌아오는지 확인해 줘.
   ```

5. 더하는 시험도 합니다. 11.2 의 시킬 말에서 **줄 번호만 바꿨습니다**(‹›). 이 파일은 12행이 합계 줄이라, 12행에 넣으면 합계 수식을 덮어씁니다.

   ```prompt
   매출 시트 ‹13행›에 담당자 「이현우」, 금액 1,000,000 짜리 행을 임시로 넣어 줘.
   합계가 얼마가 되는지 확인하고, 확인 뒤에 그 행을 지워 줘.
   ```

   이 파일에서는 N2 가 그대로입니다. N2 수식의 범위(A2:A11)가 13행까지 닿지 않기 때문입니다. 8.4 에서 본 그 문제입니다.

6. 결과를 남깁니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   「검산」 시트를 만들어 A열에 이름, B열에 값을 적어 줘.
   A1 「손 검산」 — 2번에서 내가 손으로 더한 값(내가 불러 주는 숫자)
   A2 「수식 값」 — 2번 때 N2 가 낸 값
   A3 「음성 대조」 — 3번에서 A4 를 바꿨을 때 N2 값
   A4 「줄어든 금액」 — A2 값에서 A3 값을 뺀 것
   매출 시트는 더 고치지 마.
   ```

   「내가 불러 주는 숫자」 자리에는 여러분이 손으로 더한 값을 말해 줍니다.

7. `11-01_검산.xlsx` 를 엑셀로 한 번 열고 저장한 뒤 채점합니다.

   ```
   python grader/check.py 11-01 11-01_검산.xlsx
   ```

## 확인법 — 11.1·11.2 에서 배운 것

- 「합계를 받으면 손으로 셀 이유가 없어진다」 — 2번.
- 「줄어든 만큼이 맞아야 한다」 — 3번에서 줄어든 금액이 4행 금액과 같은지.
- 「돌려놓는 것까지가 시험이다」 — 4번. 돌려놓지 않으면 시험으로 넣은 값이 진짜 데이터가 됩니다.
- 「빼는 시험은 범위 안쪽을, 더하는 시험은 범위 바깥쪽을 확인한다」 — 5번.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「검산」 시트가 있다 | — |
| 검산!B1 손 검산 · B2 수식 값 | 채점기가 원본 매출에서 담당자가 「이현우」인 줄의 수량×단가를 직접 더한다 |
| 검산!B3 음성 대조 | 위 값에서 원본 4행 수량×단가를 뺀다 |
| 검산!B4 줄어든 금액 | 원본 4행 수량×단가 |
| 매출!N2 가 SUMIF 수식이고, 지금 값이 손 검산 값과 같다 | 위와 같은 계산 |
| 매출 A1:E12 가 원본과 같다(A4 를 돌려놓았다) | 원본과 칸마다 댄다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

## 스스로 확인할 것

- □ 「합계는 내지 말고 행만 보여 줘」로 받은 세 줄을 내가 직접 더했다
- □ 더하는 시험(13행 임시 행)에서 N2 가 그대로인 것을 보고 — 범위가 13행까지 안 닿는다 — 그 줄을 지웠다

## 막혔을 때

`solution/` 에 정답 예시 파일이, `wrong/` 에 흔한 실수 하나(음성 대조 뒤 A4 를 「이현우」로 돌려놓지 않은 파일)가 있습니다.
매출 시트 항목과 N2 값 항목이 함께 ✗ 가 됩니다. 채점기 출력 원문은 [`_verify.txt`](_verify.txt) 에 있습니다.
