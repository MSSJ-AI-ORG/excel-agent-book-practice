# 14-01 읽는 곳과 쓰는 곳을 가르고, 돌려서 확인하기

- **어느 장**: 14장 「14.1 이 코드가 어느 시트·범위를 건드리는지 짚기」 · 「14.2 `If` 조건이 무엇을 가르는지 말로 받기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsm` — 원본은 열지 않습니다. 사본에서 합니다.
- **낼 파일**: `14-01_집계.xlsm`

## 왜 하나

남의 매크로를 읽을 때 첫 질문은 「이게 어디를 건드리나」입니다. **읽기만 하는 곳**(값이 안 바뀌는 곳)과 **쓰는 곳**(값이 바뀌는 곳)을 가르면 돌려도 되는지가 정해집니다.
그다음 조건(`If`)을 «업무 말로» 받습니다. 14.2 에서는 같은 파일 안의 두 방식 — `Trim`(앞뒤 공백만 뺀다)과 `Replace(…, " ", "")`(공백을 다 뺀다) — 이 다른 답을 냈습니다.
이 과제에서 그 어긋남을 직접 돌려서 파일에 남깁니다.

## 할 일

1. `practice/부서 관리대장.xlsm` 을 작업 폴더에 `14-01_집계.xlsm` 으로 복사하게 합니다. 원본은 열지 않게 합니다.

2. 14.1 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   집계매크로의 부서별집계 프로시저를 읽고,
   이 코드가 «읽는 곳»과 «쓰는 곳»을 갈라서 목록으로 만들어 줘.
   시트 이름과 셀 범위까지 적어 줘. 실행하지는 마.
   ```

3. 14.2 의 조건 시킬 말을 책 그대로 칩니다.

   ```prompt
   부서별집계에 있는 If 문을 전부 찾아서,
   각각 «무엇과 무엇을 가르는지» 업무 말로 설명해 줘.
   VBA 문법 설명 말고, 이 조건이 통과하면 어떤 경우이고 안 통과하면 어떤 경우인지.
   ```

4. 2번에서 쓰는 곳이 정산 G열뿐이라는 답을 받았으면, 14.2 의 돌리기 시킬 말을 책 그대로 칩니다.

   ```prompt
   부서별집계를 돌려서 정산 G열에 무엇이 적히는지 알려 줘.
   그리고 공백무시합계 함수로 영업1팀 금액도 구해 줘.
   ```

   과제에서 덧붙이는 말:

   ```prompt
   공백무시합계로 구한 영업1팀 금액을 정산 H3 에 수식이 아니라 숫자로 적고, 14-01_집계.xlsm 을 저장해 줘.
   다른 칸은 건드리지 마.
   ```

   > [그림 14-01-A] 매크로를 돌려도 되는지 묻는 화면 (촬영 예정)

5. `14-01_집계.xlsm` 을 **엑셀로 한 번 열고, 저장하고, 닫습니다.**(정산 시트의 수식 계산값이 파일에 들어가게 합니다.)

6. 채점합니다.

   ```
   python grader/check.py 14-01 14-01_집계.xlsm
   ```

## 확인법 — 14장에서 배운 것

- 「읽는 곳과 쓰는 곳을 가른다」 — 읽기만 하는 시트는 안전하고, 쓰는 시트는 값이 바뀝니다.
- 「「업무 말로」를 붙인다」 — 안 붙이면 「amount 가 target 보다 크거나 같으면」 같은 번역이 돌아옵니다.
- G3 의 판정(`Trim` 으로 센 것)과 H3 의 금액(공백을 다 빼고 센 것)을 목표와 나란히 놓고 봅니다. 어긋나면 **어느 쪽이 맞는지는 코드가 안 알려 줍니다. 사람이 정합니다.**
