# 12-02 단추에 걸되, 되돌릴 수 없는 매크로는 걸지 않기

- **어느 장**: 12장 「12.4 버튼에 걸어 한 번에 돌리기」
- **응용 과제** · 채점: 스스로 확인하는 과제(manual)
- **시작 파일**: `practice/부서 관리대장.xlsm` — 원본은 열지 않습니다. 사본에서 합니다.
- **만들 파일**: `12-02_단추.xlsm` (채점기에 넣지 않습니다. 아래 확인 목록으로 스스로 봅니다)

---

## 왜 하나

매달 하는 일이면 단추 하나로 돌립니다. 그런데 12.4 에서 본 것처럼 **단추에 매크로가 연결돼 있어도 코드 어디에도 그 사실이 안 적힙니다.**
그리고 단추는 눌리기 쉬우므로, 되돌릴 수 없는 일을 하는 매크로는 단추에 걸지 않습니다.
이 과제에서는 안전한 매크로 하나만 단추에 걸고, 누르면 먼저 묻게 하고, 단추 연결 목록을 받아 봅니다.

## 할 일

1. `practice/부서 관리대장.xlsm` 을 `12-02_단추.xlsm` 으로 복사하게 합니다. 원본은 열지 않게 합니다.

2. 사본을 엑셀로 열고, 12.4 순서대로 단추를 답니다(이것은 엑셀 화면에서 직접 합니다).

   ```
   [개발 도구] - [삽입] - [양식 컨트롤]의 단추를 시트에 그린다
   → 매크로 지정 대화상자에서 매크로1 을 고른다
   → 단추 이름을 「서식 맞추기」로 바꾼다
   ```

   단추는 대장 시트에 그립니다. 저장하고 엑셀을 닫습니다.

3. 12.4 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   매크로1 에 확인 창을 붙여서, 단추를 눌러도 「진행할까요」를 먼저 묻게 해 줘.
   ```

4. 12.4 의 목록 시킬 말을 책 그대로 칩니다.

   ```prompt
   이 통합 문서에서 단추·도형에 연결된 매크로가 있는지 전부 찾아 줘.
   어느 시트의 어느 도형에 어떤 매크로가 연결돼 있는지 목록으로 만들어 줘.
   ```

5. 사본을 엑셀로 다시 열어 단추를 눌러 봅니다. 확인 창에서 한 번은 [아니요], 한 번은 [예]를 누릅니다.

## 스스로 확인할 것

`python grader/check.py 12-02` 를 치면 아래 목록이 나옵니다.

- □ 대장 시트에 양식 컨트롤 단추가 있고, 단추에 적힌 글자가 「서식 맞추기」다(「단추 1」이 아니다)
- □ 그 단추를 오른쪽 단추로 눌러 [매크로 지정]을 열면 매크로1 이 골라져 있다
- □ 단추를 누르면 「진행할까요」를 먼저 묻는 창이 뜨고, [아니요]를 누르면 아무것도 바뀌지 않는다
- □ 월말마감(시트 삭제·덮어쓰기·파일 삭제)은 어떤 단추에도 걸려 있지 않다
- □ 「단추·도형에 연결된 매크로를 전부 찾아 줘」로 받은 목록에 서식 맞추기 → 매크로1 한 줄만 있다
- □ 파일을 .xlsm 으로 저장했고, 다시 열었을 때 매크로가 빠지지 않았다

## 확인법 — 12장에서 배운 것

- 「단추 이름은 그 매크로가 하는 일」이어야 한다 — 「서식 맞추기」는 좋고 「매크로1」은 나쁘다.
- 「빨강으로 분류한 작업은 단추를 만들지 않는다」 — 꼭 필요하면 단추를 눌렀을 때 먼저 물어보게 한다.
- 단추 연결 목록은 16.4 의 매크로 목록에 합칩니다. 「호출 안 됨」 판정이 단추 연결을 못 보면 틀린 판정이 됩니다.

## 만드는 사람을 위한 기록 — 왜 manual 인가

카탈로그는 단추를 파일 안에서 찾는 새 채점 규칙(`zip_member_matches`)을 전제로 합니다. 지금 채점기에는 그 규칙이 없어서 이 과제는 스스로 확인하는 과제로 두었습니다.
새 규칙을 만들 때 쓰도록 엑셀로 단추를 실제로 만들어 저장 구조를 재 두었습니다(`_measure/단추_측정본.xlsm`, 엑셀 COM 으로 `Buttons.Add` · `OnAction = "매크로1"` · `Caption = "서식 맞추기"` 후 저장).

| 부분 파일 | 들어 있는 것 |
|---|---|
| `xl/worksheets/sheet1.xml` | `<control shapeId="2049" r:id="rId3" name="Button 1">` 안에 `<controlPr … macro="매크로1">` |
| `xl/drawings/vmlDrawing1.vml` | `<x:ClientData ObjectType="Button">` 안에 `<x:FmlaMacro>매크로1</x:FmlaMacro>`, 단추 글자 「서식 맞추기」(글자 사이에 줄바꿈이 들어갈 수 있다) |
| `xl/drawings/drawing1.xml` | 단추 글자 「서식 맞추기」와 `macro=` 속성 |
| `xl/ctrlProps/ctrlProp1.xml` | `<formControlPr … objectType="Button" …/>` |

규칙을 만든다면 `sheet1.xml` 의 `controlPr` 의 `macro` 속성(연결)과 `vmlDrawing` 의 글자(이름)를 보는 것이 가장 단순합니다.
「월말마감 연결이 없다」는 같은 곳에 `macro="월말마감"` 이 없는지로 볼 수 있습니다.
