# 00-02 나는 어디서 막혔고, 첫 한 가지는 무엇인가

- **어느 장**: 0장 「0.2 그런데 왜 못 들어가나」 · 「0.3 하나씩 바꾸면 된다」
- **응용 과제** · 채점: 스스로 확인(manual)
- **시작 파일**: 없음 — 여러분의 업무에서 시작합니다
- **낼 파일**: 없음 — 적은 것을 `00-02_첫한가지.md` 로 작업 폴더에 남겨 둡니다

---

## 왜 하나

0.2 는 새 방식에 못 들어가는 이유를 네 가지로 나눴습니다. 넷 다 게으름이 아니라 합리적인 이유였습니다.
0.3 은 통째로 바꾸지 말고 **한 가지부터** 바꾸라고 했습니다.

이 과제는 그 두 절을 여러분 업무에 대 봅니다. 나는 넷 중 어디에 걸려 있는지, 그리고 처음 시킬 한 가지는 무엇인지 적습니다.
클로드 없이 해도 됩니다. 종이에 적어도 되고 메모장에 적어도 됩니다.

## 할 일

1. **막힌 이유를 하나 고릅니다.** 0.2 의 네 가지입니다.

   | 번호 | 이유 | 먼저 볼 부(0.2 「언제 이 방법을 쓰나」) |
   |---|---|---|
   | 첫째 | 그 파일을 버릴 수 없다 | 2부 |
   | 둘째 | 되돌릴 수 없는 자리가 있다 | 6부 |
   | 셋째 | 틀려도 티가 나지 않는다 | 3부 |
   | 넷째 | 배울 시간이 없다 | 4부 |

   고른 이유와, 그래서 먼저 볼 부를 한 줄로 적습니다.

2. **첫 한 가지 후보를 셋 적고, 0.3 의 세 조건으로 따져 봅니다.** 아래 표를 그대로 옮겨 쓰면 됩니다.

   | 후보 | 반복해서 한다 | 결과가 눈에 보인다 | 틀려도 되돌릴 수 있다 |
   |---|---|---|---|
   | (후보 1) | ○ / × | ○ / × | ○ / × |
   | (후보 2) | | | |
   | (후보 3) | | | |

   셋 다 ○ 인 후보를 첫 한 가지로 고릅니다.
   0.3 은 「매달 하는 서식 맞추기나 표기 정리 같은 것」이 대개 여기에 든다고 했습니다.

3. **고른 것이 계산 결과를 바꾸는 일인지 봅니다.** 바꾸는 일이면 다른 후보로 바꿉니다.
   0.3: 「계산 결과를 바꾸는 일은 처음에 고르지 않는다」. 그건 검산하는 법을 배운 뒤(3부)입니다.

4. **「그래도 안 되는 것」에 걸리는지 봅니다.** 0.3 의 세 가지입니다.
   - 권한이 걸린 일 — 사내 시스템 로그인이 필요한 일
   - 판단이 책임으로 이어지는 일 — 숫자를 승인하는 일
   - 원본이 하나뿐인 일 — 사본을 못 만드는 파일

   하나라도 걸리면 다른 후보로 바꿉니다.

5. 1~4 를 `00-02_첫한가지.md` 로 저장해 둡니다. 1장에서 업무 목록을 적을 때 다시 봅니다.

## 확인법 — 0장에서 배운 것

- 「버리고 새로 만드는 것이 답이 아니다」 — 첫 한 가지는 지금 쓰는 파일 위에서 하는 일이어야 합니다.
- 「계산 결과를 바꾸는 일은 처음에 고르지 않는다」
- 「사본에서 하면 원본이 남는다」 — 세 조건 가운데 「틀려도 되돌릴 수 있다」가 이 뜻입니다.
