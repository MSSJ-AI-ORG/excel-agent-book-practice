# 02-01 받은 답을 화면과 대조하는 표 만들기

- **어느 장**: 2장 「2.2 내 시트 읽히고 무엇이 들었는지 설명받기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 클로드에게는 열지 말고 읽히기만 합니다. 화면을 볼 때는 **사본**을 엑셀로 엽니다.
- **낼 파일**: `02-01_대조표.xlsx` — 여러분이 새로 만드는 대조표

---

## 왜 하나

2.2 에서 파일 구조를 받고, 그 답을 「물은 것 / 받은 답 / 화면」 표로 대 봤습니다.
그리고 이렇게 적었습니다. 「첫 응답은 반드시 화면과 대조한다」.

이 과제는 그 표를 직접 만듭니다. 받은 답을 한 칸, 엑셀 화면에서 직접 본 것을 한 칸에 적습니다.
채점기는 두 칸을 모두 원본에서 다시 센 값과 댑니다.

## 할 일

1. 저장소의 `practice` 폴더에서 `claude` 를 실행하고, 2.2 의 첫 시킬 말을 책 그대로 칩니다.

   ```prompt
   이번 달 매출.xlsx 를 열지 말고 구조만 읽어서,
   시트가 몇 장인지, 각 시트에 어떤 열이 있는지, 몇 행인지 알려 줘.
   그리고 수식이 들어 있는 칸이 있으면 어디인지도 알려 줘.
   ```

   > [그림 02-01-A] 구조 설명을 받은 화면 (촬영 예정)

2. **화면을 봅니다.** `이번 달 매출.xlsx` 를 practice 폴더 밖으로 복사하고, 그 **사본**을 엑셀로 엽니다.
   시트 탭, 1행의 열 이름, 마지막 줄 번호를 봅니다. 수식이 든 칸은 칸을 하나씩 눌러 수식 입력줄을 봅니다.
   2.2 처럼 E2 를 누르면 수식 입력줄에 `=C2*D2` 가 보입니다. 합계 줄도 눌러 봅니다.

3. 새 엑셀 파일에 대조표를 만듭니다. ‹이 단계는 과제에서 새로 붙인 것입니다.›
   시트 이름을 「대조」로 바꾸고, 2.2 의 표와 같은 모양으로 적습니다. **숫자 칸에는 숫자만** 적습니다.

   | | A | B | C |
   |---|---|---|---|
   | 1 | 물은 것 | 받은 답 | 화면 |
   | 2 | 시트 수 | (클로드 답) | (내가 본 것) |
   | 3 | 열 | (열 이름들) | (열 이름들) |
   | 4 | 행 | (머리글과 합계 줄까지 센 줄 수) | |
   | 5 | 수식이 든 칸 | (합계 칸까지 센 개수) | |

   받은 답이 「데이터 10행」처럼 머리글을 뺀 수로 왔다면, 머리글과 합계 줄을 더해 적고 그렇게 했다고 메모해 둡니다.
   `02-01_대조표.xlsx` 로 저장합니다.

4. 2.2 의 두 번째 시킬 말을 책 그대로 칩니다.

   ```prompt
   이 표가 무엇을 기록한 것인지, 각 열이 무슨 뜻인지 설명해 줘.
   그리고 이 표를 보고 알 수 있는 것과 알 수 없는 것을 나눠서 알려 줘.
   ```

   받은 답의 「알 수 없는 것」에 무엇이 들었는지 봅니다.

5. 저장소 폴더에서 채점합니다.

   ```
   python grader/check.py 02-01 02-01_대조표.xlsx
   ```

## 확인법 — 2장에서 배운 것

- 「첫 응답은 반드시 화면과 대조한다」 — 받은 답 칸과 화면 칸을 따로 적는 이유입니다.
- 「「알 수 없는 것」을 물어보면 그 표의 한계가 드러난다」 — 이 표에는 날짜도 거래처도 없습니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「대조」 시트가 있다 | — |
| B2·C2 시트 수 | 원본 파일의 시트를 채점기가 센다 |
| B4·C4 행 수 | 원본 A열에서 담당자가 적힌 데이터 행을 채점기가 센 뒤, 머리글 1줄과 합계 1줄을 더한다 |
| B5·C5 수식이 든 칸 수 | 데이터 행마다 금액 수식 1칸, 거기에 합계 수식 1칸 — 원본 데이터 행 수로 채점기가 계산한다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

3행(열 이름)과 「알 수 없는 것」은 채점기가 보지 않습니다. 결과 아래 「스스로 확인하세요」에 나옵니다.

## 예시 파일

`solution/` 은 맞게 적은 예, `wrong/` 은 흔한 실수 하나를 넣은 예입니다.
wrong 은 화면 칸(C5)의 수식 칸 수에서 합계 칸을 빼먹었습니다 — E2:E11 만 눌러 보고 합계 줄 E12 를 안 본 경우입니다.
