# 00-01 도구가 엑셀 파일을 정말 읽고 쓰는지 실물로 확인하기

- **어느 장**: 0장 「0.5 깔고 한 번 말 걸어 보기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `00-01_점검.xlsx`

---

## 왜 하나

0.5 에서 클로드 코드를 깔고 폴더 목록을 받아 봤습니다. 목록이 돌아오면 「도구가 살아 있다」고 했습니다.
그런데 엑셀 파일을 읽고 쓰려면 부품이 하나 더 있어야 합니다.
이 과제에서는 그 부품이 정말 있는지를 **말이 아니라 파일로** 확인합니다.

그리고 0장이 두 번 한 말도 같이 확인합니다. **적어 둔 금지가 늘 지켜지지는 않는다.**
「고치지 마」라고 시킨 매출 시트가 정말 그대로인지를 채점기가 한 칸씩 댑니다.

## 할 일

1. 저장소 폴더(이 README 가 있는 곳 두 단계 위)에서 명령 프롬프트를 열고 `claude` 를 실행합니다.

2. 0.5 의 첫 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금 이 폴더에 어떤 파일이 있는지 이름만 목록으로 보여 줘.
   파일을 열지는 말고, 고치지도 마.
   ```

3. 0.5 의 두 번째 시킬 말도 책 그대로 칩니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   엑셀 파일을 읽고 쓰려고 하는데, 지금 이 컴퓨터에 필요한 게 다 깔려 있는지 확인해 줘.
   없으면 무엇이 없는지 알려 주고, 설치해도 되는지 먼저 물어봐 줘.
   ```

   > [그림 00-01-A] 설치해도 되는지 먼저 묻는 화면 (촬영 예정)

4. 이제 실제로 읽고 쓰게 합니다. 아래는 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 복사해서 「00-01_점검.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   사본에 「점검」 시트를 새로 만들고,
   A1 에 「데이터 행 수」, B1 에 매출 시트의 데이터 행 수(머리글과 합계 줄은 빼고)를 적어 줘.
   A2 에 「금액 합계」, B2 에는 금액 합계를 숫자가 아니라 =SUM(매출!E2:E11) 수식으로 넣어 줘.
   매출 시트는 한 칸도 고치지 마.
   ```

5. `00-01_점검.xlsx` 를 **엑셀로 한 번 열고, 저장하고, 닫습니다.**
   클로드가 파이썬으로 저장한 파일에는 수식의 계산 결과가 비어 있을 수 있습니다. 엑셀이 열어서 계산해 채워 넣게 하는 것입니다.

6. 채점합니다.

   ```
   python grader/check.py 00-01 00-01_점검.xlsx
   ```

## 확인법 — 0장에서 배운 것

- 「목록이 돌아오면 도구가 살아 있는 것이다」 — 2번에서 목록이 왔는지 봅니다.
- 「설치해도 되는지 먼저 물어봐 줘」 — 3번에서 설치하기 전에 먼저 물어 왔는지 봅니다(이미 다 깔려 있었다면 그렇다는 답이 옵니다).
- 「적어 둔 금지가 늘 지켜지지는 않는다」 — 그래서 「고치지 마」가 지켜졌는지는 채점기가 파일로 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 사본에 「점검」 시트가 있다 | — |
| 점검!B1 이 데이터 행 수와 같다 | 원본 매출 시트 A열에서 담당자가 적힌 칸을 채점기가 직접 센다 |
| 점검!B2 가 SUM 수식이다 | — |
| 점검!B2 의 값이 맞다 | 원본의 수량×단가를 행마다 곱해 채점기가 직접 더한다(금액 열의 수식은 안 쓴다) |
| 사본의 매출 시트가 한 칸도 안 바뀌었다 | 원본 매출 시트와 칸마다 댄다 — 값 칸은 값, 수식 칸은 수식 글자 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

`!` 가 나오면 5번(엑셀로 열고 저장)을 하지 않은 것입니다. 틀린 것이 아닙니다.
