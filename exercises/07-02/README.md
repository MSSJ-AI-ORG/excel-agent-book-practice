# 07-02 제목 병합은 풀고 채우지 않기, 글자 날짜는 날짜로

- **어느 장**: 7장 「7.1 병합된 셀 풀고 값 채우기」 · 「7.2 문자로 들어간 날짜·숫자 되돌리기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `07-02_날짜.xlsx`

---

## 왜 하나

대장 시트 맨 위 두 줄은 여러 칸이 하나로 병합된 제목입니다. 「병합을 풀고 빈칸은 채워 줘」라고 한 문장으로 시키면
제목이 여섯 칸에 복제됩니다. 7.1 에서 본 일입니다. 그래서 병합을 풀기 전에 **그 병합이 데이터인지 제목인지** 먼저 가릅니다.

대장 A열의 날짜는 날짜가 아니라 글자입니다. 하이픈·점·「년 월 일」 세 가지 형식이 섞여 있고,
7.2 에서는 점으로 찍은 형식만 날짜로 바뀌지 않았습니다. 이 과제에서는 바꾼 뒤 **날짜로 읽히는 칸이 몇 개인지 세어서** 빠진 형식이 없는지 확인합니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 복사해서 「07-02_날짜.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「작업본」이라고 하면 이 사본을 가리키는 걸로 해 줘.
   ```

2. 7.1 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   작업본의 대장 시트에서 병합된 셀이 어디 있는지 목록으로 알려 줘.
   각 병합 영역의 범위와 그 안에 든 값을 함께 적어 줘. 아직 풀지는 마.
   ```

3. 병합을 풉니다. 7.1 의 시킬 말에서 **앞의 두 줄만** 칩니다.
   책의 셋째 줄(제목 두 줄을 표 바깥으로 빼기)은 줄을 옮기는 일이라, 이 과제에서는 하지 않습니다. 줄이 옮겨지면 채점할 칸이 어긋납니다.

   ```prompt
   대장 시트의 병합을 풀되, A1 과 A2 는 표의 데이터가 아니라 제목 줄이야.
   값을 채우지 말고 A1·A2 한 칸에만 남겨 줘.
   ```

4. 7.2 의 시킬 말 넷을 차례로 책 그대로 칩니다.

   ```prompt
   대장 시트 A열의 값이 날짜인지 글자인지 판정해 줘.
   글자라면 어떤 형식으로 적혀 있는지 종류별로 묶어서 보여 주고,
   각 형식이 몇 건인지도 세어 줘. 아직 바꾸지는 마.
   ```

   ```prompt
   대장 A열의 글자 날짜를 엑셀이 계산할 수 있는 날짜로 바꿔 줘.
   바꾸기 전에, 바꿀 수 없는 값이 있으면 먼저 알려 줘.
   ```

   ```prompt
   A열에서 점으로 구분된 날짜만 골라, 점을 하이픈으로 바꾼 뒤 날짜로 변환해 줘.
   다른 형식은 건드리지 말고, 바꾼 행이 몇 건인지 알려 줘.
   ```

   ```prompt
   날짜로 바꿀 수 없는 값은 고치지 말고, 그 행 번호와 원래 값만 목록으로 남겨 줘.
   ```

5. 바꾼 결과를 셉니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   작업본에 「날짜검산」 시트를 만들어 줘.
   A1 에 「날짜로 읽히는 칸 수」, B1 에 대장 A4:A19 가운데 엑셀이 날짜(숫자)로 알아보는 칸이 몇 개인지 세는 수식을 넣고,
   A2 에 「비어 있지 않은 칸 수」, B2 에 대장 A4:A19 에서 비어 있지 않은 칸을 세는 수식을 넣어 줘.
   ```

6. `07-02_날짜.xlsx` 를 엑셀로 엽니다. 대장 A1 을 눌러 선택 영역이 A1 한 칸뿐인지, A열 날짜가 칸 오른쪽에 붙어 있는지 봅니다.
   날짜검산!B1 과 B2 가 같은지 봅니다. 저장하고 닫습니다.

7. 채점합니다.

   ```
   python grader/check.py 07-02 07-02_날짜.xlsx
   ```

## 확인법 — 7.1·7.2 에서 배운 것

- 「병합을 풀기 전에 그 병합이 「데이터」인지 「제목」인지부터 가른다」 — 3번. B1:F1 과 B2:C2 가 비어 있어야 합니다.
- 「바꾼 건수를 반드시 받는다」 — 4번 셋째 시킬 말의 답에 건수가 있는지 봅니다. 그리고 5번에서 남은 것이 없는지 셉니다.
- 13월처럼 날짜가 될 수 없는 값은 자동으로 고치지 않습니다. 이 파일에는 그런 값이 없다는 답이 와야 합니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 대장 1·2행 — 제목은 A1·A2 한 칸에만, 옆 칸은 비어 있다 | 원본 대장 A1:F2 와 칸마다 댄다(원본에서 옆 칸은 병합에 묶인 빈칸) |
| 대장 B:F열 · A3 머리글이 그대로다 | 원본과 칸마다 댄다 |
| 대장!A12 — 비어 있던 줄은 그대로 비어 있다 | — |
| 날짜검산!B1 이 수식이고, 날짜로 읽히는 칸 수 = 날짜가 적혀 있던 칸 수 | 채점기가 원본 A4:A19 에서 글자가 적힌 칸을 센다. 그 칸이 모두 날짜로 읽을 수 있는 글자라는 것은 [`_expected.py`](_expected.py) 가 확인했다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

## 스스로 확인할 것

- □ 대장 A1 을 눌렀을 때 A1 한 칸만 선택된다(병합이 풀렸다). A2 도 같다
- □ A4:A19 의 날짜가 칸 오른쪽에 붙고, 원래 글자와 같은 날짜다(예: 「2026.01.22」 → 2026-01-22)
- □ 점으로 찍은 날짜를 바꾼 건수(2건)를 따로 받았다
- □ 날짜로 바꿀 수 없는 값이 있으면 고치지 않고 행 번호와 원래 값만 목록으로 받았다(이 파일에는 없다는 답)

채점기는 아직 병합이 남았는지, 날짜가 «원래 글자와 같은 날»인지는 보지 못합니다. 그래서 위 첫째·둘째 줄은 눈으로 봅니다.
