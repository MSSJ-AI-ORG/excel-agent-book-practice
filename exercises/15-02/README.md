# 15-02 경고를 끄지 않는 월말마감으로 다시 쓰기

- **어느 장**: 15장 「15.4 지우고 저장하는 줄만 따로 확인받기」
- **응용 과제** · 채점: 자동(auto) — 코드 글 파일을 채점합니다
- **시작 파일**: `practice/부서 관리대장.xlsm` — 원본은 열지 않습니다. 사본에서 합니다.
- **낼 파일**: `월말마감_고침.bas` (고친 「위험매크로」 모듈을 내보낸 글 파일)

---

## 왜 하나

「월말마감」 한 프로시저 안에 시트 삭제, 파일 덮어쓰기, 파일 삭제(`Kill` — 휴지통에 가지 않습니다)가 함께 들어 있습니다.
15.4 의 결론은 「지우는 줄을 조심한다」가 아니라 **「경고를 끄지 않는다」**였습니다.
`Application.DisplayAlerts = False` 한 줄이 그 뒤의 지우는 줄들을 모두 묻지 않고 지나가게 만들기 때문입니다.
이 과제에서는 **한 번도 돌리지 않고** 읽어서 위험한 줄을 고르고, 경고를 끄지 않는 코드로 다시 쓰게 합니다.

## 할 일

1. `practice/부서 관리대장.xlsm` 을 작업 폴더에 `15-02_작업.xlsm` 으로 복사하게 합니다. 원본은 열지 않게 합니다.

2. 15.4 의 시킬 말을 책 그대로 칩니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   월말마감 매크로에서 되돌릴 수 없는 일을 하는 줄만 골라 줘.
   각 줄마다 무엇이 사라지는지 적어 줘.
   ★실행하지 마.
   ```

3. 15.4 의 두 번째 시킬 말을 책 그대로 칩니다.

   ```prompt
   이 매크로가 DisplayAlerts 를 다시 켜는지 확인해 줘.
   중간에 오류가 나면 어떻게 되는지도 알려 줘.
   ```

4. 15.4 의 고치기 시킬 말을 책 그대로 칩니다.

   ```prompt
   이 매크로를 다음처럼 고쳐 줘.
   ① 맨 위에 무엇을 하는 매크로인지 주석
   ② 지우기 전에 무엇이 사라지는지 화면에 보여 주고 물어보기
   ③ DisplayAlerts 는 끄지 않기 — 물어보는 것을 없애지 않는다
   ④ 오류가 나도 설정이 원래대로 돌아오게
   ★고치기 전에 원본을 남겨 줘.
   ```

   과제에서 덧붙이는 말:

   ```prompt
   원본은 위험매크로 모듈이 아니라 새 모듈에 남겨 줘. 고친 것도, 원본도 돌리지 마.
   ```

5. 사본을 엑셀로 열고 VBA 편집기에서 「위험매크로」 모듈을 고른 뒤 **[파일] - [파일 내보내기]** 로 `월말마감_고침.bas` 로 저장합니다.

6. 채점합니다.

   ```
   python grader/check.py 15-02 월말마감_고침.bas
   ```

## 확인법 — 15장에서 배운 것

- 「경고를 끄지 않는다」 — 엑셀이 물어보는 것은 방해가 아니라 마지막 안전망입니다.
- 「멈춘 매크로는 설정을 원래대로 안 돌려놓고 멈춘다」 — 맨 아래에서 `= True` 로 되돌려도, 중간에 오류가 나면 거기까지 가지 못합니다.
- 월말마감은 이 과제 내내 **돌리지 않습니다.** 고친 것도 사본에서만, 이 과제가 끝난 뒤에 돌립니다.

## 채점기가 보는 것

채점기는 주석 줄을 빼고 코드를 봅니다(맨 위 주석 항목만 주석 줄을 봅니다).

| 항목 | 무엇을 보나 |
|---|---|
| `Sub 월말마감` 이 있다 | 모듈을 제대로 내보냈나 |
| `DisplayAlerts = False` 가 없다 | ③ 경고를 끄지 않는다 |
| `MsgBox … vbYesNo` 가 있다 | ② 물어보기 |
| `.Delete` 가 묻는 줄(`vbYesNo`)보다 뒤에 있다 · `Kill` 도 묻는 줄보다 뒤에 있다 | 지우기 **전에** 묻나 |
| `On Error GoTo` 가 있다 | ④ 오류가 나도 끝을 처리하나 |
| 첫 `Sub` 앞에 주석 줄이 있다 | ① 맨 위 주석 |

## 여기서 쓴 엑셀 기능

`DisplayAlerts` · `Sheets().Delete` · `SaveAs` · `Kill` · `MsgBox`·`vbYesNo` · `On Error` · [파일 내보내기]
