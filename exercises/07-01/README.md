# 07-01 부서 표기를 한 가지로 모으고 전후를 검산하기

- **어느 장**: 7장 「7.3 같은 뜻 다른 표기를 한 가지로 모으기」 · 「7.4 걷어내기 전후를 행 수로 검산하기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `07-01_표기통일.xlsx`

---

## 왜 하나

대장 B열에는 「영업1팀」·「영업 1팀」·「영업1 팀」처럼 띄어쓰기만 다른 표기가 섞여 있습니다.
정산 수식은 글자가 정확히 같은 것만 세므로, 빠진 금액이 있어도 오류 표시가 뜨지 않습니다.

이 과제에서는 표기를 한 가지로 모읍니다. 그리고 **고치기 전에** 기준값을 적어 두고, 고친 뒤 같은 값을 다시 세어 나란히 놓습니다.
고치다가 행이나 금액이 새어도 오류로는 나타나지 않기 때문입니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 복사해서 「07-01_표기통일.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「작업본」이라고 하면 이 사본을 가리키는 걸로 해 줘.
   ```

2. **고치기 전에** 기준값을 적어 둡니다. 7.4 의 시킬 말을 책 그대로 치고, 적을 자리를 이 과제에서 새로 붙인 말로 정해 줍니다.

   ```prompt
   지금 상태의 대장 시트에서 다음 셋을 세어 줘.
   ① 부서 이름이 적혀 있는 행 수
   ② 금액 열의 합계
   ③ 부서별 건수
   이 셋을 「정리 전」이라는 이름으로 새 시트에 적어 둬.
   ```

   ```prompt
   「정리 전」 시트의 A2·B2 에 「부서가 적힌 행 수」와 그 값, A3·B3 에 「금액 합계」와 그 값,
   A4·B4 에 「부서 표기 수」(서로 다른 표기가 몇 가지인지)와 그 값을 적고,
   6행부터 표기별 건수를 한 줄에 하나씩 적어 줘.
   값은 나중에 바뀌지 않게 수식이 아니라 숫자로 적어 둬.
   ```

3. 7.3 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   대장 시트 B열에 적힌 부서 이름을 중복 없이 목록으로 만들어 줘.
   각 표기가 몇 건씩 쓰였는지도 함께 세어 줘.
   ```

4. 표기를 모읍니다. 7.3 「제대로 고친다」의 시킬 말을 책 그대로 칩니다.

   ```prompt
   대장 B열의 부서 이름에서 공백을 모두 제거한 뒤,
   남은 표기가 몇 가지인지 다시 세어 줘.
   세 가지가 아니면 멈추고 무엇이 남았는지 알려 줘.
   ```

5. 7.4 의 시킬 말 두 개를 책 그대로 칩니다. 이어서 표를 둘 자리를 이 과제에서 새로 붙인 말로 정해 줍니다.

   ```prompt
   「정리 전」 시트의 세 값과 지금 값을 나란히 놓고, 다른 것이 있으면 표시해 줘.
   행 수와 합계 가운데 하나만 다른 경우에는 무엇이 달라졌는지 행 단위로 찾아 줘.
   ```

   ```prompt
   정리 전후 대조표를 「검산」 시트로 남기고,
   맨 위에 오늘 날짜와 이번에 고친 세 가지를 한 줄씩 적어 줘.
   ```

   ```prompt
   「검산」 시트는 A1 에 날짜, 2~4행에 고친 것을 한 줄씩(이번에는 한 가지) 적고,
   6행에 「항목 / 정리 전 / 정리 후 / 같은가」 머리글, 7~9행에 부서가 적힌 행 수 · 금액 합계 · 부서 표기 수를 놓아 줘.
   「정리 후」(C7:C9)는 지금 대장을 세는 수식으로 넣어 줘.
   ```

6. `07-01_표기통일.xlsx` 를 엑셀로 열어 정산 시트 B3:B5 가 달라졌는지 봅니다. 저장하고 닫습니다.

7. 채점합니다.

   ```
   python grader/check.py 07-01 07-01_표기통일.xlsx
   ```

## 확인법 — 7.3·7.4 에서 배운 것

- 「끝난 뒤의 모습을 미리 적어 두고 거기에 못 닿으면 멈추게 한다」 — 4번의 「세 가지가 아니면 멈추고」.
- 「두 값을 같이 봐야 한다」 — 행 수와 합계는 서로 다른 것을 잡습니다. 검산 시트에 둘 다 있는지 봅니다.
- 「모르면 지우지 않는다」 — 대장 12행은 비어 있습니다. 지우지 않고 그대로 둡니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 대장!B5·B8·B14 가 공백 없는 이름이 됐다 | 원본 그 칸에서 공백을 뺀 글자. 계산한 스크립트가 [`_expected.py`](_expected.py) 에 있다 |
| 원래 공백이 없던 부서 칸 · A열 · C:F열(금액 포함)이 그대로다 | 원본 대장과 칸마다 댄다 |
| 정리 전!B2 행 수 · B3 금액 합계 · B4 부서 표기 수 | 채점기가 원본 대장 B4:B19·D4:D19 에서 직접 센다. B4 는 공백을 빼지 않고 센 «고치기 전» 표기 수 |
| 검산!C7 행 수 · C8 금액 합계 · C9 부서 표기 수 | 채점기가 원본에서 직접 센다. C9 는 공백을 뺀 뒤의 표기 수 |
| 정산!B3:B5 부서별 매출합계 | 채점기가 원본 대장 B열에서 공백을 뺀 부서 이름으로 D열을 다시 모은다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

`!` 가 나오면 엑셀로 한 번 열고 저장하지 않은 것입니다. 틀린 것이 아닙니다.

## 스스로 확인할 것

- □ 「세 가지가 아니면 멈추고」를 붙여 시켰다
- □ 「정리 전」을 표기를 고치기 «전에» 적었다(고친 뒤에 적으면 표기 수가 3 으로 나온다)
- □ 비어 있는 12행을 지우지 않았다
