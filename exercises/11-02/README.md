# 11-02 다른 방법으로 한 번 더, 그리고 검산 기록 쌓기

- **어느 장**: 11장 「11.3 옛 방식 결과와 나란히 두고 비교하기」 · 「11.4 검산표를 시트에 남겨 두기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `11-02_두방법.xlsx`

---

## 왜 하나

옛 방식의 결과가 없으면, **같은 계산을 다른 방법으로** 한 번 더 합니다. 같은 함수를 다시 쓰면 같은 실수가 반복될 뿐이라 검산이 안 됩니다.

그리고 확인한 사실을 파일 안에 남깁니다. 기록은 **덮어쓰지 않고 한 줄씩 쌓습니다.**
쌓여 있어야 나중에 「언제부터 틀어졌나」를 좁혀 찾을 수 있습니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본과 검산할 수식을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 복사해서 「11-02_두방법.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「매출 시트」라고 하면 이 사본의 매출 시트를 가리키는 걸로 해 줘.
   매출 시트 N1 에 「이현우」라고 적고, N2 에 =SUMIF(A2:A11,N1,E2:E11) 을 넣어 줘.
   ```

2. 11.3 의 시킬 말을 책 그대로 칩니다. 채점을 위해 두 방법을 칸에 남기게 하는 말을 이 과제에서 새로 붙입니다.

   ```prompt
   N2 의 값을 SUMIF 말고 다른 방법으로 한 번 더 구해 줘.
   피벗 테이블이든 다른 함수든 상관없어. 두 값이 같은지 알려 줘.
   ```

   ```prompt
   다른 방법 두 가지를 N3 과 N4 에 수식으로 남겨 줘. 둘 다 SUMIF 가 아닌 서로 다른 함수로.
   M2:M4 에는 각 칸에 쓴 방법의 이름을 적어 줘. A:E열은 고치지 마.
   ```

3. 11.4 의 시킬 말을 책 그대로 칩니다. 표 모양을 이 과제에서 새로 붙인 말로 정해 줍니다.

   ```prompt
   「검산」이라는 시트를 만들고 다음을 적어 줘.
   ① 오늘 날짜
   ② 검산한 수식이 어느 칸에 있는지
   ③ 손으로 센 값과 수식이 낸 값
   ④ 일부러 틀리게 했을 때 얼마나 움직였는지
   ⑤ 다른 방법으로 구한 값
   ```

   ```prompt
   「검산」 시트는 1행에 「날짜 / 대상 / 손 검산 / 수식 값 / 음성 대조 / 다른 방법」 머리글을 두고,
   2행부터 검산 한 번에 한 줄씩 적어 줘. 날짜는 A열, 수식 값은 D열에.
   ```

4. 11.4 의 시킬 말 둘을 책 그대로 칩니다. 둘째 것(「검산해 줘.」)이 다음 달에 할 말입니다. 과제에서는 지금 한 번 쳐서 기록이 한 줄 더 쌓이는지 봅니다.

   ```prompt
   이 검산 절차를 「검산절차.md」로 작업 폴더에 저장해 줘.
   앞으로 「검산해 줘」라고 하면 이 절차대로 하고 결과를 검산 시트에 한 줄 추가해 줘.
   ```

   ```prompt
   검산해 줘.
   ```

5. `11-02_두방법.xlsx` 를 엑셀로 열어 검산 시트 2행과 3행이 둘 다 있는지 봅니다. 저장하고 닫습니다.

6. 채점합니다.

   ```
   python grader/check.py 11-02 11-02_두방법.xlsx
   ```

## 확인법 — 11.3·11.4 에서 배운 것

- 「「다른 방법으로」를 분명히 한다」 — N2·N3·N4 의 함수가 서로 달라야 합니다.
- 「한 줄 추가가 중요하다. 덮어쓰면 지난달 기록이 사라진다」 — 4번 뒤에 기록이 두 줄인지.
- 「없는 것을 지어내지 않는다」 — 지난달 보고서 값이 없으면 11.3 의 첫 시킬 말은 건너뜁니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| N2 가 SUMIF 수식, N3·N4 가 수식이다 | — |
| N2·N3·N4 값이 모두 이현우 금액 합계 | 채점기가 원본 매출에서 담당자가 「이현우」인 줄의 수량×단가를 직접 더한다 |
| 「검산」 시트가 있고, D2·D3 에 두 번의 수식 값이 적혀 있다 | 위와 같은 계산 — 기록이 두 줄 쌓였는지 |
| 매출 A1:E12 가 원본과 같다 · practice 의 원본이 그대로다 | 원본과 댄다 |

## 스스로 확인할 것

- □ N2 · N3 · N4 에 쓴 함수가 서로 다르다(같은 함수를 다시 쓰면 검산이 아니다)
- □ 검산 시트 2행과 3행의 날짜 칸(A열)이 비어 있지 않다 — 덮어쓰지 않고 한 줄씩 쌓였다
- □ 작업 폴더에 「검산절차.md」가 있다

채점기는 아직 세 수식의 함수가 «서로 다른지»와 날짜 칸이 채워졌는지를 보지 못합니다. 그래서 위 세 줄은 눈으로 봅니다.

## 막혔을 때

`solution/` 에 정답 예시 파일이, `wrong/` 에 흔한 실수 하나(«다른 방법» 칸 N4 에 수식 대신 숫자를 적어 넣은 파일)가 있습니다.
값은 같으니 값 항목은 ✓ 인데, 수식인지 보는 항목이 ✗ 가 됩니다. 채점기 출력 원문은 [`_verify.txt`](_verify.txt) 에 있습니다.
