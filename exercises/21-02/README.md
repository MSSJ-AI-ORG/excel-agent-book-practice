# 21-02 오류 셋을 심어 검사기가 잡는지 보기

- **어느 장**: 21장 「21.3 빠진 행·중복된 행 찾아내기」 · 「21.4 검사 결과를 시트에 표로 남기기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: 21-01 에서 만든 `21-01_검사기.xlsx` 의 사본
- **낼 파일**: `21-02_오류심기.xlsx` — **오류를 심은 채로** 냅니다

---

## 왜 하나

21-01 의 검사기는 여덟 줄이 전부 「통과」였습니다. 21.3 은 여기서 이렇게 말합니다.
「**그래서 아무것도 확인되지 않았다.**」

이 과제에서 오류 셋을 일부러 심고, 검사기가 잡는지 봅니다.
채점기는 여러분의 검사기 수식을 믿지 않고, **제출한 파일의 대장을 따로 세어** 검사기 값과 댑니다.
그리고 결과를 「검사이력」에 **덮어쓰지 않고 한 줄씩** 쌓았는지 봅니다.

## 할 일

1. 21-01 결과의 사본을 만듭니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   「21-01_검사기.xlsx」를 복사해서 「21-02_오류심기.xlsx」로 만들어 줘. 이 과제에서는 이 사본만 고쳐 줘.
   ```

2. 21.4 의 검사이력 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 모양 맞추기 말을 칩니다.

   ```prompt
   검사기를 돌린 결과를 「검사이력」 시트에 한 줄씩 쌓아 줘.
   날짜 · 검사 항목 수 · 통과한 수 · 확인이 뜬 항목 이름.
   ★덮어쓰지 말고 한 줄씩 추가해 줘.
   ```

   ```prompt
   검사이력 1행 머리글은 「날짜」「항목 수」「통과」「확인이 뜬 것」으로 해 줘.
   오류를 심기 전인 지금 결과를 2행에 먼저 남겨 줘.
   ```

3. 21.3 의 오류 심기 시킬 말을 책 그대로 칩니다.

   ```prompt
   작업본에 오류를 세 개 심어 줘.
   ① 금액 하나를 음수로
   ② 담당 칸 하나를 비우고
   ③ 어느 행 하나를 그대로 복사해서 중복을 만들어 줘
   심은 뒤에 검사기가 무엇을 잡았는지 알려 줘.
   ```

   > [그림 21-02-A] 「확인」이 뜬 검사기 화면 (촬영 예정)

4. 심은 뒤 결과를 한 줄 더 남깁니다. 이 과제에서 새로 붙인 말입니다.

   ```prompt
   오류를 심은 뒤의 검사 결과를 검사이력 3행에 한 줄 더 남겨 줘. 2행은 덮어쓰지 마.
   ```

5. `21-02_오류심기.xlsx` 를 **엑셀로 한 번 열고, 저장하고, 닫습니다.** 그리고 채점합니다. **오류를 심은 상태로** 채점합니다.

   ```
   python grader/check.py 21-02 21-02_오류심기.xlsx
   ```

6. 채점이 끝나면 21.3 의 되돌리기 시킬 말을 책 그대로 칩니다.

   ```prompt
   심은 오류 세 개를 전부 되돌리고, 검사기가 다시 전부 통과하는지 확인해 줘.
   ```

## 확인법 — 21장에서 배운 것

- 「**셋을 심었는데 넷이 잡혔다**」 — 음수·빈칸·중복 말고 금액 총합 줄도 같이 걸렸는지 봅니다.
- 「중복이 **2건**으로 나온 것에도 주의한다.」 — 한 줄을 복사해 만든 중복은 원래 줄과 사본 둘 다 세어집니다.
- 「**「덮어쓰지 말고」가 핵심이다.**」 — 검사이력 2행(심기 전)이 남아 있는지 채점기가 봅니다.
- 「**되돌리는 것까지가 시험이다.**」 — 6번 뒤에 여덟 줄이 다시 통과인지 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 검사기 1~7번 줄의 B 값이 오류를 심은 대장을 제대로 센다 | **제출한 파일의** 대장(4~40행)을 채점기가 직접 센 값 |
| 1~7번 줄의 D = 원본과 달라졌으면 「확인」, 같으면 「통과」 | 원본 대장과 제출 파일 대장을 채점기가 각각 세어 댄 결과 |
| 음수·담당 빈칸·중복 줄(D5·D8·D9)이 「확인」이다 — 오류 셋이 정말 심겼고 검사기가 잡았다 | 심은 오류 세 가지 |
| 검사이력 머리글 · 2행 통과 = 8(심기 전) | 21-01 의 여덟 줄이 전부 통과였다 |
| 검사이력 3행 통과 = 지금 검사기의 「통과」 수 | 제출 파일 검사기 D2:D9 에서 채점기가 「통과」를 센 값 |
| practice 의 원본이 그대로다 | 원본 파일의 지문 |

8번 줄(중복 줄 수)의 값은 채점기가 아직 세지 못합니다. 「2 이상인지」는 확인 목록으로 나옵니다.

## 정답·오답 예시

- `solution/21-02_오류심기.xlsx` — 21-01 정답의 사본에 엑셀로 실제로 오류 셋(대장 D10 을 음수로 · E11 을 비움 · 7행을 13행에 덮어 복사)을 심고, 검사이력을 심기 전·뒤 두 줄로 남긴 파일. 전부 ✓. 이 파일에서 검사기는 넷(금액 총합·음수·담당 빈칸·중복)을 잡았고 중복 줄 수는 2 였습니다.
- `wrong/21-02_오류심기.xlsx` — 같은 조작인데 **검사이력을 2행에 덮어써** 한 줄만 남긴 파일. 검사이력 두 항목만 ✗.
- `_verify.txt` — 두 파일을 채점한 출력 원문.
