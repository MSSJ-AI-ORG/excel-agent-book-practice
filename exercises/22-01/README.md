# 22-01 「모름」 칸이 있는 검수표와 고치기 어려운 승인 기록

- **어느 장**: 22장 「22.1 어느 단계에서 사람이 봐야 하는지 정하기」 · 「22.3 승인 기록을 파일로 남기기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/부서 관리대장.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `22-01_승인.xlsx`

---

## 왜 하나

22.1 에서 사람이 볼 지점을 고르고, 지점마다 「무엇을 보는가」를 한 문장으로 적었습니다.
판정 칸에는 「통과·반려」 말고 「모름」도 두었습니다. 「**「모름」이 없으면 확신 없는 것이 통과로 들어간다.**」

22.3 에서는 승인 기록을 시트로 남겼습니다. 「**「이유」 칸이 이 기록의 값어치다.**」
그리고 그 시트를 보호했습니다. 「**고칠 수 있는 기록은 기록이 아니다.**」

이 과제에서 검수표와 승인이력을 한 파일에 만듭니다.

## 할 일

1. 사본을 만듭니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「부서 관리대장.xlsx」를 이 폴더에 복사해서 「22-01_승인.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마. 이 과제에서는 사본만 고쳐 줘. 대장 시트는 고치지 마.
   ```

2. 22.1 의 두 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금까지 이 폴더에서 하는 작업을 세 기준으로 검토해서,
   사람이 봐야 하는 지점을 목록으로 만들어 줘.
   각 지점마다 「무엇을 보는가」를 한 문장으로 적어 줘.
   ```

   ```prompt
   방금 만든 목록에서, 검사기로 대신할 수 있는 지점이 있으면 알려 줘.
   사람이 보는 지점은 최대 다섯 개로 줄이고 싶어.
   ```

3. 22.1 의 「모름」 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 모양 맞추기 말을 칩니다.

   ```prompt
   검수 지점마다 판정 칸을 두되, 「통과·반려」 말고 「모름」도 넣어 줘.
   「모름」이 나오면 그 항목이 무엇 때문에 판단이 안 서는지 적게 해 줘.
   ```

   ```prompt
   이 목록을 「22-01_승인.xlsx」의 「검수표」 시트에 적어 줘.
   1행은 머리글, 2행부터 지점 하나에 한 줄씩(다섯 줄 이하).
   A열 검수 지점 / B열 무엇을 보는가 / C열 판정 / D열 모름일 때 무엇 때문에 판단이 안 서나.
   C열 판정 칸은 누르면 「통과·반려·모름」 셋 중에서 고르게 목록으로 만들어 줘.
   ```

4. 22.3 의 승인이력 시킬 말을 책 그대로 칩니다. 이어서 이 과제에서 새로 붙인 말을 칩니다.

   ```prompt
   「승인이력」 시트를 만들고, 멈춤에 걸렸다가 진행한 건을 한 줄씩 남겨 줘.
   날짜와 시각 · 무슨 작업 · 어느 조건에 걸렸나 · 그때 숫자 · 누가 승인 · 이유
   ★덮어쓰지 말고 추가만 해 줘.
   ```

   ```prompt
   승인이력 1행 머리글은 책의 표 그대로 「일시」「작업」「걸린 조건」「숫자」「승인」「이유」로 해 줘.
   2행에는 지금까지 내가 승인하고 진행한 작업 하나를 적어 줘(예: 19-01 에서 「진행」이라고 해서 1월 자료를 지운 것).
   이유 칸을 비우지 마. 이유를 모르면 나에게 물어봐 줘.
   ```

   진행한 작업이 아직 하나도 없다면, 19-01 을 먼저 해 봅니다. 기록은 실제로 한 일로 채웁니다.

5. 22.3 의 보호 시킬 말을 책 그대로 칩니다.

   ```prompt
   승인이력 시트를 수정하지 못하게 보호해 줘.
   추가는 되고 고치거나 지우는 건 안 되게 해 줘.
   ```

   > [그림 22-01-A] 보호가 걸린 승인이력 시트에서 고치려 하자 엑셀이 막는 화면 (촬영 예정)

6. 채점합니다.

   ```
   python grader/check.py 22-01 22-01_승인.xlsx
   ```

## 확인법 — 22장에서 배운 것

- 「**「무엇을 보는가」가 없으면 그 검수는 형식이 된다.**」 — 지점마다 B열이 채워졌는지 채점기가 봅니다.
- 「**검수 지점이 많으면 전부 형식이 된다.**」 — 다섯 개 이하인지 채점기가 봅니다.
- 「**「모름」이 없으면 확신 없는 것이 통과로 들어간다.**」 — 판정 목록에 「모름」이 있는지 스스로 봅니다.
- 「**「이유」 칸이 이 기록의 값어치다.**」 — 이유 칸이 비었는지 채점기가 봅니다.
- 「**고칠 수 있는 기록은 기록이 아니다.**」 — 보호가 걸렸는지 스스로 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 「검수표」 시트가 있다 · 7행이 비어 있다(지점 다섯 개 이하) | — |
| 지점이 적힌 줄마다 「무엇을 보는가」(B열)가 채워져 있다 | 제출 파일에서 채점기가 지점 줄 수와 B열 줄 수를 따로 센다 |
| 「승인이력」 머리글 여섯 칸 | 22.3 의 표 |
| 승인이력 2행 이유 칸(F2)이 비어 있지 않다 | 제출 파일에서 채점기가 센다 |
| 사본의 대장 시트가 한 칸도 안 바뀌었다 · practice 원본이 그대로다 | 원본과 칸마다 · 원본 지문 |

판정 칸의 「통과·반려·모름」 목록과 시트 보호는 채점기가 아직 보지 못합니다. 채점 결과 아래 확인 목록으로 나옵니다.
