# P3-01 담당자별 집계표를 만들고 세 가지로 검산하기

- **어느 장**: 3부 종합 — 9장 「9.4 오류를 숨기지 말고 드러나게 두기」 · 10장 「10.1 조건에 맞는 값만 더하게 시키기」 · 11장 「11.1」~「11.4」
- **3부 종합 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `P3-01_집계.xlsx`

---

## 왜 하나

3부에서 가장 중요한 문장은 11.2 에 있었습니다. **값이 맞게 나왔다는 사실만으로는 수식이 맞는지 알 수 없다.**

이 과제에서 담당자별 집계표를 새로 받습니다. 그리고 3부에서 배운 확인을 세 가지로 겁니다.
손으로 한 명을 세고, 일부러 틀리게 해 보고, 집계 합계를 매출 합계와 댑니다.
오류를 0 으로 덮는 `IFERROR` 는 쓰지 않습니다(9.4).

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 복사해서 「P3-01_집계.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「매출 시트」라고 하면 이 사본의 매출 시트를 가리키는 걸로 해 줘.
   ```

2. 집계표를 받습니다. 이 과제에서 새로 붙인 시킬 말입니다. 10.1 처럼 **조건을 셀로** 뺀 수식을 받습니다.

   ```prompt
   「집계」 시트를 새로 만들어 줘.
   1행에 「담당자 / 금액 / 건수」 머리글을 적고,
   A열에는 매출 시트의 담당자를 중복 없이, 매출 시트에 처음 나온 차례대로 한 줄에 한 명씩 적어 줘.
   B열에는 그 줄 A열 칸을 조건으로 매출 시트 금액을 더하는 SUMIF 수식을,
   C열에는 그 줄 담당자의 거래 건수를 세는 수식을 넣어 줘.
   담당자 아래 줄에는 A열에 「합계」, B·C열에 위 칸들을 모두 더하는 수식을 넣어 줘.
   오류를 0 으로 덮는 IFERROR 는 쓰지 마. 매출 시트는 고치지 마.
   ```

3. **손 검산** — 11.1 의 시킬 말을 책 그대로 칩니다. 돌아온 행의 금액을 직접 더해 집계의 이현우 줄과 댑니다.

   ```prompt
   매출 시트에서 담당자가 「이현우」인 행만 골라서,
   행 번호와 품목, 금액을 표로 보여 줘. 합계는 내지 말고 행만 보여 줘.
   ```

4. **음성 대조** — 11.2 의 시킬 말 둘을 책 그대로 칩니다. 이번에는 집계 시트의 이현우 금액이 줄어드는지 봅니다.

   ```prompt
   매출 시트 A4 의 담당자를 「이현우」에서 「이현우아님」으로 바꿔 줘.
   그리고 N2 의 합계가 어떻게 되는지 알려 줘.
   ```

   이 과제에는 N2 가 없으니, 답이 «N2 가 비어 있다»로 오면 「집계 시트의 이현우 금액은 어떻게 됐어?」라고 다시 묻습니다.

   ```prompt
   A4 를 원래대로 「이현우」로 돌려놓고, 합계가 5,194,000 으로 돌아오는지 확인해 줘.
   ```

5. **기록** — 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   「검산」 시트를 만들어 A열에 이름, B열에 값을 적어 줘.
   A1 「손 검산(이현우)」 — 3번에서 내가 손으로 더한 값(내가 불러 주는 숫자)
   A2 「집계의 이현우 금액」 — 집계 시트 이현우 줄을 가리키는 수식
   A3 「음성 대조」 — 4번에서 A4 를 바꿨을 때 이현우 금액
   A4 「집계 합계」 — 집계 시트 합계 줄 금액을 가리키는 수식
   A5 「매출 합계」 — 매출!E12 를 가리키는 수식
   A6 「같은가」 — B4 와 B5 가 같으면 「같음」, 다르면 「다름」을 내는 수식
   ```

6. `P3-01_집계.xlsx` 를 엑셀로 열어 검산!B6 이 「같음」인지 봅니다. 저장하고 닫습니다.

7. 채점합니다.

   ```
   python grader/check.py P3-01 P3-01_집계.xlsx
   ```

## 확인법 — 3부에서 배운 것

- 「값이 맞게 나왔다는 사실만으로는 수식이 맞는지 알 수 없다」 — 그래서 손 검산 하나로 끝내지 않고 음성 대조와 합계 대조를 겁니다.
- 「0은 의심받지 않는 값이다」 — `IFERROR(…,0)` 을 쓰지 않습니다.
- 「조건을 셀로 빼는 것이 이 장에서 가장 자주 쓰는 손질」 — B열 수식이 이름을 글자로 박지 않고 A열 칸을 봅니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 집계!A2:A5 담당자 넷(처음 나온 차례) | 채점기가 원본 매출에서 그 이름이 처음 나오는 칸을 읽는다. 어느 칸인지는 [`_expected.py`](_expected.py) 가 확인했다 |
| 집계!B2 가 SUMIF 수식이다 | — |
| 줄마다 B 금액 · C 건수 | 채점기가 **그 줄 A열의 이름**으로 원본 매출에서 줄을 골라 수량×단가를 더하고, 줄 수를 센다 |
| 집계!A6 「합계」 · B6 = 매출 전체 합계 · C6 = 매출 줄 수 | 채점기가 원본 수량×단가 전체를 더하고, 이름이 적힌 줄을 센다 |
| 검산!B1 손 검산 · B3 음성 대조 | 원본 이현우 줄의 수량×단가 합 · 거기서 원본 4행 수량×단가를 뺀 값 |
| 매출 A1:E12 가 원본과 같다(돌려놓았다) · practice 의 원본이 그대로다 | 원본과 댄다 |

## 스스로 확인할 것

- □ 집계 시트의 수식에 IFERROR 가 없다(오류를 0 으로 덮지 않았다)
- □ 집계 B열 수식이 담당자 이름을 글자로 박지 않고 그 줄 A열 칸을 가리킨다
- □ 검산 시트의 「집계 합계 = 매출 합계」 대조가 「같음」이다

## 막혔을 때

`solution/` 에 정답 예시 파일이, `wrong/` 에 흔한 실수 하나(합계 줄 수식이 마지막 담당자 줄까지 닿지 않는 `SUM(B2:B4)` 파일)가 있습니다.
담당자별 값은 모두 맞는데 합계만 ✗ 가 됩니다. 검산 시트의 「같은가」도 「다름」이 됩니다. 채점기 출력 원문은 [`_verify.txt`](_verify.txt) 에 있습니다.
