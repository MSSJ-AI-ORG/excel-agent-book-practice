# P1-01 1부 방식으로 한 벌 손보고, 바뀐 자리를 표시해 넘기기

- **어느 장**: 1부 종합 — 3장 「3.2 셀 값과 글꼴·색을 말로 바꾸기」 · 「3.3 열 너비·행 높이·틀 고정을 말로 맞추기」 · 4장 「4.1 무엇을 바꿨는지 목록으로 받기」 · 「4.2 바뀐 셀에 표시 남기게 하기」 · 「4.4 작업 전 사본을 자동으로 남기게 하기」
- **종합 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 작업 폴더에 **복사**한 것을 씁니다.
- **낼 파일**: `P1-01_1부종합.xlsx`

---

## 왜 하나

1부에서 서식·너비·틀 고정을 말로 걸었고(3장), 바뀐 칸을 목록으로 받고 표시를 남겼고, 손대기 전에 사본이 남게 했습니다(4장).
이 과제는 그 순서를 한 벌 이어서 합니다. 끝나면 **받는 사람이 무엇이 바뀌었는지 한눈에 보는 파일**이 됩니다.

## 할 일

1. `C:\엑셀실습` 에 저장소의 `practice/이번 달 매출.xlsx` 를 복사해 `P1-01_1부종합.xlsx` 로 이름을 바꿉니다.
   `C:\엑셀실습` 에서 `claude` 를 실행하고, **먼저** 4.4 의 사본 규칙을 책 그대로 겁니다(04-02 에서 걸었어도 새 대화면 다시 겁니다).

   ```prompt
   앞으로 이 폴더의 엑셀 파일을 고치기 전에는, 먼저 「_백업」 폴더에 사본을 만들어 줘.
   사본 이름은 원래 이름 뒤에 날짜와 시각을 붙여 줘.
   사본을 만든 뒤에 고치고, 사본 경로를 알려 줘.
   ```

2. `P1-01_1부종합.xlsx` 를 엑셀로 열고, 3.1 의 시킬 말로 그 창에 붙게 합니다(03-01 의 2번).

3. 서식을 겁니다. 3.2 의 시킬 말에서 **③ 채우기만 뺐습니다.** 채우기는 7번에서 표시 색으로 씁니다.

   ```prompt
   지금 열려 있는 매출 시트에서 다음 두 가지를 해 줘.
   ① 1행 머리글을 굵게
   ② C열부터 E열까지 숫자에 천 단위 구분 기호
   값은 바꾸지 말고 서식만 바꿔 줘.
   ```

   3.3 의 시킬 말 두 개를 책 그대로 칩니다.

   ```prompt
   A열부터 E열까지 내용에 맞춰 너비를 자동으로 맞춰 줘.
   ```

   ```prompt
   1행 머리글이 스크롤해도 보이게 틀 고정을 걸어 줘.
   지금 몇 행에 틀 고정이 걸리는지도 알려 줘.
   ```

4. 4.1 의 기준 잡기 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금부터 바꾸는 것을 기록해 줘.
   바꾸기 전에 매출 시트 A1:E12 의 값을 전부 기억해 두고,
   작업이 끝나면 바뀐 셀을 「셀 주소 / 전 / 후」 표로 알려 줘.
   ```

5. 값을 하나 바꿉니다. ‹과제에서 새로 붙인 시킬 말입니다.›

   ```prompt
   담당자가 「강민서」이고 품목이 「모니터」인 줄의 수량을 9로 바꿔 줘.
   ```

6. 받은 표를 시트에 남기고 종류를 가르게 합니다. ‹과제에서 새로 붙인 시킬 말입니다(04-01 의 4번과 같습니다).›

   ```prompt
   방금 받은 표를 이 통합 문서에 「변경목록」 시트를 새로 만들어 적어 줘.
   1행은 머리글로 「셀 / 전 / 후 / 종류」, 2행부터 한 줄에 한 칸씩 적어 줘.
   순서는 매출 시트에서 위쪽 줄부터, 같은 줄이면 왼쪽 칸부터.
   전·후 칸에는 화면에 보이는 글자가 아니라 셀에 든 값을 적고, 숫자는 숫자로 적어 줘.
   종류 칸에는 직접 바꾼 칸이면 「직접」, 수식 때문에 따라 바뀐 칸이면 「따라」를 적어 줘.
   ```

7. 바뀐 칸에 표시를 남깁니다. 4.2 의 순서대로 **칠하기 전에 원래 색을 먼저** 받습니다.
   4.2 의 시킬 말에서 「다섯 칸」을 이 과제에 맞게 「바뀐 칸」으로 바꿨습니다.

   ```prompt
   칠하기 전에, 그 바뀐 칸들에 원래 채우기 색이 있었는지 확인해서 알려 줘.
   있으면 그 색을 따로 적어 두고 칠해 줘.
   ```

   ```prompt
   방금 바뀐 칸들에 연한 노란색 채우기를 해 줘.
   직접 바꾼 칸과 따라 바뀐 칸을 다른 색으로 해 줘.
   ```

   > [그림 P1-01-A] 직접 바꾼 칸과 따라 바뀐 칸이 다른 색으로 칠해진 화면 (촬영 예정)

8. 엑셀에서 저장(Ctrl+S)하고 닫은 뒤, 저장소 폴더에서 채점합니다.

   ```
   python grader/check.py P1-01 C:\엑셀실습\P1-01_1부종합.xlsx
   ```

## 확인법 — 1부에서 배운 것

- 「화면에 보이는 것과 셀에 든 것을 가르는 습관」(3.2)
- 「기준을 먼저 잡아야 비교가 된다」(4.1)
- 「표시를 남기는 작업이 표시를 지우는 작업을 어렵게 만들지 않도록 한다」(4.2) — 7번에서 원래 색을 먼저 받는 이유입니다.
- 「손대기 전에 사본이 자동으로 남는다」(1부에서 갖춘 것) — 1번을 맨 먼저 합니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 굵게 · `#,##0` · D·E열 너비 9 이상 · 틀 고정 A2 | 03-01 과 같은 규칙(채우기 제외) |
| 「강민서 / 모니터」 줄(3행)의 수량이 9 | 과제에서 시킨 값 |
| 그 밖의 칸은 원본 그대로 | 원본과 칸마다 댄다 — 값 칸은 값, 수식 칸은 수식 글자 |
| 매출!E12 가 따라 바뀌었다 | 원본 수량×단가 합에서 그 줄만 수량을 9로 바꿔 채점기가 다시 더한다 |
| 변경목록 2~4행의 셀·전·후·종류, 5행은 빈칸 | 원본 입력 칸에서 바꾸기 전·후를 따로 계산해 다른 칸만 골라낸 결과 |
| C3 · E3 · E12 에 표시 색이 있다 | — |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

★ 「강민서 / 모니터」 줄의 번호와 변경목록의 셀 주소·종류는 `check.json` 에 값으로 적어 두었습니다. 원본에서 나온 값인지는 `_expected.py` 가 확인합니다.

★ **두 색이 서로 다른지는 채점기가 아직 보지 못합니다.** 사본 규칙, 원래 색 확인과 함께 결과 아래 「스스로 확인하세요」에 나옵니다.
