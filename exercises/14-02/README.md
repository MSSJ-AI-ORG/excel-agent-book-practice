# 14-02 코드는 한 줄도 고치지 말고 주석만 달기

- **어느 장**: 14장 「14.3 `For`·`Do` 반복이 몇 번 도는지 세기」 · 「14.4 코드 한 줄씩 주석 달게 하기」
- **응용 과제** · 채점: 자동(auto) — 코드 글 파일을 채점합니다
- **시작 파일**: `practice/부서 관리대장.xlsm` — 원본은 열지 않습니다. 사본에서 합니다.
- **낼 파일**: `집계매크로_주석.bas` (주석을 단 「집계매크로」 모듈을 내보낸 글 파일)

---

## 왜 하나

14.1~14.3 에서 대상·조건·반복을 읽었습니다. 14.4 는 **읽은 것을 코드에 남기는 일**입니다.
여기서 흔히 생기는 일이 있습니다. 주석을 달아 달라고 했는데 「이왕이면 이렇게 고치는 게 좋겠다」며 **코드가 바뀌어** 옵니다.
이 과제의 채점기는 주석과 빈 줄을 뺀 코드가 원본과 한 줄도 다르지 않은지 댑니다.

## 할 일

1. `practice/부서 관리대장.xlsm` 을 작업 폴더에 `14-02_작업.xlsm` 으로 복사하게 합니다. 원본은 열지 않게 합니다.

2. 14.3 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   부서별집계의 For 문을 찾아서, 각각 몇 번 도는지 세어 줘.
   안쪽과 바깥쪽이 겹쳐 있으면 총 몇 번 도는지도 알려 줘.
   ```

3. 14.4 의 시킬 말을 책 그대로 칩니다. ★ 마지막 줄을 빼지 않습니다.

   ```prompt
   부서별집계 코드에 주석을 달아 줘.
   ① 프로시저 맨 위에 — 무엇을 하는지, 어느 시트를 읽고 어디에 쓰는지
   ② 각 For 앞에 — 몇 번 도는지와 무엇을 도는지
   ③ 각 If 앞에 — 무엇과 무엇을 가르는지 업무 말로
   ★코드는 한 줄도 고치지 말고 주석만 달아 줘.
   ```

   과제에서 덧붙이는 말(채점기는 «바로 윗줄»을 봅니다):

   ```prompt
   주석은 For 줄·If 줄 바로 윗줄에 붙여 줘. 주석과 그 줄 사이에 빈 줄을 두지 마.
   ```

4. 사본을 엑셀로 열고 VBA 편집기에서 「집계매크로」 모듈을 고른 뒤 **[파일] - [파일 내보내기]** 로 `집계매크로_주석.bas` 로 저장합니다.

5. 채점합니다.

   ```
   python grader/check.py 14-02 집계매크로_주석.bas
   ```

## 확인법 — 14장에서 배운 것

- 「「코드는 고치지 마」를 반드시 붙인다」 — 주석 달기와 고치기는 다른 작업입니다.
- 「번역 주석은 안 쓰느니만 못하다」 — 「i 를 1 증가시킨다」가 아니라 **왜** 이렇게 하는지, 건드리는 시트와 범위, 조건이 가르는 업무 경우, 주의할 점을 씁니다.
- 「겹친 반복은 곱해진다」 — 바깥 3번 × 안쪽 16번.

## 채점기가 보는 것

| 항목 | 무엇을 보나 |
|---|---|
| 주석과 빈 줄을 빼면 원본 집계매크로와 줄마다 같다 | 원본 파일에서 꺼낸 집계매크로의 코드 줄(주석·빈 줄을 뺀 32줄)을 차례대로 댄다. 줄 안의 띄어쓰기 개수와 줄 끝에 붙인 주석은 따지지 않는다(`_expected.py` 가 원본에서 규칙을 만든다) |
| 부서별집계 안의 `For` 줄·`If` 줄 바로 윗줄이 모두 주석이다 | ②·③ 주석을 달았나 |
| `Sub 부서별집계` 줄 바로 윗줄이 주석이다 | ① 프로시저 맨 위 주석 |

채점 결과 아래의 □ 항목(번역 주석이 아닌가)은 스스로 봅니다. 기계는 주석이 «좋은지»를 못 봅니다.
