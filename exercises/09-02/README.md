# 09-02 오류를 0 으로 덮지 말고 빈칸으로, 덮은 개수는 세어 두기

- **어느 장**: 9장 「9.3 순환 참조 찾아 끊기」 · 「9.4 오류를 숨기지 말고 드러나게 두기」
- **응용 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 클로드에게 사본을 만들게 합니다.
- **낼 파일**: `09-02_오류.xlsx`

---

## 왜 하나

9장 끝의 표에서 «안 보이는 오류» 셋을 봤습니다. 이 과제는 그 가운데 둘을 다룹니다.

- **순환 참조** — 오류가 아니라 0 이 뜹니다. 0 은 의심받지 않는 값입니다.
- **`IFERROR` 로 덮은 값** — 0 으로 덮으면 「계산할 수 없다」가 「계산했더니 0 이다」로 바뀌고, 그 0 이 조용히 계산에 들어갑니다.

그래서 오류는 0 이 아니라 **빈칸**으로 덮고, 덮은 칸이 몇 개인지 **세어 둡니다.**

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 복사해서 「09-02_오류.xlsx」로 만들어 줘.
   원본은 열지도 말고 건드리지도 마.
   앞으로 이 대화에서 「매출 시트」라고 하면 이 사본의 매출 시트를 가리키는 걸로 해 줘.
   ```

2. **순환 참조** — 9.3 의 시킬 말 셋을 책 그대로 칩니다.

   ```prompt
   매출 시트 J2 에 `=J2+1` 을 넣어 줘. 그리고 화면에 무엇이 뜨는지 알려 줘.
   ```

   ```prompt
   이 통합 문서에 순환 참조가 있는지 전부 찾아 줘.
   있으면 어느 시트 어느 칸인지, 어떤 경로로 자기 자신에게 돌아오는지 알려 줘.
   ```

   ```prompt
   이 순환 참조가 무엇을 하려던 것인지 추측해 주고,
   끊는 방법을 두세 가지 제안해 줘. 아직 고치지는 마.
   ```

   이 과제에서는 시험으로 넣은 칸이므로 비워서 끊습니다(이 과제에서 새로 붙인 말).

   ```prompt
   J2 를 비워서 순환 참조를 끊어 줘.
   ```

3. **IFERROR 가 없애는 것** — 9.4 의 시킬 말 둘을 책 그대로 칩니다. 본 뒤에는 시연 칸을 지우게 합니다(이 과제에서 새로 붙인 말).

   ```prompt
   C4 에 「미정」을 넣고,
   K2 에는 `=C4*D4` 를, L2 에는 `=IFERROR(C4*D4,0)` 을 넣어 줘.
   그리고 M2 에 `=SUM(L2)` 를 넣어서 합계도 내 줘.
   ```

   ```prompt
   이 시트에서 IFERROR 로 오류를 0으로 바꾸는 수식이 있는지 찾아 줘.
   그중에 그 값이 다시 합계에 들어가는 칸이 있으면 따로 표시해 줘.
   ```

   ```prompt
   시연으로 넣은 K2:M2 는 지워 줘. C4 의 「미정」은 그대로 둬.
   ```

4. **빈칸으로 덮기** — 이 과제에서 새로 붙인 시킬 말입니다.

   ```prompt
   매출 시트 E2:E11 의 금액 수식을, 계산이 안 되면 0 이 아니라 빈칸이 되게 바꿔 줘.
   E12 합계 수식과 A:D열은 그대로 둬.
   ```

5. **덮은 개수 세기** — 9.4 「덮는 대신 세어 둔다」의 시킬 말입니다. 이 과제에서는 첫 줄의 「0으로」를 「빈칸으로」로 바꿔 칩니다. 셀 자리는 이 과제에서 새로 붙인 말로 정해 줍니다.

   ```prompt
   오류가 난 칸을 빈칸으로 바꾸되, 몇 칸을 바꿨는지 세는 칸을 하나 만들어 줘.
   그 칸에 0이 아닌 숫자가 있으면 사람이 봐야 한다고 적어 줘.
   ```

   ```prompt
   세는 칸은 N1 에 수식으로 넣고 M1 에 「덮은 칸 수」라고 적어 줘.
   그리고 N2 에는 E2:E11 에서 금액이 숫자로 나온 칸 수를 세는 수식을, M2 에는 그 이름을 적어 줘.
   ```

6. `09-02_오류.xlsx` 를 엑셀로 엽니다. [수식] - [오류 검사] - [순환 참조]가 회색(비활성)인지 보고, E4 가 0 이 아니라 빈칸으로 보이는지 봅니다. 저장하고 닫습니다.

7. 채점합니다.

   ```
   python grader/check.py 09-02 09-02_오류.xlsx
   ```

## 확인법 — 9.3·9.4 에서 배운 것

- 「0은 의심받지 않는 값이다」 — 2번에서 J2 에 오류가 아니라 0 이 뜨는 것을 봅니다.
- 「빈칸(`""`)으로 바꾸면 합계에 안 들어가지만, 0으로 바꾸면 들어간다」 — N2 가 그 차이를 셉니다. 0 으로 덮으면 숫자 칸이 하나 더 많아집니다.
- 「덮은 개수를 세어 두면 덮은 것이 사라지지 않는다」 — 5번.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| C4 가 「미정」이고, 나머지 A:D열은 원본과 같다 | 원본과 칸마다 댄다 |
| J2 가 비어 있다(순환 참조를 끊었다) | — |
| E2·E4·E11 에 IFERROR 가 있다 | — |
| E12 합계 = 4행만 빠진 값 | 채점기가 원본의 수량×단가 전체 합에서 원본 4행 수량×단가를 뺀다 |
| N1 이 수식이고, 덮은 칸 수 = 수량 칸에 숫자가 아닌 것이 든 줄 수 | 채점기가 **제출 파일** C2:C11 에서 숫자가 아닌 칸을 다시 센다 |
| N2 가 COUNT 수식이고, 금액이 숫자로 나온 칸 수 = 수량이 숫자인 줄 수 | 채점기가 제출 파일 C2:C11 에서 숫자인 칸을 다시 센다 — 오류를 0 으로 덮으면 하나 더 많아진다 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

## 스스로 확인할 것

- □ J2 에 =J2+1 을 넣었을 때 오류가 아니라 0 이 뜨는 것을 보았다
- □ [수식] - [오류 검사] - [순환 참조]가 회색(비활성)이다 — 자기 자신을 가리키는 수식이 남아 있지 않다
- □ 매출!E4 가 0 이 아니라 빈칸으로 보인다

채점기는 빈칸을 내는 수식 칸(E4)을 직접 읽지 못합니다(엑셀이 그 칸에 계산값을 저장하지 않습니다). 그래서 N2 의 개수로 대신 확인하고, 셋째 줄은 눈으로 봅니다.

## 막혔을 때

`solution/` 에 정답 예시 파일이, `wrong/` 에 흔한 실수 하나(오류를 빈칸이 아니라 `IFERROR(…,0)` 으로 0 으로 덮은 파일)가 있습니다.
