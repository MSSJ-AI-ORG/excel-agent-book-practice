# 04-01 세 칸을 바꾸고 다섯 칸짜리 변경 목록 받기

- **어느 장**: 4장 「4.1 무엇을 바꿨는지 목록으로 받기」
- **기본 과제** · 채점: 자동(auto)
- **시작 파일**: `practice/이번 달 매출.xlsx` — 원본은 열지 않습니다. 사본 `04-01_변경목록.xlsx` 를 만들어 그 사본을 엑셀로 엽니다.
- **낼 파일**: `04-01_변경목록.xlsx`

---

## 왜 하나

4.1 에서 세 칸을 바꾸라고 시켰는데 목록에는 다섯 칸이 올라왔습니다.
금액 칸과 합계 칸이 수식 때문에 따라 바뀌었기 때문입니다.
그리고 이렇게 배웠습니다. 「따라 바뀐 칸은 되돌릴 대상이 아니기 때문이다」.

이 과제는 그 목록을 받아 시트에 남기고, 직접 바꾼 칸과 따라 바뀐 칸을 가릅니다.
채점기는 원본에서 전·후 값을 **따로 다시 계산해** 목록과 댑니다.

## 할 일

1. 저장소 폴더에서 `claude` 를 실행하고 사본을 만들게 합니다. ‹과제에서 새로 붙인 시킬 말입니다.›

   ```prompt
   practice 폴더의 「이번 달 매출.xlsx」를 이 폴더에 「04-01_변경목록.xlsx」라는 이름으로 복사해 줘.
   원본은 열지도 말고 건드리지도 마.
   ```

   `04-01_변경목록.xlsx` 를 엑셀로 열고, 3.1 의 시킬 말로 그 창에 붙게 합니다(03-01 의 2번).

2. **바꾸기 전에** 기준을 잡게 합니다. 4.1 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   지금부터 바꾸는 것을 기록해 줘.
   바꾸기 전에 매출 시트 A1:E12 의 값을 전부 기억해 두고,
   작업이 끝나면 바뀐 셀을 「셀 주소 / 전 / 후」 표로 알려 줘.
   ```

3. 세 칸을 바꿉니다. 4.1 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   B2 를 「태블릿」으로, C3 을 9로, A1 을 「담당」으로 바꿔 줘.
   ```

   > [그림 04-01-A] 「셀 주소 / 전 / 후」 표를 받은 화면 (촬영 예정)

   받은 표가 몇 줄인지 셉니다. 시킨 것은 세 칸입니다.

4. 받은 표를 시트에 남기게 합니다. ‹과제에서 새로 붙인 시킬 말입니다.›

   ```prompt
   방금 받은 표를 이 통합 문서에 「변경목록」 시트를 새로 만들어 적어 줘.
   1행은 머리글로 「셀 / 전 / 후 / 종류」, 2행부터 한 줄에 한 칸씩 적어 줘.
   순서는 매출 시트에서 위쪽 줄부터, 같은 줄이면 왼쪽 칸부터.
   전·후 칸에는 화면에 보이는 글자가 아니라 셀에 든 값을 적고, 숫자는 숫자로 적어 줘.
   매출 시트는 더 고치지 마.
   ```

5. 직접 바꾼 칸과 따라 바뀐 칸을 가르게 합니다. 4.1 의 시킬 말을 책 그대로 칩니다.

   ```prompt
   방금 목록에서 직접 바꾼 칸과, 수식 때문에 따라 바뀐 칸을 갈라서 보여 줘.
   ```

   ‹받은 결과대로 변경목록 D열에 「직접」 또는 「따라」를 적게 합니다.›

6. 엑셀에서 저장(Ctrl+S)하고 닫은 뒤 채점합니다.

   ```
   python grader/check.py 04-01 04-01_변경목록.xlsx
   ```

## 확인법 — 4장에서 배운 것

- 「기준을 먼저 잡아야 비교가 된다」 — 2번을 3번보다 먼저 합니다.
- 「따라 바뀐 칸은 되돌릴 대상이 아니기 때문이다」 — 되돌릴 때는 C3 만 되돌리면 E3·E12 는 알아서 돌아갑니다.

## 채점기가 보는 것

| 항목 | 기대값은 어디서 오나 |
|---|---|
| 매출 A1·B2·C3 이 시킨 값이다 | 4.1 의 시킬 말에 적힌 값 |
| 매출 E3·E12 가 따라 바뀌었다 | 원본 단가·수량에서 채점기가 다시 계산한다(원본 E열 수식은 안 쓴다) |
| 변경목록 2~6행의 셀·전·후·종류 | 원본 입력 칸에서 바꾸기 전·후의 A1:E12 를 따로 계산해 다른 칸만 골라낸 결과 · 원본에서 수식이 있던 칸이면 「따라」, 없던 칸이면 「직접」 |
| 변경목록 7행은 비어 있다 | 안 바뀐 칸이 끼어들지 않았는지 |
| practice 의 원본이 그대로다 | 원본 파일의 지문을 처음 받은 지문과 댄다 |

★ 셀 주소와 종류는 `check.json` 에 값으로 적어 두었습니다. 그 값이 원본에서 다시 계산한 결과인지는 `_expected.py` 가 확인합니다.
전·후 값은 채점기가 원본에서 직접 계산합니다.

## 예시 파일

`solution/` 은 위 과정을 엑셀에서 그대로 한 파일입니다. 바꾸기 전과 후의 A1:E12 를 엑셀에서 읽어 서로 다른 칸을 모두 적었습니다.
`wrong/` 은 흔한 실수 하나 — **시킨 세 칸만 적고 따라 바뀐 두 칸을 빠뜨린** 파일입니다.
